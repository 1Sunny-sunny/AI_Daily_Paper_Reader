## 摘要
尽管黎曼深度学习取得了进展，跨域EEG解码仍具挑战性：不同受试者的协方差矩阵在SPD流形上占据显著不同的区域，然而现有域适应方法要么需要目标域校准数据，要么学习无法跨域泛化的受试者特定成分。我们提出动态Stiefel路由：在Stiefel流形上设置K个专家投影滤波器，每个专门针对SPD流形的不同区域，通过交叉注意力将每个输入协方差路由至最合适的滤波器，从而逐样本自适应子空间投影。一项核心发现是，这种简单实现的方法可被证明会退化为集成平均：当路由权重均匀时，自适应滤波器精确简化为专家的等贡献组合，与单个固定滤波器无异。三种结构特性打破了这一退化：对称锚点W_base∈St(n,k)消除了专家间的邻近偏差；冻结的域判别式查询编码器将路由与任务优化解耦；解耦的关键对齐损失将专家关键训练为稳定的域吸引子。三者结合首次在SPD流形上实现了真正专一且域结构化的路由，在三个数据集上取得了一致提升：平衡准确率从0.773提高到0.823，0.757提高到0.809，0.801提高到0.839，对齐策略由单一数据驱动规则自动确定，无需针对数据集进行超参数搜索。

## Abstract
Cross-domain EEG decoding remains challenging despite advances in Riemannian deep learning: covariance matrices from different subjects occupy systematically distinct regions of the SPD manifold, yet existing domain adaptation methods either require target-domain calibration data or learn subject-specific components that cannot generalise across domains. We propose dynamic Stiefel routing: a pool of $K$ expert projection filters on the Stiefel manifold, each specialised for a different region of the SPD manifold, with each input covariance routed to the most appropriate filter via cross-attention, adapting the subspace projection per sample. A central finding is that this approach, implemented naively, provably collapses to ensemble averaging: when routing weights are uniform, the adaptive filter reduces exactly to an equal-contribution combination of experts, indistinguishable from a single fixed filter. Three structural properties break this degeneracy: a symmetric anchor $W_{\mathrm{base}} \in \mathrm{St}(n,k)$ that removes proximity bias among experts; a frozen domain-discriminative query encoder that decouples routing from task optimisation; and a decoupled key alignment loss that trains expert keys toward stable domain attractors. Together they produce the first genuinely committed and domain-structured routing on SPD manifolds, with consistent gains across three datasets: balanced accuracy improves from $0.773\to 0.823$, $0.757\to 0.809$, and $0.801\to 0.839$, with the alignment strategy determined automatically by a single data-driven rule and no dataset-specific hyperparameter search.

*   **研究动机**：现有域适应方法或需目标域校准数据，或学习无法泛化的受试者特定成分，缺乏一种能**在推理时、无需重新训练即根据输入样本动态调整子空间**的机制。
*   **整体含义**：论文探究**自适应子空间选择何时真正有效**，揭示了简单实现会**退化为集成平均**，并提出了打破该退化的结构性解决方案，首次实现了Stiefel流形上真正“专一”且具有域结构的路由。

### 2. 论文提出的方法论

*   **核心思想**：在Stiefel流形 $\text{St}(n,k)$ 上维护一个**专家投影滤波器池** $\{W_j\}_{j=1}^K$，每个专家负责SPD流形的不同区域。通过**交叉注意力**为每个输入协方差矩阵 $X_i$ 计算路由权重，动态插值生成**逐样本自适应滤波器** $W_i$。
*   **推导的退化问题**：
    *   论文**证明**，若路由权重 $\alpha_i$ 因梯度消失等原因趋近于均匀分布 $1/K$，则生成滤波器会**精确退化为**固定滤波器 $W_i = R_{W_{\text{base}}}\left(\frac{1}{K}\sum_j P_{W_{\text{base}}}(W_j)\right)$。
    *   此退化是**自我强化**的：均匀权重使各专家获得相同梯度信号，丧失专长动力，进而专家相似，导致权重梯度进一步减弱。
*   **打破退化的三大结构性修复**（构成域自适应Stiefel池DASP层）：
    1.  **对称锚点 $W_{\text{base}} \in \text{St}(n,k)$**：引入一个独立于专家池的、可学习的专用参考点，消除因选择某个专家作为基点在几何上对特定专家产生的“邻近偏差”，让所有专家公平竞争。
    2.  **冻结的域判别查询编码器**：对协方差的对数进行**域分离投影 (DSP)**，仅提取切线空间中响应“域身份”的低维信号（$\tilde{x}_i = x_i P_{\text{DSP}}$），此矩阵预计算后冻结。这迫使查询生成仅依赖于域纯度特征，解耦了**路由与分类任务优化**，类似提示学习(L2P)中的冻结主干网络。
    3.  **解耦的键对齐损失**：专家键 $E$ 不通过交叉熵梯度更新，而是由独立损失训练：
        $$L_{\text{align}} = \lambda_{\text{align}} \mathbb{E}_i \left[ 1 - \cos\left( \text{sg}(q_i), E_{j_i^*} \right) \right]$$
        仅更新权重最高的胜者键 $j_i^*$，迫使键移向各自域查询的稳定“吸引子”，避免“移动靶”问题。
*   **统一扩展方法论**：通过**切线-域比率** $\rho = n(n+1)/(2D)$ 自动决定DSP和对齐策略。当 $\rho > 50$ 时激活DSP和解耦键，反之则禁用。

*   **退化普适性**：朴素的自适应Stiefel路由因梯度机械原因，会**必然退化为集成平均**，该增益源自专家多样性而非逐样本自适应。
*   **诊断标准**：只有 $K=1$ 代理差距 $\Delta_{K=1} > 0$ 才能作为**真正路由产生增益的必要条件**。
*   **结构性修复有效**：对称锚点、冻结DSP查询编码器和解耦键对齐损失三者结合，是首次在SPD流形上产生**“专一”（低熵）** 和 **“域结构化”（高域对齐比）** 路由的唯一途径。
*   **数据驱动扩展可行**：通过切线-域比率 $\rho$ 可自动、无需数据集特定调参地决定DASP层的使用策略，并在性质差异巨大的数据集上均取得**一致的性能提升**（准确率分别提升0.050, 0.053, 0.038）。

### 8. 不足与局限

*   **零样本泛化受限**：在LOSO实验中，所有自适应变体均未能超越固定基线。方法适用于**已知域内的自适应**，而非对完全未见域的零样本泛化。

*   **资源规模**：尽管没有使用算力密集型GPU，但也限制了该方法在大规模高维数据集或与更大型深度模型结合时的验证。
