## 摘要
尽管非言语行为和表达性动作对于自然的人机交互至关重要，但现有方法往往忽略了一个关键要素：人类的内在认知状态。主动式多智能体系统常常在不合时宜的时刻打断人类，导致认知超载并降低任务表现。本文提出了一种生成“认知对齐”多智能体交互的框架，增强机器人系统在人类心理负荷高和参与度强的时刻，根据情境将通信延迟给智能体系统用户的能力。我们设计并实现了一种闭环架构，探索自主任务执行与实时神经生理专注度之间的相互作用。利用消费级脑机接口（BCI），我们的方法持续监测脑电图（EEG）频谱带功率，同时人类执行一项需要投入的任务。我们提出了一种参与度驱动的流程，其中基于HTTP的信令机制在检测到高参与度时，将主智能体的感觉输入和音频输出置于保持状态。这使得次级智能体能够在后台无缝处理复杂的委托任务。一旦人类认知状态恢复到较低的认知负荷基线，主智能体便释放排队的智能体消息。初步结果表明，利用实时信号处理、大语言模型（LLMs）和物理机器人实体来创建具有认知感知、非侵入式多智能体系统的可行性。

## Abstract
While non-verbal behaviors and expressive movements are essential for natural human-robot interaction, existing methods often overlook a crucial element: the human's internal cognitive state. Frequently, proactive multi-agent systems can interrupt humans at inopportune moments, leading to cognitive overload and decreased task performance. This paper introduces a framework for generating "cognitively aligned" multi-agent interactions, enhancing the ability of robotic systems to contextually defer communications to the user of an agent system during moments of high human mental workload and engagement. We present the design and implementation of a closed-loop architecture that explores the interplay between autonomous task execution and real-time neurophysiological focus. Using a consumer-grade Brain-Computer Interface (BCI), our approach continuously monitors Electroencephalography (EEG) spectral band powers while a human performs an engagement-inducing task. We propose an engagement-driven pipeline where an HTTP-based signaling mechanism places a primary agent's sensory inputs and audio outputs into a holding state upon detecting high engagement. This allows secondary agents to seamlessly process complex, delegated tasks in the background. Once the human's cognitive state returns to a lower cognitive load baseline, the primary agent releases the queued agent message. Our preliminary results demonstrate the feasibility of leveraging real-time signal processing, Large Language Models (LLMs), and physical robotic embodiments to create cognitively-aware, non-intrusive multi-agent systems.

## 2. 方法论：核心思想与关键技术细节
- **核心思想**：构建一个闭环架构，使交互主代理（Primary Agent）的音频输出和麦克风输入在检测到高参与度时自动进入“保持状态”（Holding State），而后台次级代理（Secondary Agent）继续完成复杂委托任务；待用户认知负荷下降后再释放已排队的消息。
- **认知状态测量**：
  - 使用 Muse 头带记录 4/5 通道 EEG（256 Hz）、PPG、IMU。
  - 应用 FFT 和 50/60 Hz 陷波滤波器提取频带功率 $\delta$、$\theta$、$\alpha$、$\beta$、$\gamma$。
  - 计算瞬间参与度比率：
    $$R_t = \frac{P(\beta_t)}{P(\alpha_t) + P(\theta_t)}$$
  - 经指数移动平均（EMA）平滑得到最终参与度分数：
    $$E_t = \alpha R_t + (1-\alpha) E_{t-1}, \quad \alpha \in (0,1)$$
- **通信门控机制**：
  - 当 $E_t$ 持续超过某阈值（基于 30 秒基线校准后的 $1.5\times E_{base}$）并稳定 60 秒后，游戏模拟器通过 HTTP POST（`/focus?state=on`）通知主代理进入静默状态，物理 LED 转为红色。
  - 当参与度回落，发送 `/focus?state=off` 释放消息。
- **语义重要性分类器**：引入本地量化 LLM 评估消息重要性权重 $W_{imp}$，中断决策由
  $$I_t = \mathbb{I}(W_{imp} > \lambda \cdot E_t)$$
  决定，危急消息可覆盖门控，而常规消息则被暂缓。
- **代理生态与通信**：
  - 主代理（Nadine）基于 Gemini‑3.1‑flash‑live‑preview 实现双向音频对话，并负责任务委托与门控。
  - 次级代理（Red Claw、Blue Claw）通过 ADK（Agent Development Kit）执行诸如机票预订等长时间任务，仅通过 LED 动画和外周无声振动传递状态，不直接打断用户。

## 6. 主要结论与发现
- **认知对齐可行**：通过 BCI 门控，94.2% 的代理消息在高参与度期间被成功拦截，平均保持时长 42.6 秒，证明多代理系统可尊重人的认知窗口。
- **物理表达减少干扰**：机器人通过 LED 颜色变化、非语言哼鸣（恐龙咆哮）在周边视野传递状态，避免了屏幕弹窗产生的焦点剥夺。
- **移情与拟人化**：软质龙虾和“不能说话”的 Blue Claw 引发了用户额外的触摸、问候和同理心，说明硬件约束可能产生意料之外的情感参与。
- **跨领域可泛化**：基于脑电的认知标记不限定任务类型，同一架构可用于修车、驾驶等场景。

## 7. 优点
- 首次在嘈杂的真实世界场所将**多代理系统、物理机器人实体与在线 BCI 门控**整合为一体，实现了认知对齐概念验证。
- 引入 **语义重要性分类器**，在保护心流的同时确保紧急信息不被漏失。
- 隐私设计优秀：原始 EEG 完全停留于本地边缘设备，仅传递抽象的二元聚焦状态，无云传输风险。
- 通过不同材质和能力的机器人，**探索了物理化、非屏幕交互**在减少认知负载上的潜力。

## 8. 不足与局限
- **实验严谨性不足**：缺乏受控对比和纵向测试，一次现场展示的结论无法排除新奇效应和选择偏差。
- **信号质量有限**：消费级 Muse 头带对运动伪影、肌肉噪声敏感，且无法区分“专注心流”“紧张”或“感官超载”。
- **阈值鲁棒性差**：依赖个体基线校准和固定倍乘阈值，不同用户的 EEG 差异大，不能“一刀切”。
- **延迟与稳定性**：BLE 协议在射频拥堵环境中可能丢包，导致参与度监测短暂中断，影响门控时效。
- **应用限制**：需长期佩戴头带，且当前仅在简单游戏任务中验证，尚未覆盖真实复杂办公或驾驶场景。
