## 摘要
自动化睡眠分期是被动脑机接口（pBCI）的一项基本应用，通过解码自发性神经状态来实现独立于用户意图的闭环干预。本研究评估了从去趋势波动分析（DFA）中提取的临界性特征在深度睡眠（N3）特定识别中的应用。我们使用UMAP流形学习对290名老年女性的347,232个EEG时段进行了分析，以可视化状态转换。随后，通过10折交叉验证对六种分类器进行了基准测试，使用平衡准确度来确定用于神经反馈的最优“状态感知”引擎。朴素贝叶斯取得了最高的平均平衡准确度（87.17% ± 0.24%），显著优于全连接深度神经网络（FNN：81.58%）和随机森林（80.97%）。线性模型（LDA：57.21%；SVM：51.01%）表现不佳，表明DFA衍生的临界性特征位于独特的非线性流形上。基于概率的EEG临界性解码为pBCI提供了一种高精度的感知机制。这一稳健的分类管线有助于开发状态依赖的神经反馈，例如靶向听觉刺激，以促进认知恢复。

## Abstract
Automated sleep staging is a fundamental application of passive Brain-Computer Interfaces (pBCI), decoding spontaneous neural states to enable closed-loop interventions independent of user intent. This study evaluates criticality features derived from Detrended Fluctuation Analysis (DFA) for the specific identification of deep sleep (N3).   We analyzed $347,232$ EEG epochs from $290$ older women using UMAP manifold learning to visualize state transitions. Subsequently, six classifiers were benchmarked via 10-fold cross-validation, using balanced accuracy to determine the optimal "state-sensing" engine for neurofeedback.Naive Bayes achieved the highest mean balanced accuracy ($87.17\% \pm 0.24\%$), significantly outperforming a fully connected deep neural network (FNN: $81.58\%$) and Random Forest ($80.97\%$). Linear models (LDA: $57.21\%$; SVM: $51.01\%$) performed poorly, indicating that DFA-derived criticality features reside on a distinct, non-linear manifold.   Probabilistic decoding of EEG criticality provides a high-accuracy sensing mechanism for pBCIs. This robust classification pipeline supports the development of state-dependent neurofeedback, such as targeted auditory stimulation, to enhance cognitive recovery.

### 2. 论文提出的方法论

本研究的核心方法是通过量化 EEG 信号的临界性特征，并基于此训练一个高精度的 N3 睡眠分类模型。关键技术细节如下：

-   **特征提取：去趋势波动分析（DFA）**
    -   **核心思想**：DFA 用于量化 EEG 信号中的长程时间相关性（LRTC），以标度指数 $\alpha$（即 Hurst 指数 $H$）作为信号临界性的代理。一个 $\alpha \approx 1$ 的值表明信号处于 $1/f$ 噪声，与健康的自组织临界性相符；$\alpha \approx 0.5$ 则代表白噪声。
    -   **算法流程**：对每个 30 秒的 EEG 时段进行处理，主要步骤为：
        1.  **积分**：将原始时间序列 $x(i)$ 通过公式 $Y(i) = \sum_{k=1}^{i}[x(k)-\langle x\rangle]$ 转换为一个类随机游走的积分轮廓。
        2.  **分割**：将积分轮廓划分为等长的、不重叠的片段。
        3.  **局部去趋势**：在每个片段内，用最小二乘法拟合一个多项式趋势（阶数 $k=1$，即线性趋势），并将其去除，以消除信号的非平稳漂移。
        4.  **计算波动函数**：计算去趋势后所有片段方差的均方根，得到关于片段长度 $n$ 的函数 $F(n)$。标度指数 $\alpha$ 由 $\log F(n)$ 与 $\log n$ 双对数图中的斜率确定。
    -   **输入通道**：分析了四组双极导联 EEG 信号：C3-A2, C4-A1, C3-A1 和 C4-A2。

-   **流形可视化：统一流形逼近与投影（UMAP）**
    -   应用无监督的 UMAP 算法，将高维的 DFA 特征降至三维，以观察不同睡眠阶段的自然聚类结构。这揭示了 N3 期与其他睡眠阶段之间是否存在线性或非线性的分离。

-   **分类模型与验证**
    -   **任务**：将睡眠状态分为“N3 期”与“非 N3 期”的二分类问题。
    -   **模型**：为对比不同模型对特征空间几何结构的适应性，选用了六种分类器：
        -   **线性模型**：线性判别分析（LDA）、线性支持向量机（Linear SVM）。
        -   **非线性/集成模型**：随机森林（Random Forest）、K-最近邻（KNN）。
        -   **概率/神经模型**：高斯朴素贝叶斯（Gaussian Naive Bayes）、四层全连接神经网络（FNN）。
    -   **验证策略**：采用 10 折分层交叉验证，使用平衡准确度作为主要评估指标，以解决潜在的类别不平衡问题。该指标定义为各类别召回率的算术平均：$$\text{Balanced Accuracy} = \frac{1}{2} \left( \frac{TP}{TP + FN} + \frac{TN}{TN + FP} \right)$$ 其中 $TP$、$FP$、$TN$、$FN$ 分别代表真阳性、假阳性、真阴性和假阴性。所有特征在交叉验证流程中均进行了标准化处理。
