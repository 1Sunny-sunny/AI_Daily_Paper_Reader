## Abstract 9

Coherent scenes facilitate object recognition, but the representational basis of this 10 

facilitation and its temporal evolution in the brain remain unclear. We tested this 11 

question using EEG and multivariate pattern analysis while 15 participants categorized 12 

objects from five semantic categories after a 500-ms preview of either an intact 13 

rendered scene or a phase-scrambled version of the same background. Reliable object 14 

decoding emerged earlier in intact scenes than scrambled scenes (142 ± 5 vs. 162 ± 10 15 

ms), with higher decoding for intact scenes from 124 to 268 ms after object onset. 16 

Cross-condition decoding object information that generalized across scene formats, 17 

whereas subtracting cross-condition from within-condition decoding identified an earlier 18 

and stronger context-dependent component when scene structure was coherent. Cross-19 

temporal representational similarity analysis (RSA) further showed that representational 20 

structure established during late scene preview generalized to early object processing 21

## Introduction 31 

Objects are typically encountered within structured scenes that provide strong statistical 32 

regularities about which objects are likely to occur and where they are likely to appear 33 

(Bar, 2004; Oliva and Torralba, 2007). Such regularities provide semantic and spatial 34 

priors that can constrain object perception. Behaviorally, these priors facilitate object 35 

recognition, particularly when bottom-up object information is degraded or ambiguous 36 

(Davenport and Potter, 2004; Munneke et al., 2013). Neural studies have linked such 37 

benefits to interactions between scene-selective and object-selective systems, whereby 38 

scene context sharpens category-specific object representation in visual cortex (Bar, 39 

2004; Brandman and Peelen, 2017; Wischnewski and Peelen, 2021; Leticevscaia et al., 40 

2024; Soltandoost et al., 2025). However, the extent to which coherent scene context 41 

alters the time course and representational content of object processing remains 42 

unclear. 43

One unresolved issue is what scene context adds to neural object representation. 44 

Contextual facilitation could reflect an earlier or stronger expression of an object code 45 

that is largely invariant across backgrounds. Alternatively, coherent scenes may 46 

contribute additional representational structure tied to the semantic and spatial relations 47 

between an object and its surrounding scene. These alternatives are not mutually 48 

exclusive, but they make different predictions: the first predicts information that 49 

generalizes across intact and disrupted scene formats, whereas the second predicts a 50 

context-dependent component that is selectively expressed when coherent scene 51 

structure is preserved. 52 

A related issue concerns timing. In everyday vision, global scene information can be 53 

available before focal object processing is complete. Such prior scene information may 54 

establish expectations about likely objects and thereby constrain subsequent object 55 

processing (Bar, 2004; De Lange et al., 2018). If contextual facilitation has an 56 

anticipatory component, the representational structure elicited during scene preview 57 

should be related to the earliest stages of object-evoked activity. Testing this 58 

relationship can clarify whether context acts only after object onset or whether scene-59 

derived structure is already in place before the object appears. 60 

A final question is which computational representations best capture context-sensitive 61 

neural object code. Deep neural networks (DNNs) provide explicit representational 62 

spaces that can be compared with neural data using representational similarity analysis 63 

(RSA). Vision-only models may capture image-based similarity, whereas vision– 64 

language models trained on image–text pairs may better capture semantic and 65

relational structure relevant to objects embedded in meaningful scenes (Wang et al., 66 

2022; Conwell et al., 2024; Doerig et al., 2025; Rajaei et al., 2026). Thus, if coherent 67 

scenes add semantically structured information to object representations, language-68 

aligned models should show stronger alignment with neural representations in intact 69 

scenes than when scene structure is disrupted. Here, we combined EEG with 70 

multivariate decoding and representational similarity analysis while participants viewed 71 

a 500 ms scene preview followed by a briefly presented object embedded either in an 72 

intact rendered scene or in a phase-scrambled version of the same scene. This design 73 

allowed us to ask whether coherent context accelerates or strengthens object-74 

discriminative information, whether it contributes a context-dependent representational 75 

component beyond context-invariant object code, and whether scene-preview 76 

representations are reinstated during early object processing. We then compared neural 77 

representational geometry with supervised vision, self-supervised vision, and language-78 

aligned vision–language models to test which computational representations best 79 

captured object coding when coherent scene structure was available. 80 

## Experiments and Results 81 

To determine how scene context shapes object processing over time, we organized the 82 

Results into four complementary analyses. The first three focus on the human EEG 83 

data, and the fourth compares those neural representations with computational models. 84

to establish when object-selective information emerges and whether coherent scene 86 

structure accelerates and strengthens object processing. We then use cross-condition 87

Coherent scene context accelerates and enhances object decoding 99 

We tested whether coherent scene context facilitates neural object processing and, 100 

critically, whether such facilitation reflects changes in the representational structure of 101 

object information rather than a nonspecific increase in signal strength. Fifteen 102 

participants viewed 25 objects from five semantic categories (food, electronics, 103 

containers, office supplies, and home décor) while EEG was recorded (Fig. 1A; full set 104 

in Fig. S1). Objects appeared under two context conditions: an intact condition, in which 105 

objects were embedded in coherent scenes, and a scrambled condition, in which the 106 

same object was presented at the same location on a phase-scrambled version of the 107 

same scene background (Fig. 1B). On each trial, participants viewed the scene 108 

background for 500 ms, followed by an 80-ms presentation of the target object 109

Coherent scene context generates earlier and stronger context-171 

dependent object information 172 

The shared code above cannot, by definition, capture information that depends on the 173 

specific scene context in which an object appears. To test our second hypothesis — 174 

that coherent context contributes object information beyond this context-invariant code 175 

— we isolated the context-dependent component by subtracting cross-condition from 176 

within-condition decoding, yielding a context advantage measure. This measure indexes 177 

object information that is available within a given contextual format but does not 178 

generalize across formats, providing a direct estimate of a context-dependent 179 

component of object-related discriminability. 180 

Coherent scene context shaped this context-dependent component in two ways. First, it 181 

accelerated its emergence: the context advantage arose approximately 23 ms earlier for 182 

intact than for scrambled scenes (128 ± 2 ms vs. 151 ± 4 ms; p < 0.0122). Second, it 183 

amplified its magnitude: the context advantage was significantly greater for intact than 184 

scrambled scenes from 121 to 256 ms after object onset (p < 0.05, FDR-corrected; Fig. 185 

2D). Thus, beyond the object code shared across formats, coherent scene structure 186

## Discussion 343 

The present study examined whether coherent scene context influences how the brain 344 

represents objects. Our findings suggest that object representations comprise two 345 

separable components: a context-invariant object code that generalizes across 346 

contexts, and a context-dependent representational component that is selectively 347 

present when scene structure is preserved. The object-related component likely reflects 348 

processing that is relatively independent of background structure, whereas the context-349 

related component appears to provide additional representational information tied to the 350 

object’s embedding within a coherent scene, and was largely absent when scene 351 

structure was disrupted. Rather than simply making discriminative object information 352 

available earlier or more strongly, coherent scenes thus contributed an additional 353 

representational component—a distinction directly motivating the two hypotheses set 354 

out in the Introduction. This contextual contribution increased object discriminability and 355 

accelerates the emergence of decodable object representations, advancing decoding 356 

onset from 162 ± 10 ms to 142 ± 5 ms. 357

One plausible mechanism underlying this facilitation is object-related expectation. Top-358 

down accounts propose that coherent scenes can pre-activate likely object 359 

representations before the object appears, thereby biasing subsequent object 360 

processing (Bar, 2004; Brandman and Peelen, 2017; De Lange et al., 2018; 361 

Wischnewski and Peelen, 2021; Krugliak et al., 2024). The scene-preview design used 362 

here may have favored such a mechanism because it allows scene representations to 363 

develop before object onset. This contrasts with earlier MEG studies in which scenes 364 

and objects were presented simultaneously and contextual facilitation of object 365 

representations emerged relatively late, approximately 320 ms after stimulus onset 366 

(Brandman and Peelen, 2017; Leticevscaia et al., 2024). In the present paradigm, the 367 

context advantage, measured as the intact-minus-scrambled difference in decoding 368 

accuracy, emerges approximately 120 ms and peaks around 200 ms after object onset, 369 

roughly 100 ms earlier than in simultaneous-presentation paradigms. We interpret this 370 

as evidence that, when scene context is available before object onset, anticipatory 371 

processing can shift contextual modulation of object representations to substantially 372 

earlier time-points relative to object presentation. Consistent with this interpretation, 373 

cross-temporal RSA shows that representational geometry established during late 374 

scene preview re-emerged during early object processing, suggesting that scene-375 

derived information shapes the earliest stages of object-evoked activity. The absence of 376 

a comparable effect in the scrambled condition, despite preserved low-level image 377 

statistics, further indicates that this effect depends on the semantic and structural 378 

coherence of the scene rather than on low-level visual properties alone. It is worth 379 

noting that these two observations are not contradictory: the temporal generalization 380

and is most pronounced at later processing stages; the cross-temporal RSA, by 382

that it is established during scene preview and re-expressed from the earliest latencies 384 

of object-evoked activity onward. 385 

The model comparison further suggests that the structure of neural object 386 

representations in coherent scenes is better captured by language-aligned than by 387 

vision-only models. The language-aligned model (MetaCLIP) showed a relative 388 

alignment advantage in intact scenes that was specific to later processing stages, 389 

whereas no comparable advantage is observed in scrambled scenes. This pattern is 390 

consistent with the possibility that language supervision supports representations that 391 

better capture the semantic and relational regularities linking objects to their scene 392 

context—precisely the regularities that the scrambling manipulation removes. By 393 

contrast, vision-only models may capture visual similarity well but be less sensitive to 394 

the broader contextual structure that organizes objects in natural environments. 395 

Notably, the two vision-only models classify objects more accurately when backgrounds 396 

are phase-scrambled than when they are intact, the opposite of the human pattern. This 397 

suggests that, in the absence of semantic supervision, coherent background features 398 

compete with target object features rather than supporting their interpretation. 399 

These results converge with previous findings that language-aligned models capture 400 

brain representations of natural scenes better than vision-only models (Wang et al., 401 

2022; Doerig et al., 2025), and with behavioral evidence also shows that language-402

Several limitations should be noted. First, the present paradigm used a single difficulty 405

Scene–object Stimulus Set 427 

To manipulate scene–object relationships under controlled conditions while preserving 428 

naturalistic structure, stimuli were rendered using the OmniGibson embodied-AI 429 

environment (Ge et al., 2024; Li et al., 2024), which supports fine-grained control over 430 

scene layout, viewpoint, and lighting. Twenty-five object identities were drawn from five 431 

high-level semantic categories—food, electronics, containers, office supplies, and home 432 

décor (five objects per category)—defined using metadata from the THINGSplus 433 

dataset (Stoinski et al., 2023). 434 

Each object was placed within a semantically appropriate scene (e.g., microwaves in 435 

kitchens, folders in workspaces, apples on tables) using OmniGibson’s affordance-436 

aware scripting tools, and placements were manually verified for ecological plausibility 437 

(Rajaei et al., 2026). To minimize trivial pixel-level regularities, camera viewpoint and 438 

lighting were varied across renders. Each object identity was, however, consistently 439 

paired with the same rendered scene image across repetitions in the intact condition. 440 

This design increased within-object consistency for time-resolved decoding but also 441 

entails that object identity is statistically associated with its background; within-condition 442 

decoding can therefore reflect a mixture of object- and background-related information. 443 

Our main inferences are based on contrasts that match object identity, object position, 444 

and low-level background statistics across conditions (intact vs. scrambled). All images 445 

were converted to grayscale to remove color-based saliency. Grayscale was a446

Phase-scrambled Images 449 

To disrupt global scene structure while preserving low-level image statistics, we 450 

generated phase-scrambled versions of the scene backgrounds. Each background 451 

image was transformed into the Fourier domain via FFT; the phase spectrum was 452 

randomized while the amplitude spectrum was preserved, and an inverse FFT yielded 453 

the scrambled image. Phase scrambling was applied to the background only; the target 454 

object was left intact and superimposed at the same location used in the intact 455 

condition. Intact and scrambled trials were thus matched on object identity, object 456 

position, and amplitude-derived background statistics, while differing in the presence of 457 

coherent global scene structure (Portilla and Simoncelli, 2000). 458 

(https://github.com/TetsuyaOdaka/texture-synthesis-portilla-simoncelli) 459 

Task and Procedure 460 

Participants performed an object categorization task in which target objects appeared 461 

briefly within either an intact scene or its phase-scrambled counterpart, with the same 462 

scene background. Trials from the two conditions were intermixed in random order. 463 

Each trial began with a central red fixation cross on a black background (1500 ms), 464 

followed by a 500-ms preview of the scene background alone. The target object was 465 

then embedded on the background for 80 ms, after which the background remained on 466

per condition. 468 

To minimize motor-related EEG activity time-locked to object onset, explicit responses 469 

were required only on intermittent probe trials (every one to five trials, randomly 470 

determined). On probe trials, participants reported the category of the object presented 471 

on the immediately preceding trial via a five-alternative keypress (one key per category) 472 

within a 1500-ms response window. Because participants did not know in advance 473 

which trials would be probed, object categorization remained task-relevant throughout. 474 

Stimulus presentation and response collection were controlled in MATLAB with the 475 

Psychophysics Toolbox (Brainard, 1997). 476 

Behavioral analysis 477 

Categorization performance was assessed on trials, on which participants reported the 478 

category of the object presented on the preceding trial. For each participant and 479 

condition (intact, scrambled), accuracy was defined as the number of correct responses 480 

divided by the number of trials on which a response was given (responded-only 481 

definition); trials with no response were excluded from the accuracy measure and 482 

quantified separately as the miss rate. Accuracy, response rate, and miss rate were 483 

compared between conditions across the 15 participants using two-tailed Wilcoxon 484 

signed-rank tests. 485

Time-resolved Decoding 503 

Decoding was performed within each participant using a symmetric sliding window of 11 504 

samples (44 ms at 250 Hz), stepped sample-by-sample from −700 to 1000 ms relative 505 

to object onset. Within each window, raw voltages from all retained channels and 506 

samples served as features. Because each object identity was consistently paired with 507 

a specific background, decoding results are summarized for the post-object interval (0– 508 

1 s); pre-object decoding is not reported (Chen et al., 2022). 509

Within-condition decoding . For each condition (intact, scrambled), pairwise two-class 510 

classification was carried out across all 300 unique pairs of the 25 objects. For each pair 511 

and each time window, features were dimensionality-reduced using principal component 512 

analysis (PCA), retaining components that explained 99% of the training set variance, 513 

and classified with linear discriminant analysis (LDA) using 10-fold cross-validation. 514 

Class sizes were approximately balanced (~30 trials per object after artifact rejection); 515 

when minor imbalances remained, all available trials per class were used. Accuracies 516 

were averaged across folds and across pairs to yield one decoding time course per 517 

condition. 518 

Cross-condition decoding. To assess context-invariant object information, the same 519 

pairwise pipeline was repeated with classifiers trained on trials from one condition and 520 

tested on trials from the other (intact →scrambled and scrambled →intact). Training and 521 

testing trials were strictly disjoint by condition, so no intact and scrambled trials were 522 

ever combined within a training set. 523 

Temporal generalization. To examine the temporal stability of object codes (King and 524 

Dehaene, 2014), we extended the within- and cross-condition pipelines to time-by-time 525 

decoding. Classifiers were trained at each time point and tested on all other time points, 526 

yielding a two-dimensional temporal generalization matrix for each direction (within-527 

intact, within-scrambled, intact →scrambled, scrambled →intact). 528
