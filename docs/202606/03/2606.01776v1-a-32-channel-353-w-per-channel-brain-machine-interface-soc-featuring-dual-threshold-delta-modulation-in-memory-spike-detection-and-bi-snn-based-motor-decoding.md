## 摘要
随着传感器通道数量的增加，系统在前端数据感知和植入设备数据处理方面面临挑战。本文提出一款基于65nm CMOS工艺的32通道全事件驱动iBMI SoC，旨在实现高效的神经形态信号处理流水线。该SoC集成了一个32通道双阈值增量调制（DTDM）前端阵列，可提供高达26倍的前端数据压缩；一个存内计算（IMC）尖峰检测器（SPD），用于高效的像素内尖峰检测；以及一个基于双极性LIF的脉冲神经网络（Bi-SNN）解码器，用于片上运动意图解码（MID）。该芯片每通道功耗仅为3.53 μW，解码R2约为0.62，每通道面积仅为0.034 mm²，为植入式设备提供了高效的信号记录、处理与解码能力。

## Abstract
With the scaling of sensor channel counts, systems confront challenges in frontend data sensing and on-implant data processing. This work presents a 32-channel fully event-based iBMI SoC in 65nm CMOS for an efficient neuromorphic signal processing pipeline. The SoC integrates a 32-channel dual-threshold delta modulation (DTDM) frontend array that provides up to 26x data compression at the frontend, an in-memory computing (IMC) spike detector (SPD) for efficient in-pixel spike detection, and a bipolar LIF-based spiking neural network (Bi-SNN) decoder for on-chip motor intention decoding (MID). Consuming only 3.53 μW per channel and achieving ~0.62 decoding R2 with a compact 0.034 mm2 per-channel area, the chip enables high-efficiency signal recording, processing, and decoding for implantable devices.

### 2. 论文提出的方法论
- **核心思想**：构建端到端的、基于事件的iBMI处理流水线，在像素级完成压缩和特征提取，仅把必要信息传递给轻量级脉冲神经网络解码器。
- **关键技术细节**
  - **双阈值增量调制前端（DTDM）**：
    - 模拟前端（AFE）采用斩波技术和钳位T型电容反馈网络，在降低1/f噪声的同时，以更小的总电容实现高增益（$M(2N+1)$，典型$M=30, N=1$）。
    - DTDM量化器使用自适应**粗阈值（$V_{th1}=VH_1-VL_1$）**和**细阈值（$V_{th2}=VH_2-VL_2$）**：信号变化超过粗阈值时生成事件并重置放大器；之后切换到细阈值提高跟踪保真度；静默期则使用粗阈值抑制噪声事件，实现26倍数据压缩。
  - **存内尖峰检测器（IMC-SPD）**：
    - 每个像素内集成8个处理ON/OFF事件的单元，使用eDRAM辅助的事件锁存器，以125 μs的时间片在1 ms滑动窗口内记录事件。
    - 通过共享检测线将eDRAM中存储的比特数转化为脉冲计数，并经过数字阈值比较实现片上尖峰检测，可降低前端的地址事件表示（AER）通信事件率最高达101.2倍，同时减少9.5倍的缓存需求。

    - 采用32-48-2层级结构：输入为32通道的发放模式帧（250 Hz采样），经过32个双极性LIF神经元、48个双极性LIF神经元后，由2个LIF输出层预测二维运动速度。
    - 神经元实现使用位移泄漏路径和减法器模拟指数膜电位衰减，支持正负两极性发放，利用事件稀疏性大幅削减MAC操作数（与ANN相比减少23.4倍），并可在空闲/推理模式间切换以节省功耗。
