## 摘要
冻结的脑电图编码器大量涌现；按模型微调的默认做法无法扩展。我们提出了Nimbus Personalizer：一个统一的合同，编码到贝叶斯头再到BrainState（可选仿射中间层），它部署在异构的冻结主干上，无需为每种架构搭建新的个性化堆栈。论点（系统层面）：贡献在于主干无关的API——而非作为机器学习新颖性的嵌入上的LDA——因此原始设备制造商只需集成一次便可更换主干。证据：相同的接口在五个经典主干EEGNet、Shallow、Deep、Conformer、ATCNet与四个运动想象数据集（18个单元）上运行，并在同一Personalizer下应用于一个基础编码器（REVE）。在嵌入容量存在的情况下，该头是一个廉价的默认中间点，相比热启动微调或PEFT，其适应墙钟时间成本低了几个数量级，同时恢复了大部分微调带来的准确率增益；仅在干净时校准在12/18个单元中成立。头的增益是支持证据，表明API在容量存在的地方是有用的。受试者级别的置信区间识别出最清晰的数据集，而在其他地方跨越零值。所有结果均为探索性（受试者级别自助法，无验证性检验）；何时升级适应的决策逻辑将在我们关于控制层的配套工作中讨论。

## Abstract
Frozen EEG encoders proliferate; per-model fine-tune defaults do not scale. We present Nimbus Personalizer: one contract encode to Bayesian head to BrainState (optional affine mid-tier) that sits on heterogeneous frozen trunks without a new personalization stack per architecture. Thesis (systems): the contribution is the trunk-agnostic API - not LDA-on-embeddings as an ML novelty - so OEMs integrate once and swap trunks. Evidence: the same surface runs on five classical trunks EEGNet, Shallow, Deep, Conformer, ATCNet x four MI datasets (18 cells) and on a foundation encoder (REVE) under the same Personalizer. Where embedding capacity exists, the head is a cheap default mid-point versus warm-start fine-tune or PEFT, costing orders of magnitude less adaptation wall time while recovering much of the fine-tune accuracy gain; calibration-only-when-clean holds in 12/18 cells. Head gains are supporting evidence that the API is useful where capacity exists. Subject-level confidence intervals identify the clearest dataset and span zero elsewhere. All results are exploratory (subject-level bootstrap, no confirmatory tests); the decision logic for when to escalate adaptation is addressed in our companion work on the control layer.

# 论文深度分析：通用脑机接口个性化——冻结脑电图主干与基础模型的统一API

## 1. 核心问题与整体含义

- **研究动机**：深度运动想象（MI）脑电图编码器已进入多元化时代（EEGNet、ShallowConvNet、DeepConvNet、Conformer、ATCNet 等），但会话偏移及受试者差异仍是主要失效模式。工业界惯常的逐模型、逐用户微调策略难以规模化。
- **核心问题**：能否设计一个与主干无关的个性化接口，使其部署于多种冻结的脑电主干之上而无需为每种架构重写个性化流程？该共享表面在何种条件下值得采用？
- **整体含义**：论文提出一种系统级解决方案——Nimbus Personalizer，主张以统一 API 作为部署默认路径，把全微调、参数高效微调（PEFT）等视为可选的、定价的逃生出口。

## 2. 方法论

- **核心思想**：通过一个三层抽象契约，将“编码→贝叶斯头→结构化脑状态”路径标准化，实现在异构冻结主干上的即插即用个性化。
- **关键技术细节**：
  - **编码器层**：第三方提供从原始试验到嵌入矩阵 $Z \in \mathbb{R}^{n \times d}$ 的冻结映射（可调用对象、sklearn 变换器或 PyTorch 方法）。
  - **贝叶斯头**：在标定嵌入上拟合，默认为线性判别分析（LDA），支持二次判别分析（QDA）和 Softmax 头，所有头共享同一接口。
  - **可选仿射中间层**（L2）：监督仿射映射作用于嵌入，再接贝叶斯头。
  - **输出合约**：每次预测返回结构化对象，包含主要意图、归一化不确定性及排序后的备选假设，而非裸标签。
- **分层个性化梯次**（同一 API 内部）：
  - **L0**：纯校准 Personalizer，仅使用标定数据拟合贝叶斯头，不消耗适应标签。
  - **L1**：流式 Personalizer，在已标定适应的流数据上在线更新头。
  - **L2**：仿射映射 + 贝叶斯头。
  - 全微调（L3）视为外部昂贵逃生出口，不在 API 内部但用于成本对比。
- **公式与度量**：各层级在共享效用函数下比较：
  $$U = \text{acc} - \lambda_w \cdot t_{\text{adapt}} - \mu_n \cdot (n_{\text{adapt}} / N_{\text{max}})$$
  其中 $t_{\text{adapt}}$ 为适应拟合时间（秒），$n_{\text{adapt}}$ 为消耗的标记流试验数，$\lambda_w$ 和 $\mu_n$ 为工程先验惩罚系数（默认 $\lambda_w=0.02$，$\mu_n=0.05$，$N_{\text{max}}=80$）。

## 3. 实验设计

- **数据集与场景**：
  - 使用 MOABB 平台的四个公开运动想象数据集：BNCI2014-004（9人，2类）、Zhou2016（4人，3类）、Kumar2024（18人，2类，在线含反馈）、Shin2017-A（9人，2类，适应会话短，标签预算固定为20）。
  - 每个受试者划分为：校准（首会话）、适应（中间会话）、评估（末会话）。
- **主干模型**：经典主干 {EEGNet，Shallow，Deep，Conformer，ATCNet}，以及基础主干 REVE（Hub REVE 预训练模型）。经典主干在 4 个数据集上组成 18 个主干×数据集单元（Kumar 仅含 EEGNet、Shallow、Conformer，3 单元）。
- **对比方法**：
  - 内部比较：L0（仅校准头）、L1（在线头）、L2（仿射+头）。
  - 外部对照：主干自带的 softmax（工厂解码器）、匹配的线性探针、热启动全微调（L3）、LoRA（对 EEGNet 和 REVE 作专设基准）、最后一层微调。
- **压力测试**：在适应和评估阶段对原始多通道脑电施加合成通道混合压力（向随机通道排列加偏置的凸混合，强度 0、0.25、0.5、0.75），以模拟可恢复分布变化。
- **评估指标**：准确率、适应拟合墙钟时间，以及上述基于惩罚的效用 $U$。

## 4. 资源与算力

- 文中提到在 CUDA 设备上进行适应拟合时间测量（如 EEGNet 的 L1 适应仅需数毫秒），并在 Modal L40S GPU 上对 REVE 成本烘培进行了基准测试。

## 5. 实验数量与充分性

- **实验量**：
  - 核心 18 个主干×数据集单元，涵盖 4 种应力强度（从无到 0.75），共计 72 组主要对比。
  - 主干无关性验证：5 个经典主干 + 1 个基础主干，覆盖不同数据集和应力条件。
  - 头族研究：LDA/QDA/Softmax 在 5 主干×4 数据集×严重应力共 20 单元上的对比，并进一步在另外三种合成应力（幅度缩放、通道丢弃、SNR 噪声）下复制，形成约 60 单元的分析。
  - 成本对比：每经典主干在严重应力下对比 L0/L1/线性探针/全微调；EEGNet 和 REVE 分别进行了更密集的基线（含 LoRA、末层微调）对比。
- **充分性与公正性**：
  - 实验设计遵循统一流水线，各主干统一频带（8–30 Hz）和时段，保证了比较公平性。
  - 合成压力仅涵盖通道混合，物理电极位移、临床信噪比等实际漂移尚未评估，且统计上多重比较未做校正，**样本量小**（如 Zhou 仅 4 人），故结论为探索性。
  - 尽管控制了工程先验惩罚系数并通过网格验证了其稳健性，但**未进行预注册确认性检验**，置信区间多跨零，统计效力有限。

## 6. 主要结论与发现

- **主干无关 API 可行性**：同一 Personalizer 接口可成功运行于五种经典主干和一种基础主干，无需按主干重设计。
- **头增益条件**：在存在嵌入容量且施加严重合成压力时，流式贝叶斯头（L1）相比纯校准（L0）可提升效用（如在 Zhou2016 上所有主干皆正收益），但并非所有主干×数据集均成立（12/18 单元显示校准仅干净时最优）。
- **成本优势**：L1/L2 的适应墙钟时间比全微调（L3）低数十倍，在大多数单元中能以极低成本恢复大部分微调带来的准确率增益；全微调应作为定价逃生出口。
- **严格序贯升级有限**：同时满足“干净→L0”和“严重→L2”的严格序贯模式仅出现在 5/18 单元，属于条件性而非普遍规律。
- **头家族表现**：LDA 是稳健的默认选择；QDA 的优势主要限于 BNCI 数据集上的通道混合应力，在其他应力和数据集上并未普遍胜出，因此头应保持可互换。

## 7. 优点

- **系统设计清晰**：以最小契约实现最大兼容，提供从编码器到结构化决策状态的统一管道，天然支持不确定性量化。
- **可扩展与低成本**：存储和推理开销极小（头仅需类均值和协方差），适应拟合时间为毫秒级，适合多用户部署。
- **实验扎实丰富**：在多个主干、多个数据集和多个合成应力水平上进行了交叉验证，并提供了头族选择、成本烘培等深入分析。
- **工程先验稳健性验证**：对惩罚系数进行了 5×5 网格检验，证明结论对权重不敏感。

## 8. 不足与局限

- **统计效力不足**：受试者样本量小（Zhou 仅 4 人），多数效用的置信区间包含零，且未进行多重比较校正；所有结果均为探索性。
- **应力覆盖单一**：主要压力测试仅采用了合成通道混合，未涵盖电极位移、信噪比下降等实际临床漂移；虽在附录中补充了其他合成应力，但依然属于人工设定。
- **基础模型性能上限低**：REVE 的绝对准确率低于从零训练的经典主干，论文仅论证其作为廉价中间层的价值，而非追求基础模型最优性能。
- **决策逻辑外置**：何时从 L0/L1 升级至更昂贵层级的动态决策机制不在本文范围，依赖配套控制层论文。
- **可复现性细节不全**：未提供超参数搜索空间、随机种子管理及完整算力消耗，部分代码实现未随文公开。
