## 摘要
利用基于非侵入式脑电图（EEG）的脑机接口（BCI）解码连续的三维（3D）运动想象（MI）仍具挑战，原因在于信号变异性和残余解码误差。卷积神经网络-长短期记忆（CNN-LSTM）等深度学习架构可捕捉空间与时间动态以进行连续运动学解码，但预测轨迹中仍存在系统性残差。我们提出一种两阶段解码框架，应用强化学习（RL）对CNN-LSTM解码器的输出进行残差运动学校正（CNN-LSTM-RL）。RL智能体离线训练，无需直接输入EEG，而是基于预测的运动学轨迹优化相对于目标轨迹的运动精度。解码性能采用皮尔逊相关系数（r）和沿x、y、z轴的均方根误差（RMSE）量化。与单独使用CNN-LSTM相比，CNN-LSTM-RL在2D环境中将平均相关系数从0.5076提升至0.7181（p=0.0005），在VR中从0.6420提升至0.7780（p=0.0059），相对增益分别为41.5%和21.2%。相应地，RMSE在2D中从0.0890降至0.0532（p<0.0001），在VR中从0.0714降至0.0441（p<0.0001），相对降低幅度分别为40.2%和38.2%。这些发现表明，该可扩展框架通过离线残差RL校正运动学误差，无需额外神经数据即可增强3D BCI MI解码，推动神经康复、假肢和虚拟交互的发展。

## Abstract
Decoding continuous three-dimensional (3D) motor imagery (MI) using non-invasive electroencephalography (EEG)-based brain--computer interfaces (BCIs) remains challenging due to signal variability and residual decoding errors. Deep learning architectures such as convolutional neural network--long short-term memory (CNN--LSTM) models can capture spatial and temporal dynamics for continuous kinematic decoding; however, systematic residual errors persist in predicted trajectories. We propose a two-stage decoding framework that applies reinforcement learning (RL) to perform residual kinematic correction on the outputs of a CNN--LSTM decoder (CNN--LSTM--RL). The RL agent is trained offline without direct EEG input and instead operates on predicted kinematic trajectories to optimize movement accuracy relative to target trajectories. Decoding performance was quantified using Pearson correlation coefficients ($r$) and Root Mean Square Errors (RMSE) along the $x, y$, and $z$ axes. Compared to CNN--LSTM applied alone, CNN--LSTM--RL improved the mean correlation from $0.5076$ to $0.7181$ ($p = 0.0005$) in 2D and from $0.6420$ to $0.7780$ ($p = 0.0059$) in VR, with relative gains of $41.5\%$ and $21.2\%$, respectively. Correspondingly, RMSE was reduced from $0.0890$ to $0.0532$ (2D, $p < 0.0001$) and from $0.0714$ to $0.0441$ (VR, $p < 0.0001$), representing relative reductions of $40.2\%$ and $38.2\%$. These findings demonstrate that this scalable framework enhances 3D BCI MI decoding by correcting kinematic errors via offline residual RL without extra neural data, advancing neurorehabilitation, prosthetics, and virtual interaction.

### 2. 论文提出的方法论
*   **核心思想**：采用**两阶段流水线**，将EEG解码与运动校正解耦。
    1.  **阶段一**：用传统CNN–LSTM解码EEG信号，得到初步的速度预测 $\mathbf{v}^{\text{BCI}}_t$。
    2.  **阶段二**：训练一个RL智能体，输入仅为解码器的输出、历史动作及时间步 $t$（不含原始EEG），输出残差速度 $\mathbf{v}^{\text{res}}_t$。最终施加于环境的速度为 $\mathbf{v}_t = \mathbf{v}^{\text{BCI}}_t + \mathbf{v}^{\text{res}}_t$。
*   **关键技术细节**：
    *   **问题形式化**：将残差控制建模为部分可观测马尔可夫决策过程（POMDP）。状态 $\mathbf{s}_t$ 包含隐藏的EEG、解码速度、目标速度等；观测 $\mathbf{o}_t = [\mathbf{v}^{\text{BCI}}_t, \mathbf{v}_{t-1}, t]$；动作 $\mathbf{a}_t = \mathbf{v}^{\text{res}}_t$；奖励 $r_t = -d(\mathbf{v}_t, \mathbf{v}^*_t)$，即校正后速度与目标速度欧氏距离的负值。
    *   **算法选择**：使用**软演员-评论家（SAC）** 算法进行离线训练。SAC在最大化期望回报的同时最大化策略熵，适应连续动作空间。训练时通过重参数化技巧保证策略可微。
    *   **维度自适应缩放**：对SAC输出的tanh变换后动作，在各坐标轴（x, y, z）上应用独立的可学习缩放因子，以应对不同维度解码误差的差异。相应的对数概率密度也进行了修正。
    *   **训练与推理**：RL智能体仅在**第一阶段数据收集的同一会话（Session 1）上离线训练**，然后**冻结**，直接应用于后续所有会话的测试，无需在线更新。

### 3. 实验设计
*   **数据集**：由10名健康右利手参与者完成。每人在10天的不同会话中，交替接受2D屏幕或沉浸式VR视觉反馈，执行上肢至4个三维目标的运动想象任务。每个会话含256次试验，总数据集包含25,600次试验。同步采集17导联EEG信号和手部3D运动学轨迹（x, y, z速度）。
*   **对比基准（Benchmark）**：
    *   **FDG (Fixed Decoder Generalisation)**：仅用Session 1训练的CNN–LSTM解码器，在Sessions 2-5上测试，代表了无校正的真实在线BCI表现。
    *   **SAT (Sequential Adaptive Training)**：在每个session上用前一session数据重新训练解码器，再测试下一个session。
    *   **WSR (Within-Session Reconstruction)**：在同一个session上训练并测试解码器，作为性能上界估算。
    *   **FRL (Fixed Reinforcement Learning)**：本文提出的方法，即固定CNN–LSTM解码器外加由Session 1训练的固定RL残差校正。
*   **评价指标**：解码轨迹与目标轨迹之间的**皮尔逊相关系数 (r)** 和**均方根误差 (RMSE)**，沿x、y、z轴分别计算并汇总。所有策略在同一测试集上比较，并分别按2D和VR反馈环境进行统计检验（配对t检验或Wilcoxon符号秩检验，经Holm-Bonferroni校正）。

### 4. 资源与算力

*   **训练时长**：

### 5. 实验数量与充分性
*   **实验组数**：论文对10名参与者在两种截然不同的视觉反馈环境（2D vs. VR）下，系统性地比较了所提FRL方法与三种典型解码策略（FDG、SAT、WSR）的性能，涵盖跨会话泛化能力。此外，还进行了基于5折交叉验证的RL超参数优化。
*   **充分性与公平性**：
    *   **充分性**：实验设计考虑了用户学习效应（FDG、FRL为固定模型）与模型更新效应（SAT），并以WSR作为理论上界，对比维度全面。统计检验严格，区分了参数与非参数测试，并修正了多重比较，效应量汇报完整（Cohen's d, Wilcoxon $r_z$）。

### 6. 论文的主要结论与发现
*   **性能大幅提升**：与基准CNN–LSTM解码器相比，加入RL残差校正后，2D环境下平均相关系数相对提升41.5%（0.5076→0.7181，p=0.0005），VR环境下提升21.2%（0.6420→0.7780，p=0.0059）。RMSE在2D环境相对降低40.2%（0.0890→0.0532，p<0.0001），VR环境降低38.2%（0.0714→0.0441，p<0.0001）。
*   **超越传统上界**：在RMSE指标上，FRL的表现**显著优于**会话内重训练上界WSR，表明RL校正能从运动学层面系统性地纠正解码偏差，突破了单纯CNN–LSTM的能力极限。
*   **跨会话稳定性强**：FRL在多个session上表现波动极小，显示出对EEG信号非平稳性和漂移的强鲁棒性。
*   **轴特异性优势**：校正对Y轴和Z轴的提升尤为显著，某些条件下相关系数可达0.98以上，误差接近零。

### 7. 优点
*   **巧妙的解耦设计**：将易受EEG噪声影响的RL决策与复杂的神经特征提取分离。RL仅处理干净的运动学输出，避免了直接输入高噪声EEG带来的不稳定。
*   **离线、即插即用的校正**：RL校正器离线训练，无需用户参与，训练后可直接附加在任何固定解码器后，易于部署。
*   **多目标联合优化**：通过Optuna超参数调优最大化轨迹形态相关性（皮尔逊系数），同时RL内部最小化点对点欧氏距离，实现了宏观形状与局部精度的协同提升。
*   **坚实的工程与统计基础**：汇报了详尽的超参数、算力消耗，并且统计检验分层严格，确保了结论的可信度。

### 8. 不足与局限
*   **任务场景简化**：实验仅包含在限定时间内对4个固定离散目标的到达任务，轨迹形态单一。框架在更复杂的自由运动轨迹或更多目标上的泛化性有待验证。
*   **对解码器性能依赖**：RL的残差探索围绕基线解码器输出进行，若解码器本身质量极差，校正空间有限。
*   **对时间信息的强依赖**：观测中包含归一化时间 $t$，这使得当前版本的RL策略与时间步锁死，难以直接应用于无时间提示的实时异步BCI场景。
*   **缺乏在线验证**：所有评估均为离线分析。真实的闭环在线校正效果及对用户学习过程的影响（如协同适应）尚未经过实验检验。
*   **超参数敏感**：论文指出残差动作的缩放因子对性能高度敏感，选择不当会导致提升有限或不稳定。
