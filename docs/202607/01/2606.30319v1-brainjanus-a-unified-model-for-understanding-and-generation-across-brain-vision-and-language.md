## 摘要
外部感觉刺激与内部神经活动之间的双向对应关系建模已成为神经科学的关键前沿。然而，现有方法主要将大脑编码和解码视为孤立任务，严重依赖单模态对齐和外部先验，而忽略了大脑作为多模态整合系统的内在本质。为了解决这些限制，我们提出了BrainJanus，这是第一个将大脑、视觉和语言整合在单一框架内的统一大脑模型。具体来说，我们引入了一个统一的大脑分词器（Unified Brain Tokenizer），将连续的神经动态量化为离散的token，这些token与共享全向空间（Omni space）中的视觉和语言表征对齐。在此基础上，我们采用了一种All-in-One自回归架构，利用下一个token预测实现无缝的任意到任意生成，包括图像到大脑和文本到大脑的编码，以及大脑到图像和大脑到文本的解码。大量实验表明，BrainJanus在多种基准测试中达到了卓越的性能。此外，我们的框架展示了零样本泛化能力，并保留了可解释的生物拓扑结构，凸显了其作为通用大脑建模范式的潜力。代码可在GitHub获取。

## Abstract
Modeling the bidirectional correspondence between external sensory stimuli and internal neural activity has emerged as a critical frontier in neuroscience. However, existing approaches predominantly treat brain encoding and decoding as isolated tasks, relying heavily on unimodal alignment and external priors while overlooking the brain's intrinsic nature as a multimodal integration system. To address these limitations, we propose BrainJanus, the first unified brain model that integrates brain, vision, and language within a single framework. Specifically, we introduce a Unified Brain Tokenizer to quantize continuous neural dynamics into discrete tokens aligned with visual and linguistic representations in a shared Omni space. Building on this, we utilize an All-in-One autoregressive architecture that leverages next-token prediction to enable seamless any-to-any generation, which encompasses image-to-brain and text-to-brain encoding, and brain-to-image and brain-to-text decoding. Extensive experiments demonstrate that BrainJanus achieves superior performance across diverse benchmarks. Furthermore, our framework exhibits zero-shot generalization and preserves interpretable biological topography, highlighting its potential as a general-purpose brain modeling paradigm. The code is available at \href{https://github.com/HaitaoWuTJU/BrainJanus}{GitHub}.

- **现有问题**：
  - **任务孤立**：已有的“脑编码”（预测脑信号）和“脑解码”（重建刺激）多数被视为独立任务，各自训练专用模型，未能共享跨任务的知识。
  - **模态单一**：大脑本质上是一个多模态整合系统，但现有方法过度依赖CLIP等单一视觉特征对齐，忽略脑信号中蕴含的丰富语义及语言信息。
  - **过度依赖外部先验**：为了弥补解码性能的不足，大量方法依赖超大规模预训练模型（如Stable Diffusion、LLaMA等），而非深度挖掘脑信号自身的信息。
- **核心目标**：构建一个能够统一处理脑编码与解码、并能跨“脑–视觉–语言”三大模态进行“任意到任意”生成的单一通用模型。

### 2. 论文提出的方法论
- **整体框架：BrainJanus**
  - **跨模态共享空间（Omni Space）**：将所有模态（脑信号 $B$、视觉 $V$、语言 $L$）映射到统一的离散化 token 嵌入空间 $\mathcal{O}$。
- **两大核心技术阶段**：
  - **阶段一：统一脑分 Tokenizer 预训练 (Unified Brain Tokenizer Pretraining)**
    - **目的**：将连续的高维脑信号（fMRI）转化为离散 token 序列，使其能与视觉、文本 token 共存于 Omni 空间。
    - **架构**：采用类 VQ-VAE 结构。编码器 $E$ 将输入 $x$ 映射到连续潜变量 $z_e(x)$，再通过最近邻查找在离散码本 $\mathcal{C} = \{e_k\}_{k=1}^{K}$ 中找到最匹配的向量 $z_q(x)$。
    - **核心损失函数**：
      $$ \mathcal{L} = \log p(x | z_q(x)) + \| \mathrm{sg}[z_e(x)] - e_k \|_2^2 + \beta \| z_e(x) - \mathrm{sg}[e_k] \|_2^2 $$
      其中，第一项为重建损失，第二项用于更新码本，第三项为承诺损失，$\mathrm{sg}(\cdot)$ 表示停止梯度算子。
  - **阶段二：全合一自回归建模 (All-in-One Autoregressive Modeling)**
    - **生成方式**：将多模态输入 token 化为（如 $b = f_B(x_B)$）后，按任意顺序拼接为前缀长度 $t$ 的序列 $z_{<t}$，利用单一大模型预测所有可能的下一个 token，并通过最小化负对数似然进行训练：
      $$ \mathcal{L}(\theta) = -\sum_{t=1}^{T} \log p_\theta(z_t | z_{<t}) $$
    - **能力范围**：这一单一的 next-token 预测机制可天然处理所有生成任务，包括：图像→脑(编码)、文本→脑(编码)、脑→图像(解码)、脑→文本(解码)，且能灵活交织多模态上下文（如 脑→文本→图像）。
- **基础模型**：自回归骨干网络采用 LoRA 高效微调 Janus-7B 的参数。

### 3. 实验设计
- **数据集与预处理**：
  - **主要数据**：Natural Scenes Dataset (NSD)，包含 8 名受试者观看 COCO 图像时的约 40 小时的 7T fMRI 扫描数据。
  - **数据划分**：选取完成全部实验的 4 名受试者（Sub-1, 2, 5, 7）为主要评价对象。每名受试者使用 9000 张独特图像用于训练，1000 张测试图像（每张重复 3 次以评估噪声）。
  - **文本真值增强**：指出原始的 COCO 描述过于简短，研究使用 Qwen3-VL 等模型生成了更详细、语义对齐度更高的图像描述作为新的训练和评测真值，并用 CLIP 分数验证了优越性。
- **对比基准与评估指标**：
  - **脑→文本 解码**：对比 MindEye2， UMBRAE， MindLLM。采用多项 NLP 指标（BLEU-1~4， METEOR， ROUGE， CIDEr 等）及语义对齐指标（CLIP-Text/Image， BERTScore）。
  - **脑→图像 解码**：对比 Takagi & Nishimoto， MindEye2， UMBRAE 等（多为扩散模型）。采用低层相似度指标（PixCorr， SSIM， AlexNet 层特征）和高层语义指标（Inception， CLIP， SwAV 等）。

- **消融实验**：
  - 探究 VQ-VAE 脑 Tokenizer 的压缩比和码本大小（Codebook Size）对重建恢复度（MSE， SSIM）和语义保持度（CLIP）的影响。
  - **零样本泛化实验**：测试仅使用 脑→文本 任务训练的模型，直接应用于 脑→图像 任务的生成能力。

### 4. 资源与算力
- **硬件**：实验在配有 **8 张 NVIDIA A100 (80GB)** GPU、96 vCPUs、1024GB 内存的服务器上完成。
- **软件与精度**：基于 Python， PyTorch， CUDA 12.8，采用 BFloat16 混合精度训练和 ZeRO Stage-2 优化策略。
- **训练细节**：
  - 脑分词器：训练 100 个周期（Epoch），batch size 256，学习率 $1e^{-4}$。
  - 自回归模型：在 Janus-7B 基础上，采用 LoRA 微调 15 个周期，峰值学习率 $2e^{-4}$，batch size 16。

### 5. 实验数量与充分性
- **实验规模**：涵盖 **4 个主要生成任务**（双向编解码）、与其他 **10 多个 SOTA 模型** 的详细对比、**跨所有 8 名受试者** 的性能分析、多组消融实验及零样本泛化测试。
- **评估客观性与公平性**：

### 6. 论文的主要结论与发现
- **性能领先**：在其定义的所有脑编解码任务（特别是在高质量描述解码上的 BERTScore 达 38.12，CLIP 分数 96.2%）上，BrainJanus 均能大幅超越以往的任务专用模型。
- **统一建模的优势**：仅仅通过一个自回归 Transformer，即可在统一框架下执行并完成四个方向的生成任务，证明了脑信号与自然信号（图文）在离散化 Omni 空间中可被高效整合。
- **脑信号的丰富性**：实验数据表明，直接从脑信号中解码图像比从对应文字描述中生成图像，能保留更多的低层视觉细节，揭示了 fMRI 信号包含比文字更丰富的像素级信息。
- **学到的表征具有生物可解释性**：生成的 fMRI 保留了真实的皮层拓扑结构（如视觉区域响应）和个体间变异性，并非仅学到了统计的表面规律，且拥有零样本跨任务迁移能力。

### 7. 优点
- **范式突破**：首次将脑编解码纳入一个跨模态（脑-视-语）的、基于 next-token 预测的“任意对任意”生成统一范式，架构简洁优美。
- **评价体系更严谨**：深刻揭露了现有脑编码指标（语义重建质量）存在的信息泄露脆弱性，并通过提出“噪声天花板”统计学基线，为领域建立了更坚实的评估参照。
- **技术路径清晰可靠**：使用非扩散的自回归方法、在冻结的视觉/文本 tokenizer 基础之上仅微调脑分词器和少量 LoRA 模块，极大降低了大规模全量训练的计算开销。

### 8. 不足与局限
- **数据模态限制**：实验目前仅针对视觉皮层区域的 fMRI 数据进行验证，能否推广到 EEG、MEG 等其他神经模态或全脑活动尚待探索。
- **生物忠实性与幻觉风险**：模型依赖强大的生成式先验（基座模型 Janus-7B），作者坦言存在潜在的“幻觉”风险，即生成的图像/文本可能偏向视觉上的美学质量或统计合理性而非完全严格对应被试当时感知的真实内容。
- **计算成本依然高昂**：虽然采用 LoRA 微调，但整个系统仍需在大规模 GPU 集群上运行，这限制了具有极端有限资源的神经科学实验室的广泛应用和即时校验。
