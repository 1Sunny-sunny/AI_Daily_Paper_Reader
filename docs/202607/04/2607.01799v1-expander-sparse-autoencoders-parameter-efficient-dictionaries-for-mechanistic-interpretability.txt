# Expander Sparse Autoencoders: Parameter-Efficient Dictionaries for Mechanistic Interpretability 

Rodrigo Mendoza-Smith * 1 

## Abstract 

Sparse autoencoders (SAEs) decompose internal activations of neural networks into sparse lin-ear combinations of learned features by fitting an overcomplete dictionary W ∈ Rm×n with 

m < n , and inferring a sparse code x ∈ Rn from 

h ≈ Wx . This inference problem closely resem-bles the canonical setup of compressed sensing, but dense decoders requires O(mn ) learned val-ues, which becomes costly at large feature counts. We introduce Expander SAEs : TopK SAEs whose decoder and tied encoder are supported on a left-d-regular expander mask with d ≪ m,learning only dn decoder values while keeping the sparse-coding problem (m, n, k ) fixed. The same structure reduces storage and turns the matching-pursuit correlation step W⊤r in OMP into an O(dn ) gather-and-reduce operation. Our experiments show that across Pythia-70M/160M, Qwen2.5-3B, and Llama-3.2-1B residual-stream activations, varying d traces a consistent storage– fidelity frontier, and that at the most compressed modern-LM setting, Qwen2.5-3B with d = 7 uses 

293 × fewer learned decoder values than the full dense decoder while retaining 84% of dense CE-loss recovered. Control experiments show that the improved storage–fidelity tradeoff is driven by sparse, diverse decoder support structure rather than by fewer learned decoder values, and that when sparse and dense decoders are compared at matched parameter count, part of the remain-ing gap comes from encoder amortisation. On the theoretical side, we show that expansion and column flatness are sufficient for identifiability of noiseless k-sparse codes, and we derive comple-mentary sufficient conditions under which OMP recovers the support exactly.

## 1. Introduction 

Mechanistic interpretability aims to reverse-engineer the in-ternal representations of a neural network by decomposing them into human-understandable components (Olah et al., 2020; Elhage et al., 2022). A central hypothesis is super-position which proposes that neural networks can represent more features than they have dimensions by exploiting the sparsity of feature activations (Elhage et al., 2022). Sparse autoencoders (SAEs) have emerged as a central tool for studying this phenomenon by decomposing the internal ac-tivations of neural networks into sparse linear combinations of interpretable features (Cunningham et al., 2023; Bricken et al., 2023; Gao et al., 2024; Templeton et al., 2024). SAEs are built by learning an encoder that maps an activation vector h ∈ Rm to sparse feature coefficients x ∈ Rn with 

n > m and a decoder which maps x back to activation space ˆh ∈ Rm. Recent work (Klindt et al., 2025; O’Neill et al., 2025) has emphasised that SAE inference is a sparse-recovery problem: given a trained decoder Wdec ∈ Rm×n

with m < n and an activation h ≈ Wdec x, recover a sparse latent code x ∈ Rn. This is the regime studied in com-pressed sensing (Candes and Tao, 2005; Donoho, 2006), where recovery is possible only because the latent vector is sparse and the measurement matrix has a suitable geometry. Indeed, prior work has shown that replacing the encoder with classic compressed-sensing algorithms like orthogo-nal matching pursuit (OMP) (Tropp and Gilbert, 2007) or gradient pursuit (Blumensath and Davies, 2008) can close the “amortisation gap” and improve reconstruction (Google DeepMind MI Team, 2024; O’Neill et al., 2025; Costa et al., 2025). A niche line of work within compressed sensing known as combinatorial compressed sensing studies the problem of sparse recovery when W is the adjacency matrix of a bipartite left d-regular expander graph (Berinde et al., 2008; Jafarpour et al., 2009; Indyk and Razenshteyn, 2010; Mendoza-Smith and Tanner, 2015). When d ≪ m, these matrices are binary, sparse, and highly structured so they are cheap to store and enable efficient recovery algorithms with provable guarantees (Xu and Hassibi, 2007; Berinde and Indyk, 2008; Mendoza-Smith and Tanner, 2015; 2017). Inspired by this line of work, we propose Expander SAEs :1

Related work. Our work is adjacent to a number of lines of research. In SAE architectures, Gated (Rajamanoharan et al., 2024a), JumpReLU (Rajamanoharan et al., 2024b), TopK (Gao et al., 2024), BatchTopK (Bussmann et al., 2024), Switch (Mudide et al., 2024), and Meta-SAEs (Buss-mann et al., 2025) all modify the encoder or sparsity mecha-nism while keeping the decoder dense. On the compressed-sensing for SAEs side, Google DeepMind MI Team (2024) first applied gradient pursuit to frozen dense decoders, O’Neill et al. Closest to our sparse construction, Ba (2018) studied deep sparse generative models with sparse-column measurement matrices.

2.1. Combinatorial compressed sensing 

Combinatorial compressed-sensing studies the problem of recovering a k-sparse vector x ∈ Rn from h = Mx where 

M ∈ { 0, 1}m×n is the adjacency matrix of a (k, ε, d )-expander graph. For completeness, we define this concept from first principles. For an integer n ∈ N we let [n] = {1, . . . , n }. A bipartite graph is a tuple G = ( L, R, E ) with node set L ∪ R and edge set E such that L ∩ R = ∅ and E ⊂ L × R. Such a graph is called imbalanced if |R| < |L| and is called 

left d-regular if each left vertex has exactly d neighbours. The adjacency matrix of such a graph can be represented as a binary matrix M ∈ { 0, 1}m×n such that m < n and 

∥Mj ∥0 = d for all j ∈ [n], where we use the notation 

Mj to refer to the j-th column of M. For S ⊆ [n], we let 

Γ( S) := {i ∈ [m] : ∃j ∈ S such that Mij = 1 }. In other words, the set Γ( S) ⊂ [m] is the set of neighbours of the node set S ⊂ [n]. The graph G is a (k, ε, d )-expander if it is bipartite, left d-regular and 

|Γ( S)| ≥ (1 − ε)d|S| (6) for every S ⊆ [n] with |S| ≤ k. The parameter ε ∈ (0 , 1) is the expansion parameter and quantifies how many collisions the nodes of S generate in [m]. That is, how often i ∈

Γ( S) has more than one neighbour. Although certifying that a graph is a (k, ε, d )-expander is NP-hard, it has been shown that for appropriate scaling of m, n, k, and d arandom binary matrix with d ≪ m ones per column is a 

(k, ε, d )-expander with high probability (Bah and Tanner, 2013). Moreover, it has been shown that when ε < 1/2,the adjacency matrix M ∈ { 0, 1}m×n of expander graphs satisfies a restricted isometry property in the ℓ1 norm (RIP-1) (Berinde et al., 2008): 

(1 − 2ε) d ∥x∥1 ≤ ∥ Mx ∥1 ≤ d ∥x∥1 (7) for all x ∈ Rn such that ∥x∥0 ≤ k. RIP-1 unlocks a re-covery toolkit with different computational and geometric guarantees from the usual dense RIP-2 setting, including greedy and peeling algorithms (Berinde and Indyk, 2008; Jafarpour et al., 2009; Indyk and Razenshteyn, 2010) and GPU-parallelisable iterative schemes (Mendoza-Smith and Tanner, 2015; 2017). Applied to the mechanistic inter-pretability setting, expansion guarantees that any small set of features activates a correspondingly large set of distinct activation coordinates, limiting the ambiguity with which a sparse activation pattern can be inverted.

## 5. Conclusion 

We introduced Expander SAEs, tied TopK sparse autoen-coders whose decoder columns are supported on a fixed left-

d-regular mask. The architecture keeps the sparse-coding dimensions (m, n, k ) fixed while reducing learned decoder values from mn to dn . We prove a weighted-expander iden-tifiability result for learned real-valued decoders under ex-pansion and column-flatness assumptions, and empirically show across Pythia, Qwen, and Llama residual streams that varying d traces a storage–fidelity frontier. At small budgets, iterative OMP recovers part of the encoder amortisation gap, while support-structure controls show that diverse sparse supports avoid clustered-mask dead-feature pathologies. We therefore view Expander SAEs not as a final replacement for dense SAEs, but as evidence that decoder support structure is an important and underexplored design axis. Promising next steps are larger-scale evaluations, low-rank corrections, learned sparse supports, and sharper data-dependent theory.

B.3. The encoder as amortised OMP

## G. Controls: full results 

This appendix reports the full per-control results for the support-structure controls summarised in Section 4.2, and explains why our primary controls fix (m, n, k ) rather than the learned-value count. Parameter-matched dense SAEs may seem like the natural baseline, but matching learned decoder values forces a dense SAE to use only n′ 

> dense

= dn/m features, which shifts δ = m/n , changes the dictionary overcompleteness, and sometimes makes the dictionary undercomplete or smaller than the target sparsity level. Sparse-recovery behaviour depends on the problem geometry, with compressed-sensing phase transitions described asymptotically at fixed δ = m/n and ρ = k/m (Donoho and Tanner, 2009). Our primary controls therefore preserve (m, n, k, d ) and change only the support structure, using clustered sparse masks and pruned-retuned dense supports. ## H. Full storage breakdown and empirical metrics 

This appendix collects the complete storage breakdown and per-architecture empirical metrics referenced from the practical summary in Section 4.3, and records the parameter choices for the Clustered-sparse and Pruned-retuned dense controls. The block count G = ⌊m/d ⌋ for the Clustered-sparse mask varies substantially across the three trained degrees. At m=512 ,the clustered mask yields G=73 disjoint blocks at d=7 with one row unused, G=10 blocks at d=50 with 12 rows unused, and G=2 blocks at d=200 with 112 rows unused. This collapse of support diversity at large d is intentional, since it lets us check whether support diversity helps avoid clustered-mask pathologies at large d or whether the size d of individual supports alone explains the observed parameter-efficiency frontier. We train Clustered-sparse at d ∈ { 7, 50 , 200 }, k ∈ { 16 , 32 , 64 , 128 }, three seeds, with the same 5000 -step cosine-schedule optimiser settings as Expander-SAE-d (Appendix A). Across the trained grid, Expander-SAE-d delivers substantial decoder-storage reductions and high CE-loss recovery in a single training pass. The controls clarify which gains come from column sparsity, support diversity, or a dense-derived support, and which require additional training.

## J. Decoder-cosine novelty 

This appendix reports decoder-cosine novelty as a complement to the activation-Jaccard novelty in Appendix D. A d-sparse decoder column has bounded cosine similarity to a dense column whose mass is spread evenly across coordinates, irrespective of whether the two represent the same feature, so the metric is biased downward at small d for purely geometric reasons. At d=m the bias vanishes and the cosine and Jaccard metrics agree.
