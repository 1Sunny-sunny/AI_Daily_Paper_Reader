## 摘要
通过表面肌电图（sEMG）进行手势识别是假肢控制的基础。在该领域，深度学习方法已成为金标准。然而，当前架构难以扩展；模型性能通常随着手势数量的增加而下降。性能下降与解码扩展手势集时统计复杂性的增加有关，并因现有方法主要依赖低延迟单模态卷积架构的局限性而加剧。卷积在局部操作，限制了模型捕捉长程序列模式的能力。单模态设置无法利用表征运动执行的协调信号中的互补信息，例如惯性和眼动追踪数据。这些局限性促使架构整合跨多模态生理序列的局部和全局特征。为弥补这一差距，本研究引入了EMG-CrossFormer，一种用于无缝多模态融合的端到端混合卷积Transformer。EMG-CrossFormer通过级联交叉注意力融合层，组合来自任意数量单模态编码器的表示，并使用可学习的手势查询解码融合表示。在四个NinaPro数据集（DB2、DB3、DB7和DB10）上对EMG-CrossFormer进行了评估，并针对六种最新模型，使用逐渐增加模态数量的设置进行了基准测试。仅使用sEMG时，EMG-CrossFormer在DB2、DB3、DB7和DB10上的平均准确率分别为72.33%、52.48%、79.16%和73.49%。加入惯性信号后，性能提升至90.66%、80.40%、92.79%和92.06%。这些结果表明，联合局部-全局特征建模改善了仅sEMG解码的效果，而多模态融合极大地增强了这一优势，突显了这两种设计原则对于复杂手势识别的价值。

## Abstract
Hand gesture recognition via surface electromyography (sEMG) is fundamental to prosthetic control. In this field, deep learning approaches have become the gold standard. However, current architectures struggle to scale; model performance typically decreases as the number of hand movements increases. Performance degradation is tied to the increased statistical complexity of decoding expanded gesture sets and compounded by the limitations of state-of-the-art methods, which primarily rely on low-latency unimodal convolutional architectures. Convolutions operate locally, limiting model's ability to capture long-range sequential patterns. Unimodal setups cannot leverage complementary information from coordinated signals characterizing movement execution, such as inertial and eye-tracking data. These limitations motivate architectures that integrate local and global features across multimodal physiological sequences. To bridge this gap, this study introduces EMG-CrossFormer, an end-to-end hybrid convolutional-transformer for seamless multimodal integration. EMG-CrossFormer combines representations from an arbitrary number of unimodal encoders through cascaded cross-attention fusion layers, and decodes the fused representations using learnable gesture queries. EMG-CrossFormer was evaluated on four NinaPro datasets (DB2, DB3, DB7, and DB10) and benchmarked against six state-of-the-art models using an increasing number of modalities. Using only sEMG, EMG-CrossFormer achieved mean accuracies of 72.33%, 52.48%, 79.16%, and 73.49% on DB2, DB3, DB7, and DB10, respectively. Incorporating inertial signals improved performance to 90.66%, 80.40%, 92.79%, and 92.06%. These results show that joint local-global feature modeling improves sEMG-only decoding and that multimodal fusion substantially amplifies this benefit, underscoring the value of both design principles for complex hand gesture recognition.

### 2. 论文提出的方法论
论文提出了 **EMG-CrossFormer**，一个端到端的混合卷积-Transformer模型。其核心思想是通过**交叉注意力机制**融合多模态特征，并利用**可学习的手势查询**进行解码。

**关键技术细节与流程如下：**

*   **单模态骨干网络（Unimodal Backbone）**：
    *   为每个输入模态（如 sEMG、ACC）设计独立的特征提取器，将信号 $ \mathbf{x}_{\text{sig}}^m \in \mathbb{R}^{C_m \times W_m} $ 映射为紧凑的 token 序列 $ \mathbf{z}_{\text{enc}}^m \in \mathbb{R}^{L_m \times d} $。
    *   研究实现了两种骨干网络变体：
        *   **EMG-CF 1D**：基于一维深度可分离卷积，参数量小，侧重提取通道特定的时间特征。
        *   **EMG-CF 2D**：基于二维多尺度卷积，将 sEMG 视为伪图像，提取时空特征，参数量更大。
    *   所有模态输出的 token 序列被投影到共享维度 $ d $。

*   **融合模块（融合层）**：
    *   模型通过**级联的非因果Transformer解码器层**进行定向融合。主模态（sEMG）的表示 $ \bar{\mathbf{z}}_{\text{enc}}^1 $ 作为初始融合状态 $ \mathbf{z}_{\text{fuse}}^{(1)} $。
    *   针对后续的辅助模态（如 $ m=2,3 $），注入正弦位置编码和可学习的**模态令牌（Mode token）** $ \mathbf{t}_{\text{mode}}^m $，以帮助模型区分和理解非sEMG信号。
    $$ \bar{\mathbf{z}}_{\text{enc}}^m = \mathbf{z}_{\text{enc}}^m + \mathbf{E}_{\text{pos}}^m + \mathbf{1}_{L_m} \mathbf{t}_{\text{mode}}^m \quad (m > 1) $$
    *   每个融合块内，先通过自注意力处理当前融合状态，再通过**交叉注意力**将辅助模态的信息融合进来：$ \mathbf{z}_{\text{fuse}}^{(m)} = \text{LN}(\hat{\mathbf{z}}^{(m)} + \text{FFN}(\hat{\mathbf{z}}^{(m)})) $，其中 $ \hat{\mathbf{z}}^{(m)} $ 包含了 $ \mathbf{z}_{\text{fuse}}^{(m-1)} $ 与 $ \bar{\mathbf{z}}_{\text{enc}}^m $ 的交叉注意力操作。

*   **基于查询的解码器（Query-based Decoder）**：
    *   该模块受 DETR 启发，使用一组**可学习的手势查询**作为输入。
    *   通过查询间的自注意力和查询与融合表示 $ \mathbf{z}_{\text{fuse}} $ 间的交叉注意力，同时对所有候选手势进行推理，捕捉它们之间的成对关系。

*   **训练损失函数**：
    *   采用组合损失 $ \mathcal{L}_{total} $ 进行深度监督，不仅关注最终分类，还优化嵌入空间的结构：
    $$ \mathcal{L}_{total} = \lambda_{ce} \mathcal{L}_{CE}(\mathbf{s}, y) + \lambda_{supcon} [\mathcal{L}_{SupCon}(\mathbf{z}_{\text{dec}}, y) + \sum \mathcal{L}_{SupCon}(\mathbf{z}_{\text{enc}}^i, y)] + \lambda_{aux} [\mathcal{L}_{CE}(\mathbf{s}_{\text{fuse}}, y) + \sum \mathcal{L}_{CE}(\mathbf{s}_{\text{enc}}^i, y)] + \lambda_{hand} \mathcal{L}_{L1}(\hat{\mathbf{h}}, \mathbf{h}) $$
    *   这包括了交叉熵（带标签平滑）、监督对比损失（$ \mathcal{L}_{SupCon} $）、辅助分类损失和手工特征（$ \mathbf{h} $）的L1回归损失。

### 6. 论文的主要结论与发现
*   **单模态时性能有限但最优**：仅用sEMG时，EMG-CrossFormer（特别是EMG-CF 2D变体）在所有数据集和窗口长度下均取得了最高准确率，但相比于随机森林等模型的提升幅度较为有限。

*   **模态选择有讲究**：加速度计信号对解码已执行手势极有帮助；而加入眼动追踪数据带来的额外增益较小，甚至有时会降低最佳变体（EMG-CF 2D）的准确率，但其增加的硬件复杂性不容忽视。

### 8. 不足与局限
*   **模型可解释性差**：作为一个复杂的Transformer架构，模型仍是“黑箱”，学习到的特征和跨模态交互的生理学意义尚不明确，这影响了其在临床上的可靠性和故障排查。
