## 摘要
基于功能磁共振成像（fMRI）的视觉解码旨在从测量到的大脑活动中恢复视觉信息，通常通过将fMRI响应映射到潜在视觉特征以用于下游解码任务。大多数现有方法学习从fMRI响应到由人工神经网络（ANN）提取的视觉特征的映射，然而ANN衍生的特征是否为脑解码提供了合适的目标仍不清楚。在本研究中，我们探索脉冲神经网络（SNN）衍生的视觉特征作为fMRI视觉解码的替代目标。我们将一个ANN基线模型与来自同一架构家族的四个SNN变体进行比较，这些变体在脉冲动态特性上有所不同。为了隔离目标特征的影响，所有模型都使用相同的L2正则化线性fMRI到特征解码器，仅改变用作回归目标的特征向量。与ANN基线相比，SNN衍生的特征表现出与fMRI响应更强的对齐性，并提高了视觉语义解码性能。例如，在GoD数据集上，SNN衍生的特征将特征预测误差从0.7707降低到0.0282，并将top-1语义解码准确率从0.1800提高到0.4400。消融研究进一步表明，脉冲神经动态特性和时间仿真步骤都对观察到的优势有所贡献。这些发现支持SNN衍生的特征作为有效的脑可解码视觉表征，并凸显目标特征设计是fMRI视觉解码的重要组成部分。

## Abstract
Functional magnetic resonance imaging (fMRI)-based visual decoding aims to recover visual information from measured brain activity, commonly by mapping fMRI responses into latent visual features for downstream decoding tasks. Most existing methods learn mappings from fMRI responses to visual features extracted by artificial neural networks (ANNs), yet it remains unclear whether ANN-derived features provide suitable targets for brain decoding. In this study, we investigate spiking neural network (SNN)-derived visual features as alternative targets for fMRI-based visual decoding. We compare an ANN baseline with four SNN variants from the same architectural family, which differ in their spiking dynamics. To isolate the effect of the target features, all models use the same L2-regularized linear fMRI-to-feature decoder, while only the feature vectors used as regression targets are varied. Compared with the ANN baseline, SNN-derived features exhibit stronger alignment with fMRI responses and improve visual semantic decoding performance. For instance, on the GoD dataset, SNN-derived features reduce feature-prediction error from 0.7707 to 0.0282 and improve top-1 semantic decoding accuracy from 0.1800 to 0.4400. Ablation results further indicate that both spiking neural dynamics and temporal simulation steps contribute to the observed advantage. These findings support SNN-derived features as effective brain-decodable visual representations and highlight target feature design as an important component of fMRI-based visual decoding.

- **研究问题**：当前基于 fMRI 的视觉语义解码普遍将大脑响应映射到人工神经网络（ANN）提取的视觉特征，但这些 ANN 特征是否真正适合作为脑解码目标是未知的。本研究旨在探索脉冲神经网络（SNN）衍生的视觉特征能否作为更优的替代目标，提升解码性能。
- **整体含义**：将解码的目标视觉表征从一个工程选择上升为科学假设，通过控制实验证明 SNN 表征具有更强的脑响应对齐性和可预测性，强调了目标特征设计在神经影像解码中的重要性。

### 2. 方法论

- **基本框架**：采用相同的 L2 正则化线性脊回归解码器，将预处理后的 fMRI 体素响应映射到不同视觉编码器的特征空间，仅变化目标特征类型（ANN vs. SNN），以隔离特征空间的影响。
- **ANN 特征**：使用标准 ResNet-18 作为基线，取其去除分类头后的倒数第二层连续激活向量 $\mathbf{z}^{\text{ANN}} = f_{\text{ANN}}(I)$。
- **SNN 特征**：采用与 ResNet-18 结构对等的 SEW-ResNet-18，但将激活单元替换为多种脉冲神经元。图像在 $T$ 个时间步上处理，生成时序特征 $f_{\text{SNN}}^t(I)$，最终通过时间平均聚合为固定长度表征：
  $$
  \mathbf{z}^{\text{SNN}} = \frac{1}{T}\sum_{t=1}^T f_{\text{SNN}}^t(I).
  $$
  脉冲神经元的通用动态形式为：
  $$
  H_t = \phi(V_{t-1}, X_t),\quad S_t = \Theta(H_t - V_{th}),\quad V_t = \psi(H_t, S_t),
  $$
  其中 $\phi$ 为充电函数，$\psi$ 为重置函数，$\Theta$ 为阶跃函数。变体包括 LIF、PSN、MPSN 和 BuSNN，分别对应经典膜整合、并行时间计算、记忆传播和爆发式脉冲编码。
- **解码映射**：对每个编码器 $m$，训练独立的线性映射 $\hat{\mathbf{z}}^{(m)}_i = \mathbf{x}_i^\top \mathbf{W}_m$，通过最小化 L2 正则化最小二乘得到最优权重大阵 $\mathbf{W}_m^*$，正则化强度 $\lambda$ 固定。
- **下游任务**：解码出的特征可直接送入分类头进行语义分类，或用于基于余弦相似度的 fMRI→图像检索，以及通过语义标签生成文本提示、利用预训练扩散模型进行语义引导的图像重建。

### 3. 实验设计

- **数据集**：
  - *Mini-Algonauts 2021*：用于体素级表征对齐分析（视觉皮层 ROI 的皮尔逊相关系数）。
  - *GoD (Generic Object Decoding)*：跨 5 名被试、包含 150 个训练类别和 50 个测试类别的 fMRI 数据，用于语义级对齐和解码。
  - *NSD (Natural Scenes Dataset)*：被试 1 的数据，选取一般 ROI，用于语义级对齐和解码的验证。
- **基准与对比方法**：
  - 基线：ResNet-18 提取的 ANN 特征。
  - SNN 变体：LIF、PSN、MPSN、BuSNN，均使用相同的 SEW-ResNet-18 骨干。
  - 解码器保持一致：线性脊回归，$\alpha=1000$；特征维度固定为 512。
- **评估协议**：
  - 体素对齐：模型特征与真实 fMRI 响应的 Pearson 相关系数（PCC）。
  - 语义对齐：解码特征与模型真实特征的均方误差（MSE）和平均特征相关系数（MFC）。
  - 语义解码：Top‑1 一致性（分类），检索的 Top‑K 准确率，以及语义引导重建的加权得分（Bo5‑SRC）。
- **公平性设计**：所有模型共享相同的数据划分、fMRI 输入和解码算法，差异仅来自预测的目标特征空间。

### 6. 主要结论与发现

- **体素级对齐更强**：在 Mini‑Algonauts 的 V1–V4 及 STS 区域，SNN 表征与 fMRI 实测值的 PCC 显著高于 ANN 基线。
- **语义对齐显著改善**：GoD 数据集上，SNN 特征（LIF/MPSN）将预测 MSE 从 0.7707 降至 0.0282；NSD 上 LIF 将 MSE 降至 0.0123。MFC 指标也表明部分 SNN 变体保留了更高的语义一致性。
- **解码性能提升**：
  - 分类：GoD 的 Top‑1 准确率从 ANN 的 0.1800 提升至 LIF 的 0.4400；NSD 上 PSN 达到 0.4206。
  - 检索：PSN 在 GoD 上的 Acc@1/3/5 分别达到 0.58/0.88/0.94，优于 ANN（0.44/0.70/0.82）。
  - 重建：PSN 在 GoD 和 NSD 上获得最高的 Bo5‑SRC 分数。
- **消融结果**：不同脉冲动态侧重不同维度（LIF 利于特征预测，PSN 利于语义检索与重建）；时间步 $T=4$ 在预测和语义一致上最优，过多或过少均不利。
- **总体结论**：SNN 衍生的脉冲特征是一种更易从 fMRI 信号中恢复的视觉表征，目标特征选择是提升解码性能的关键科学变量。

### 7. 优点

- **控制变量实验设计**：通过固定解码器和骨干架构，仅改变目标特征来源，干净地分离了表征空间对解码的影响。
- **多维度评估**：从体素对齐到语义对齐，再到分类、检索、重建，提供了全面的证据链。
- **SNN 变体覆盖广**：选取了多种代表性脉冲神经元模型，揭示了动态类型的调制作用，结论更具普适性。
- **清晰的科学叙述**：不将解码性能提升单纯归因于解码器改进，而是强调表征本身的适宜性，为神经影像解码提供了新视角。

### 8. 不足与局限

- **解码器复杂度有限**：仅使用线性脊回归，更强大或非线性解码器可能进一步影响 ANN 与 SNN 的相对表现，本文未探索。
- **对比对象局限**：ANN 仅采用 ResNet‑18，未比较 ViT、多模态模型等多样化架构，SNN 特征的广义优势至今尚未被充分证明。
- **重建为语义引导式**：非直接从 fMRI 重建像素，仅通过类别标签生成图像，评估的语义保真度受限于文本到图像模型，无法反映精细视觉细节的恢复能力。
- **算力与运行时未报告**：缺乏训练成本、推理时间等资源信息，不利于评估实际部署的可行性。
- **被试间一致性及统计检验不足**：仅在体素对齐中用了统计检验，多数结果未提供跨被试的显著性检验或置信区间。
