## 摘要
现有的大多数基于脑电的情感识别研究将情感解码表述为静态类别预测，然而由连续刺激引发的情感会随时间演变、累积、达到峰值强度，然后恢复。这促使了基于脑电的动态情感轨迹预测，即从序列脑电观测中估计连续的情感强度曲线。现有时间回归模型能捕捉粗略的强度趋势，但往往无法保持以峰值为中心的结构，导致峰值时间不准确和终端峰值偏差，即预测的最大值向试验的末尾偏移。为解决这一问题，我们提出了PeakFlow，一个基于峰值引导的由粗到细的框架，用于基于脑电的动态情感轨迹预测。PeakFlow首先通过脑电时间标记化和掩码时间建模学习粗略的情感流，然后应用轻量残差细化器进行峰值引导的有界校准。该细化器利用轨迹感知线索和以峰值为中心的目标，结合全局轨迹一致性、峰值区域强调、峰值概率定位、终端抑制和残差正则化。这种设计保留了全局情感趋势，同时纠正峰值错位、峰值值偏差和错误的终端预测。在SEED-VII上的留一被试实验表明，与强动态建模基线相比，PeakFlow在全局轨迹拟合和以峰值为中心的时间可靠性方面均有提升。在FIRMED上的辅助评估进一步表明其在稀疏的以峰值为中心的序数强度分析中的潜力。这些结果突显了峰值感知建模对于时间上忠实于脑电的动态情感预测的重要性。代码可在https://github.com/jukebox333/PeakFlow获取。

## Abstract
Most existing EEG-based emotion recognition studies formulate affective decoding as static category prediction, although emotions elicited by continuous stimulation evolve over time, accumulate, reach peak intensity, and then recover. This motivates EEG-based dynamic affective trajectory prediction, which estimates continuous affective intensity curves from sequential EEG observations. Existing temporal regression models can capture coarse intensity trends but often fail to preserve peak-centered structure, leading to inaccurate peak timing and terminal-peak bias, where the predicted maximum is shifted toward the end of a trial. To address this issue, we propose PeakFlow, a peak-guided coarse-to-refined framework for EEG-based dynamic affective trajectory prediction. PeakFlow first learns a coarse affective flow through EEG temporal tokenization and masked temporal modeling, then applies a lightweight residual refiner for peak-guided bounded calibration. The refiner uses trajectory-aware cues and a peak-centered objective combining global trajectory consistency, peak-zone emphasis, peak-probability localization, terminal suppression, and residual regularization. This design preserves the global affective trend while correcting peak misalignment, peak-value deviation, and false-terminal predictions. Leave-one-subject-out experiments on SEED-VII show that PeakFlow improves both global trajectory fitting and peak-centered temporal reliability over strong dynamic modeling baselines. Auxiliary evaluation on FIRMED further suggests its potential for sparse peak-centered ordinal intensity analysis. These results highlight the importance of peak-aware modeling for temporally faithful EEG-based dynamic emotion prediction. Code is available at https://github.com/jukebox333/PeakFlow.

## 2. 论文提出的方法论
### 2.1 整体框架（由粗到细三阶段）
1. **阶段 I：EEG 时间标记化（Stage I）**  
   - 使用 VQ‑VAE 风格的编‑解码器，将连续的 EEG 特征序列映射到离散的码本向量 $z_{i,t}$，得到离散 EEG 时间状态序列。  
   - 损失函数包括重构损失 $L_{\text{rec}}$ 和向量量化损失 $L_{\text{vq}}$。  
   - 训练后冻结码本和编码器，为阶段 II 提供辅助监督信号。

2. **阶段 II：掩码动态情感流建模（Stage II）**  
   - 输入原始 EEG 特征，经线性投影和随机掩码后，由 Transformer 编码器建模全局时间依赖。  
   - 双头输出：一个回归头预测粗略的情感强度 $\hat{y}^{\text{base}}$，一个分类头预测 VQ 码本索引 $\ell_{i,t}$。  
   - 损失为 $L_{\text{base}} = L_{\text{reg}} + \lambda_{\text{code}} L_{\text{code}}$，其中 $L_{\text{reg}}$ 为 MSE，$L_{\text{code}}$ 为交叉熵。  
   - 冻结阶段 I 的标记器，仅训练阶段 II 的 Transformer，获得全局粗略轨迹。

3. **阶段 III：峰值引导的有界残差校准（Stage III）**  
   - 输入为阶段 II 的粗轨迹 $\hat{y}^{\text{base}}$ 以及由此构建的“轨迹感知线索” $\mathbf{h}_{i,t}$，包括：粗强度、归一化时间位置、距终端的距离、局部强度变化 $\Delta \hat{y}^{\text{base}}$。  
   - 轻量**时间卷积网络（TCN）**处理这些线索，输出两个量：  
     * 原始残差分数 $\rho_i$，经 tanh 缩放和幅度系数 $\alpha$ 控制；  
     * 峰值概率序列 $q^{\text{peak}} = \sigma(a_i)$，作为软门控调制度 $g_i = 1 + \eta q^{\text{peak}}$。  
   - 最终有界残差：$r^{\text{corr}} = \alpha g_i \odot \tanh(\rho_i)$，粗轨迹加上该残差后裁剪至 $[0,1]$ 得到精炼轨迹 $\hat{y}^{\text{PF}}$。  
   - **峰值中心的校准目标**：  
     * $L_{\text{traj}}$：全局 MSE + 一阶时序一致项；  
     * $L_{\text{peak}}$：峰值带加权拟合 + 峰值概率二分类损失；  
     * $L_{\text{end}}$：对终端区域的过估计进行二次惩罚；  
     * $L_{\text{res}}$：限制残差幅度的正则项。  
   - 训练时仅更新阶段 III 的 TCN 细化器，前两阶段全部冻结。

### 2.2 关键技术细节
- **掩码建模**：在阶段 II 随机遮掩部分时间位置，使用可学习的掩码令牌，促使 Transformer 学习鲁棒的时间关联。  
- **离散 EEG 状态**：码本大小为 64，通过 t‑SNE 和强度富集分析显示，不同的码字与低、中、高情感强度区间存在偏好性关联。  
- **有界残差形式**：避免精细化过程中破坏全局趋势，残差由 $\tanh$ 限制在 $[-\alpha,\alpha]$，再经裁剪保证最终轨迹在 $[0,1]$。  
- **新评价指标**：除 MSE、MAE、PCC、R² 外，引入归一化峰值时间误差、峰值值误差和假终端峰值率 FTR，用于衡量峰值中心的时间可靠性。

## 6. 论文的主要结论与发现
- **终端峰值偏差普遍存在**：掩码时序模型在轨迹预测时倾向于将峰值推向试次末端，导致假终端峰值率高达 62.56%（EEGDancer 基线）。

- **跨被试、跨情绪稳定**：在多数被试和情绪类别上，PeakFlow 均表现出更低的峰值时间误差和假终端峰值率。  
- **稀疏标注场景的兼容性**：在 FIRMED 上，PeakFlow 的序数一致性（Macro‑F1 0.761，QWK 0.760）远高于 EEGDancer，表明峰值引导的精炼对稀疏峰值标注也有益。

## 7. 优点
- **解耦设计**：把全局轨迹学习和局部峰值校准分离，既保持趋势准确性，又针对性修正峰值问题，结构清晰且可解释。  
- **有界残差与峰值门控**：通过 tanh 限制残差幅度、峰值概率调制强度，避免过度修正，保证全局轨迹不被破坏。  
- **新颖的峰值中心评价体系**：首次在 EEG 动态情感预测中引入归一化峰值时间误差、峰值值误差和假终端峰值率，弥补了传统点式指标的不足。  
- **全面的实验验证**：不仅包括多种基底对比，还进行了详尽的消融、超参数敏感性和定性可视化，论证充分。  
- **训练稳定性**：分三阶段冻结训练，降低了联合优化的难度，并利用离散标记辅助监督提升表示学习质量。

## 8. 不足与局限
- **数据集覆盖面有限**：主要实验仅基于 SEED‑VII，虽在 FIRMED 上做了辅助验证，但仍需更多带稠密时序标注的数据集来验证泛化性。  
- **离线预测设定**：当前方法依赖全试次时间上下文，不支持流式在线峰值预测，若要用于实时系统，需拓展为因果性、递推式模型。  
- **单峰假设**：模型目前仅关注试次内最强的单一峰值，未建模多峰事件的起始、持续和消退，无法还原完整的情感动态阶段。  
- **模态单一**：仅使用 EEG 特征，未融合面部表情、皮电、心电等多模态信号，可能遗漏其他模态中反映情感峰值的互补信息。  
- **算力与效率未明确**：未报告计算成本和推理时间，难以评估实际部署的可行性。
