## 摘要
人在回路强化学习已成为训练、微调并使机器人行为与用户偏好对齐的流行方法。本文探索了利用功能性近红外光谱（fNIRS）采集的脑信号在仿真中调节机器人学习的可行性。我们比较了在被动（观察式）与主动（演示式）交互任务上训练的智能体，并测试了多种利用神经信号增强强化学习算法的方法，侧重于参数增强而非替换。我们进一步研究了模型粒度和噪声如何影响智能体学习。结果表明，该框架是有效的：在增强轨迹优先级和状态-动作Q值时，神经信号改善了学习。此外，该框架能成功地从离线数据中学习，为实时脑机接口设置不切实际或仅有限数据可用的环境提供了一种实用的替代方案。

## Abstract
Human-in-the-loop Reinforcement Learning has become a popular approach to training, finetuning, and aligning robot behavior with user preferences. Our paper explores the feasibility of using brain signals via functional near-infrared spectroscopy (fNIRS) to modulate robot learning in simulation. We compare agents trained on passive (observational) versus active (demonstrative) interaction tasks, and test multiple methods for enhancing the RL algorithm with the neural signal, focusing on parameter augmentation rather than replacement. We further examine how model granularity and noise affect agent learning. Our results show that this framework is effective: the neural signal improves learning when augmenting trajectory priorities and state-action q-values. Additionally, the framework learns successfully from offline data, offering a practical alternative for settings where real-time BCI setups are impractical or only limited data is available.

### 2. 方法论  
- **整体框架 NEURO‑LOOP**  
  - 用户观察或操控智能体，同步记录 fNIRS 数据（来自前额叶皮层）。  
  - 对神经信号进行预处理，通过**性能模型**（多层感知器 MLP）将特征向量 $f_t$ 解码为反映智能体动作最优性的标签或连续值 $\hat{y}_t$。  
  - 解码后的置信度 $c_t$（或回归误差补数）用于**增强 RL 算法的关键参数**，而不是直接替换奖励函数。  

- **性能模型粒度**  
  - **二分类** $g_b \in \{0,1\}$（最优/非最优）  
  - **三分类** $g_d \in \{0,1,2\}$（最优/次优/非最优）  
  - **回归** $g_e \in \mathbb{R}$（预测动作误差）  
  根据粒度输出不同的后处理形式，将原始模型输出与待增强参数整合：  
  分类器输出：$n_t = \big( x_t + c_t \cdot \mu_X[\hat{y}_t] \big) \cdot \beta$  
  回归器输出：$n_t = \big( x_t + c_t \cdot \mu_X[0] \big) \cdot \beta$  
  其中 $x_t$ 为原始 RL 参数（奖励、Q 值或优先级），$\mu_X$ 为各最优性类别的期望参数值，$\beta$ 为缩放因子。

- **增强技术**  
  基于 **DDPG‑HER + 优先经验回放** 的基线算法，对比四种增强方式：  
  - **优先增强（Prioritization）**：使用 $n_t$ 修改经验回放的轨迹采样优先级。  
  - **奖励增强（Reward Aug）**：用 $n_t$ 调制环境原始奖励。  
  - **Q 值增强（Q‑Aug）**：用 $n_t$ 调制状态‑动作对的 Q 值。  
  - **全增强（All）**：同时应用上述三种增强。  
  基线（Baseline）仅注入数据但不进行神经增强。

- **离线微调机制**  
  在智能体成功率到达预定义检查点（如 0.2）时，将预先录制的 MDP 元组注入经验池，供智能体进一步学习，数据用尽后恢复在线学习。主要检查早期注入效果。

- **噪声实验**  
  向性能模型输出注入合成噪声，以验证增益确实来自神经信号本身：  
  - 分类器以概率 $\tau$ 翻转输出  
  - 回归器输出加上 $(0,1)$ 的随机偏移。

### 6. 主要结论与发现  
- **神经信号有效性**：fNIRS 解码信号能够成功提升机器人学习，尤其当用于增强 **Q 值** 和**轨迹优先级**时效果显著，而直接增强奖励未显示明显增益。  
- **增强方法排序**：Q‑Aug ≈ All > Prioritization > Reward Aug ≈ Baseline。  
- **交互任务影响**：被动任务最快学习（数据分布均衡），主动任务较慢（噪声多），混合数据速度居中。  
- **模型粒度**：  
  - 被动：回归（连续）在 Q‑Aug 中表现最佳；二分类和回归在其他条件下相近；三分类整体落后。  
  - 主动：二分类和三分类优于回归；三分类与二分类表现相近。  
  - 混合：二分类最优，三分类和回归仅在部分增强中略优于基线。  
  - 三分类效果较差主要因分类准确率低（F1 = 0.47‑0.50，远低于二分类 0.67‑0.72）。  
- **噪声影响**：在 Q‑Aug 上增加噪声会使增益下降，回归至基线水平；而在 Reward Aug（已无增益）上噪声无影响，证明增益源于真实神经信号。  
- **微调时机**：早期注入（成功率阈值 0.2）效果最佳，更晚注入效果减退。

### 7. 优点  
- **离线可用性**：框架不依赖实时 BCI 系统，可利用预录数据训练，大幅降低部署门槛，适合资源受限或无实时采集条件的场景。  
- **多维增强与全面评测**：对比了多种 RL 参数增强策略，并系统评估了模型粒度、交互类型、噪声的影响，分析细致。  
- **内在反馈范式**：将 fNIRS 信号作为隐式反馈，为运动/言语障碍人群提供了新的 HITL 可能性，同时避免了用户认知过载。  
- **结合 DDPG‑HER 与优先级回放**，在标准机器人操控任务上验证，实验设置贴近实用。
