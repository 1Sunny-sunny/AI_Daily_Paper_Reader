ABSTRACT 

Asynchronous EEG event detection supports practical brain-computer interfaces by identifying event classes and temporal boundaries directly from continuous recordings without predefined event boundaries at inference time. The primary challenge lies in extracting event-related patterns embedded in ongoing back-ground activity. To address this, we propose NeuroDETR , a discrete spatiotem-poral multiscale framework that combines structured tokenization with event-aware feature refinement. Multiscale temporal codebooks capture brief responses and sustained dynamics, while Spatial-Pyramid VQ hierarchically encodes spa-tial structure across EEG channels. These complementary representations form a compact event memory for jointly classifying events and estimating their onsets and offsets. Before tokenization, we apply FOCAL, an event-aware sparse atten-tion module that uses predicted event presence to guide temporal feature refine-ment and spatial aggregation, emphasizing likely event periods while preserving context across the recording. Experiments on eight EEG datasets that span diverse paradigms demonstrate state-of-the-art performance. These findings provide a ba-sis for the development of BCI systems that recognize meaningful neural activity during continuous interaction and monitoring. 

1 INTRODUCTION 

Brain–computer interfaces (BCIs) establish direct communication pathways between neural activ-ity and external devices by translating neural signals into actionable information for device control, human–computer interaction, and clinical decision-making [1, 2]. Achieving this goal depends on reliably identifying behaviorally or physiologically meaningful neural events in continuous elec-troencephalographic (EEG) recordings. Asynchronous EEG decoding addresses this challenge by jointly identifying event categories and localizing their onset and offset within the ongoing signal. As shown in Figure 1a (i), a straightforward approach to asynchronous decoding applies sliding-window classifiers to continuous EEG, assigning each window an event or background label [3, 4]. However, the mismatch between fixed-length windows and variable event durations and boundaries can fragment detections or merge adjacent events, making performance sensitive to window settings and post-processing rules [5]. The effectiveness of this approach depends on how well the EEG features supplied to the decoder preserve event-specific information. Existing methods use cross-attention to aggregate information from long feature sequences into a fixed set of continuous latent tokens, but do not explicitly organize event cues across temporal scales and spatial regions [6, 7]. Across EEG datasets and paradigms, events vary in duration, occurrence frequency, and spatial distribution. Their responses are also em-bedded in ongoing background activity, requiring feature aggregation to preserve weak or transient event cues. In this study, we propose NeuroDETR, a multiscale discrete spatiotemporal framework for asyn-chronous EEG event detection. NeuroDETR uses vector quantization to organize continuous fea-tures into reusable learned codewords. To accommodate differences across datasets and paradigms, multiscale temporal VQ represents both brief responses and sustained dynamics, while Spatial-Pyramid VQ encodes channel information at complementary spatial levels. These representations form a compact event memory that supports joint localization and classification within a unified detection architecture. To guide this representation toward event-related activity, we introduce FOCAL, an event-aware sparse attention module. FOCAL uses predicted event presence to guide temporal feature refinement before quantization and temporal pooling within the spatial branch, while retaining cross-window context. This shared event guidance connects the temporal and spatial representations, supplying the DETR decoder with event-aware multiscale information for predicting event classes and boundaries. We evaluate NeuroDETR on eight EEG datasets spanning P300, motor imagery, motor execution, speech, and seizure detection. NeuroDETR achieves the highest event-level F1 among the evaluated methods on all eight datasets, demonstrating its effectiveness across EEG paradigms with diverse event characteristics. By improving neural event detection in continuous EEG, NeuroDETR sup-ports the development of practical BCI applications. Our main contributions are summarized as follows: • We propose NeuroDETR , which jointly predicts event classes, onsets, and offsets from continuous EEG without predefined event boundaries. At its core, vector quantization or-ganizes EEG features into a compact event memory, with multiscale temporal and hierar-chical spatial codebooks accommodating diverse event characteristics across paradigms. • We introduce FOCAL , an event-aware sparse attention module that concentrates local fea-ture refinement on likely event periods while preserving cross-window context. By sharing event-presence estimates with spatial aggregation, FOCAL directs both temporal and spa-tial tokenization toward event-relevant information. • Experiments on eight EEG datasets spanning diverse paradigms demonstrate state-of-the-art performance. Ablation studies support the complementary contributions of spatiotem-poral tokenization and event-aware refinement. 22 RELATED WORK 

2.1 ASYNCHRONOUS EEG D ECODING 

Asynchronous EEG decoding identifies events in continuous signals without known onset times. Early systems estimate control states or classify sliding windows, using probabilistic aggrega-tion or temporal decision rules [8, 4, 3]. Recovering event instances typically requires temporal post-processing. DOSED and EventNet directly localize events through single-stage detection and center–duration regression, respectively [9, 5]. DETRtime uses event queries and bipartite matching for set prediction [10], while a frozen foundation model has also been adapted for dense EEG seg-mentation [11]. DANCE combines Perceiver-style resampling [6] with query decoding to predict event classes and temporal boundaries [7]. 2.2 DISCRETE SPATIOTEMPORAL EEG R EPRESENTATIONS 

Discrete EEG tokens support EEG-to-text translation in DeWave [12] and pretraining or multimodal decoding in LaBraM, VQ-MTM, and NeuroLM [13, 14, 15]. Recent tokenizers learn single-channel time–frequency motifs and decoupled temporal–spectral vocabularies [16, 17]. Related approaches model EEG through electrode graphs, multiscale temporal filters, and regional and global spatial representations [18, 19], or use sparse attention for motor imagery decoding [20, 21]. THD-BAR constructs hierarchical spatial tokens for autoregressive learning [22], while NeuroRVQ combines multiscale temporal convolutions with residual vector quantization for biosignal reconstruction and foundation-model training [23]. NeuroDETR uses shared event-presence estimates to route local temporal attention and weight tem-poral pooling of regional features before multiscale temporal and hierarchical spatial quantization. The resulting memory supports event-set prediction.

Temporal fusion and gated spatial integration. Starting from Nq learnable queries initialized with sinusoidal embeddings, temporal fusion alternates global self-attention, sliding-window cross-attention (SWA), and feed-forward refinement: 

Q ← Q + MHSA(LN( Q)) , Q ← Q + SWA(LN( Q), Mt), Q ← Q + FFN(LN( Q)) . (17) Cross-attention spans are centered proportionally along the memory. The normalized output

Set-based event decoding. A four-layer, four-head DETR decoder [24] applies Ne event queries to the fused memory, projected from 128 to 256 dimensions and augmented with sinusoidal embed-dings. Query features oj predict classes and boundaries: 

bpj = softmax(Cls( oj )) , ˆsj = σ(Start( oj )) , ˆej = σ(End( oj )) . (19) We discard queries whose highest-probability class is background and multiply the remaining boundaries by W . Here, Nq controls memory length and Ne the candidate-event budget. 3.6 TRAINING OBJECTIVES 

Detection Loss. Hungarian matching [28] assigns ground-truth events to predicted queries using a matching cost based on class probabilities and temporal IoU. The classification loss Lcls applies cross-entropy supervision to all queries, assigning event labels to matched queries and the back-ground label to unmatched queries. For matched queries, endpoint regression loss Lℓ1 penalizes absolute onset and offset errors. Temporal generalized IoU loss LGIoU [29] complements endpoint regression by supervising interval overlap and relative position. The detection objective is 

Ldet = λℓ1 Lℓ1 + λcls Lcls + λgiou LGIoU . (20) 

Auxiliary Loss. We complement set prediction with full-resolution boundary supervision, dense classification, and prediction consistency. A boundary head applied to the backbone features H

predicts class-agnostic onset and offset heatmaps. The targets are pointwise maxima of Gaussians centered at annotated boundaries. Sigmoid focal loss Lbnd supervises these predictions while down-weighting easy non-boundary positions. For dense classification and prediction consistency, we follow the auxiliary-supervision strategy of DANCE [7]. Dense cross-entropy loss Ldense supervises class predictions at each position of the fused memory Z. To construct the set-derived predictions, we accumulate query class probabilities over their discretized predicted intervals and normalize the accumulated scores at each covered grid position. Uncovered positions are assigned zero vectors. We apply componentwise clamping to both predictions without renormalization and compute a KL-style regularizer Lcons . At covered grid positions, this term encourages agreement between dense and set-derived predictions. At uncovered positions, the clamped zero vectors induce an entropy regularization effect on the dense predictions. The complete event-supervision objective is 

Levent = Ldet + λbnd Lbnd + λdense Ldense + λcons Lcons . (21) More details on the training objectives are provided in the appendix. 64 EXPERIMENTS 

4.1 DATASETS 

We evaluate our method on eight EEG datasets spanning five task domains with diverse tem-poral characteristics. These datasets cover densely occurring and potentially overlapping P300 events (BI2013a [30] and BI2014b [31]), fine-grained high-frequency speech-related events (Broder-ick [32, 33]), sparse and long-duration motor imagery events (BNCI2014 [34] and BNCI2015 [35]), motor execution events (BNCI2020 [36] and HDOP [37]), and rare epileptic seizures with durations ranging from several seconds to several minutes (TUSZ (v2.0.6) [38]). This diversity enables a com-prehensive evaluation of whether a unified set-prediction framework can generalize across variations in event frequency, duration, category complexity, and recording configurations. Further details on the datasets are provided in Appendix D. 4.2 BASELINES 

We compare NeuroDETR with four dense temporal detection frameworks, EventNet [5], Ac-tionFormer [39], DyFADet [40], and DOSED [9], and the query-based set-prediction framework DANCE [7]. We also include a dataset-aware Random event generator as a lower bound. For each learned baseline, we adapt the input representation, classification head, and temporal decoding pro-cedure to EEG event detection while retaining its original detection mechanism. All methods use the same data splits and event-level evaluation protocol. For all dense detectors, we apply a confi-dence threshold of 0.05 and non-maximum suppression (NMS) with a temporal IoU threshold of 0.5, retaining at most Ne predictions per window. Further implementation details appear in Appendix E. 4.3 EVALUATION METRICS

4.5 ABLATION STUDIES 

We evaluate the contributions of NeuroDETR’s core components and examine the relationship be-tween spatiotemporal quantization and event guidance. 

Ablation of Core Components. We compare five variants with the full model. M1 and M2 replace the temporal and spatial quantized representations with continuous features, respectively. M3 retains only the finest temporal scale while preserving the memory grid and fusion output length. M4 retains only fine electrode clusters, removing higher spatial levels and cross-level residual connections. M5 removes FOCAL and event-presence supervision, feeds backbone features directly into temporal tokenization, and replaces event-guided spatial pooling with adaptive average pooling. Table 2 shows that the full model outperforms all five variants in event F1 on each of the eight datasets. The largest drops under M5 occur on BNCI2020, HDOP, and TUSZ, reaching 13.18, 6.14, and 17.08 points, respectively. These datasets have event occupancies of 27.03%, 6.15%, and 3.18%, respectively. On Broderick, M5 reduces event F1 by 0.89 points. These results show that the combined contribution of FOCAL-associated processing and supervision varies across datasets, with larger gains in these low-occupancy settings. M4 also reduces event F1 by 4.95 points on HDOP and 8.76 points on TUSZ, supporting the contribution of the multilevel spatial representation and its cross-level residual connections. 

Quantization and Event Guidance. We evaluate continuous and quantized representations with and without event guidance in a 2 × 2 study. Continuous variants bypass both quantizers while preserving pooling, hierarchy, and fusion. Disabling guidance replaces event-based routing with event-independent window selection and uses uniform weights for regional feature pooling. 5 CONCLUSION 

We presented NeuroDETR, a framework for asynchronous EEG event detection that jointly pre-dicts event classes, onsets, and offsets from continuous recordings. Multiscale temporal VQ and Spatial-Pyramid VQ organize temporal dynamics and hierarchical spatial information into a com-pact event memory. FOCAL uses predicted event presence to guide temporal feature refinement and spatial pooling while preserving cross-window context. Across eight datasets spanning P300, motor imagery, motor execution, speech, and seizure detection, NeuroDETR achieves the highest event-level F1 among the compared methods, improving the average over DANCE by 4.29 percentage 9points. Ablation studies support the complementary contributions of discrete spatiotemporal repre-sentations, multiscale structure, and event-aware refinement. These results demonstrate the value of organizing event-relevant information across temporal scales and spatial regions for joint event classification and localization in continuous EEG. A.2 DETECTION ERROR ANALYSIS 

To distinguish missed events from incorrect detections, we evaluate the event-level false discovery rate (FDR) and false negative rate (FNR). Predictions are matched one-to-one to ground-truth events in descending confidence order, with a true positive requiring the correct class and temporal IoU 

> 0.5. The metrics are defined as 

FDR = FP TP + FP × 100% , FNR = FN TP + FN × 100% . (24) Here, TP counts correct matches, FP counts incorrect predictions, and FN counts ground-truth events without a correct match. FDR measures the proportion of incorrect detections among predictions, while FNR measures the proportion of missed events among annotations. As shown in Figures 5 and 6, NeuroDETR achieves the lowest FDR and FNR on six of the eight datasets each, while attaining the highest F1 event on all eight. Where competing methods achieve a lower individual error rate, this advantage is accompanied by a higher complementary error rate: lower FDR coincides with more missed events, whereas lower FNR coincides with a larger pro-portion of incorrect detections. Such single-metric advantages therefore do not translate into better overall detection performance. E BASELINES 

E.1 BASELINE IMPLEMENTATIONS 

We compare NeuroDETR with six event-level baselines: a dataset-aware random predictor, two biomedical event detectors, two temporal action detection models, and DANCE. The comparison excludes sliding-window classifiers because evaluating densely overlapping windows repeatedly processes the same portions of long EEG recordings. All methods use the same dataset-specific EEG channels, preprocessing, event annotations, class mappings, temporal units, and subject-level training, validation, and test partitions. Model selection is performed exclusively on the validation set. All methods share the event-level evaluation protocol described below. For all dense detectors (EventNet, ActionFormer, DyFADet, and DOSED), we apply a confidence threshold of 0.05 and class-wise non-maximum suppression (NMS) with a temporal IoU threshold of 0.5. After NMS, we retain at most Ne predictions per window, ranked by confidence. 

Random. We construct a dataset-aware random predictor to provide a non-trivial lower bound. For each training fold, the event-class distribution, event-duration distribution, and event occurrence rate are estimated using only the training annotations. The number of predicted events in each evalu-ation segment is sampled according to the estimated occurrence rate. Their classes and durations are sampled from the corresponding training distributions, while their onset locations are sampled uni-formly within the segment. Predicted intervals are clipped to the valid temporal range and evaluated using the same event-level protocol as the learned models. 

EventNet. EventNet denotes our implementation of the event-based modeling framework intro-duced by Seeuws et al. [5]. The original method represents each event using its temporal center and duration. A sequence-to-sequence backbone produces a center-confidence signal and a duration estimate at every temporal position. During inference, local maxima in the center-confidence signal are selected as event centers, and the corresponding duration predictions are converted into temporal intervals. We extend the original binary formulation with class-specific center and duration heads for multi-class EEG event detection. Candidate intervals are decoded independently for each class, allowing 18 events of different classes to overlap. The decoded intervals undergo the shared post-processing described above. 

ActionFormer. ActionFormer [39] is a single-stage, anchor-free temporal detector originally de-veloped for temporal action localization in untrimmed videos. It constructs a multiscale temporal feature pyramid, uses local self-attention to model temporal context, and predicts an event class to-gether with the distances from each positive temporal location to the left and right event boundaries. For EEG adaptation, we replace the video feature extractor with a one-dimensional EEG encoder. Its output is arranged as a temporal feature sequence and processed by the original multiscale detection architecture. The temporal strides and regression ranges of the feature pyramid are adjusted accord-ing to the EEG sampling resolution and the dataset-specific event-duration distribution. Predicted boundary distances are converted into onset–offset intervals, followed by the shared post-processing. 

DyFADet. DyFADet [40] extends temporal action detection with dynamic feature aggregation. Its dynamic encoder adjusts the aggregation weights and temporal receptive fields according to the input features. The associated dynamic detection head further adapts its parameters across different feature-pyramid levels, allowing the model to handle events with substantially different durations. We use the same EEG encoder, input resolution, and temporal feature interface as in the Action-Former adaptation. The video feature sequence is replaced by the EEG temporal representation, while the dynamic encoder, multiscale feature pyramid, and boundary-regression mechanism are retained. The supported regression ranges are rescaled to the event durations of each EEG dataset. The output intervals are decoded in seconds and processed using the shared post-processing. 

DOSED. DOSED [9] is a one-dimensional, anchor-based detector originally designed for detect-ing multiple sleep micro-events in EEG. The model associates a collection of default temporal events with different positions and durations. For every default event, it jointly predicts a class score and localization offsets. Training matches ground-truth events to default events according to temporal overlap and optimizes the classification and localization objectives jointly. We adapt DOSED to the event categories of each dataset using its default-event detection formula-tion. Default-event durations are estimated using only the training annotations of each fold. Pre-dicted offsets are decoded into onset–offset intervals, clipped to the input duration, and processed using the shared post-processing. 

DANCE. DANCE [7] is a query-based model for detecting and classifying temporal events in EEG recordings. An EEG encoder first maps the input signal into a temporal representation. Afixed set of learnable queries then interacts with the encoded features, with each query predicting an event category and its temporal extent. During training, bipartite matching establishes a one-to-one assignment between predicted and annotated events, while unmatched predictions are assigned to the no-event category. In the query-sensitivity analysis, we vary only the number of decoder queries. The capacity used to encode ground-truth events remains fixed across the sweep, and all query settings use identical training and evaluation annotations. 

Unified evaluation. All methods ultimately output a collection of (tstart , t end , c, s ) tuples, where 

c denotes the event class and s is the confidence score. Predictions are sorted by confidence and greedily assigned to unmatched ground-truth intervals according to temporal IoU. A matched pair contributes a true positive only when its class is correct and its IoU satisfies the evaluation threshold. We report event-level F1 at a temporal IoU threshold of 0.5.

F BACKBONE ARCHITECTURE 

We use a SimpleConv backbone adapted from [25] to extract spatial and temporal features from EEG recordings. The backbone first performs spatial channel mixing, where Fourier embeddings of electrode coordinates determine learnable attention weights over the recording channels. This operation maps the input signals to a fixed set of virtual channels, incorporating electrode positions 19 into the spatial representation. A pointwise convolution then projects the mixed signals into the feature space used by the temporal stack. Temporal features are extracted through ten convolutional stages with increasing dilation rates, pro-gressively expanding the temporal receptive field. The first nine stages use 512 hidden channels with batch normalization, GELU activation, and dropout, while the final stage produces 128-dimensional features. All temporal convolutions preserve the sequence length, maintaining alignment between the extracted features and the input EEG samples for subsequent event localization and classifica-tion. G IMPLEMENTATION DETAILS 

We implement NeuroDETR using PyTorch and PyTorch Lightning. EEG signals are resampled to 128 Hz and normalized using robust scaling. For the seven cross-validation datasets, we perform five-fold subject-wise cross-validation. Within each fold, 10% of the remaining subjects are reserved for validation. TUSZ uses its predefined training, development, and evaluation splits. The random seed is fixed to 42. We train with AdamW and a OneCycle learning-rate schedule, using the first 10% of training steps for learning-rate increase. Unless otherwise specified, the peak learning rate is 10 −4, weight decay is 10 −3, and the maximum gradient norm is 1. Training runs for up to 100 epochs with an early-stopping patience of 20 epochs. Checkpoint selection and early stopping are based on validation F 1event at a temporal IoU threshold of 0.5. All experiments use FP32 precision. For the seven cross-validation datasets, we train the model on a single GPU.
