## 摘要
学习时空事件数据中的交互结构是神经科学、流行病学和地震学等领域的一个关键统计问题。我们研究连续空间域上 Hawkes 过程的这一问题，其中事件可能在不同位置触发未来事件。遵循 Baars、Laeven 和 Mandjes（2026）在“具有 graphon 诱导连接结构的时空 Hawkes 过程”中建立的框架，我们使用一个底层 graphon 来建模空间交互机制，该 graphon 刻画了强度激发强度如何随位置变化。通过将基线强度、时间激励核和 graphon 在正交基中展开，我们将该问题表示为一个高维参数推断问题。我们提出一种稀疏惩罚最小二乘估计器，在控制模型复杂度的同时恢复有效交互结构。我们的分析在参数数量可能随观测时长增长的高维情形下建立了非渐近误差界，且无需条件强度几乎必然有界。我们进一步建立了稀疏一致性结果，表明潜在交互网络可以被一致恢复。模拟研究展示了所提方法良好的有限样本性能，对包含181万个事件的大规模神经元脉冲数据的应用证明了其实际有效性。

## Abstract
Learning interaction structures from spatiotemporal event data is a key statistical problem in fields such as neuroscience, epidemiology, and seismology. We study this problem for Hawkes processes on a continuous spatial domain, where events may trigger future events at different locations. Following the framework developed in ``Spatiotemporal Hawkes processes with a graphon-induced connectivity structure'' by Baars, Laeven, and Mandjes (2026), we model the spatial interaction mechanism using an underlying graphon that characterizes how the intensities' excitation strength varies across locations. By expanding the baseline intensity, temporal excitation kernel and graphon in orthogonal bases, we represent the problem as a high-dimensional parametric inference problem. We propose a sparse penalized least-squares estimator that recovers the effective interaction structure while controlling model complexity. Our analysis establishes non-asymptotic error bounds in a high-dimensional regime where the number of parameters may grow with the observation horizon, without requiring the conditional intensity to be almost surely bounded. We further establish sparsistency results, showing that the latent interaction network can be consistently recovered. Simulation studies demonstrate the good finite sample performance of the proposed method and an application to large-scale neuronal spike data, comprising 1.81 million events, showcases its practical effectiveness.
