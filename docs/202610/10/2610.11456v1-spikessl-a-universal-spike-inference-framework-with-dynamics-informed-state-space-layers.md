## 摘要
双光子钙成像是在体内记录大规模神经群体的一种标准工具，然而在日益多样的钙指示剂中准确推断脉冲仍然是一个开放问题。现有监督方法在域内能达到合理的准确率，但对未见过的指示剂泛化能力较差，因为不同指示剂会产生不同的荧光动力学和信号统计特性，而现有架构仍是相对简单的通用时间回归器，缺乏与动力学匹配的归纳偏置。我们提出 SpikeSSL，一个通用脉冲推断框架，其时间主干是由一组受钙动力学广泛启发的双向 IIR 状态空间层组成。一个多模态条件编码器将指示剂身份、采样率和轨迹级信号统计信息映射为全局条件向量，通过自适应层归一化调制主干网络；同时，一个异方差方差头提供逐帧校准的不确定性。在由 33 个公开真值数据集构建、包含五个固定评估划分的基准上，SpikeSSL 在域内和留一指示剂的零样本设置中均取得了最先进的性能。我们还开发了一个生物物理仿真流程，能够生成成对的荧光-脉冲轨迹，并系统性地改变动力学参数、脉冲统计、响应非线性、基线漂移和噪声。利用该流程，我们合成了约 11,000 条模拟轨迹。用这些数据增强训练有效弥合了跨指示剂的域差距，并改善了零样本泛化。代码公开于 https://github.com/detimage123/SpikeSSL。

## Abstract
Two-photon calcium imaging is a standard tool for recording large neural populations in vivo, yet inferring spikes accurately across the growing diversity of calcium indicators remains an open problem. Existing supervised methods achieve reasonable in-domain accuracy but generalize poorly to unseen indicators, because different indicators induce distinct fluorescence kinetics and signal statistics while existing architectures remain relatively simple generic temporal regressors without dynamics-matched inductive bias. We propose SpikeSSL, a universal spike inference framework whose temporal backbone is a bank of bidirectional IIR state-space layers broadly motivated by calcium dynamics. A multi-modal conditioning encoder maps indicator identity, sampling rate, and trace-level signal statistics into a global conditioning vector that modulates the backbone via Adaptive Layer Normalization, while a heteroscedastic variance head provides calibrated per-frame uncertainty. On a benchmark with five fixed evaluation splits built from 33 public ground-truth datasets, SpikeSSL achieves state-of-the-art performance in both in-domain and zero-shot leave-one-indicator-out settings. We also develop a biophysical simulation pipeline capable of generating paired fluorescence-spike traces with systematically varied kinetic parameters, spike statistics, response nonlinearities, baseline drift, and noise. Using this pipeline, we synthesize approximately 11,000 simulated traces. Augmenting training with these data effectively closes the cross-indicator domain gap and improves zero-shot generalization. Code is publicly available at https://github.com/detimage123/SpikeSSL.

### 2.1 核心思想

- 将钙指示剂的指数衰减等动力学特性显式引入时序骨干网络，而不是依赖通用时序模块。

### 2.2 模型架构

- **输入投影**：荧光迹线首先通过逐点卷积进行投影。
- **SpikeSSL 模块堆叠**：主干由多个 SpikeSSL block 组成，每个 block 包含：
  - **双向 IIR 状态空间扫描**：具有可学习衰减率，用于捕捉钙信号的指数衰减动力学；
  - **自适应层归一化（AdaLN）**：根据全局条件向量对主干进行调制；
  - **时间混合器（Temporal Mixer）**：深度可分离 1D 卷积（卷积核宽度为 7）+ 逐点卷积 + GELU + 残差连接，提供局部时间混合；
  - **SwiGLU 前馈网络**：通道混合，先投影到两倍通道宽度，再分为门控和值张量，计算 $\mathrm{SiLU}(gate) \odot value$ 后投影回模型维度；两个分支均有残差连接。
- **空洞细化模块（Dilated Refinement Module）**：由扩张率为 1、2、4 的三层残差层组成，每层包含核大小为 3 的 1D 卷积、批归一化、GELU 和 dropout，逐步扩大时间感受野。
- **多模态条件编码器**：
  - **指示剂身份分支**：将离散指示剂身份映射为 64 维可学习向量，其中 ID 0 保留给未知或未见过的新指示剂；
  - **采样率分支**：对对数采样率 $\log f_s$ 通过两层 MLP 编码；
  - **信号统计分支**：对 7 维迹线统计量（标准差、偏度、超额峰度、滞后 1/3/5/10 的自相关）通过两层 MLP 编码；
  - 三个 64 维输出拼接后经 $192 \rightarrow 64 \rightarrow 64$ MLP 融合，得到全局条件向量 $c \in \mathbb{R}^{64}$。
- **输出头**：三个并行输出头分别产生：
  - 脉冲率估计；
  - 二值脉冲门控；
  - 逐帧不确定性估计。
  - 其中异方差方差头用于输出经过校准的逐帧不确定性。
