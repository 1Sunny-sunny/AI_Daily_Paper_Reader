## 摘要
可复现性、可重复性、稳健性与可推广性是可靠脑电图（EEG）研究的基本但各不相同的要求。实现这些目标仍然具有挑战性，因为 EEG 数据集在采集系统、文件格式、实验范式、被试人群、事件注释和记录条件方面差异很大。此外，预处理选择、软件实现、参数设置和计算环境的差异也会显著影响分析结果。本综述考察了支持透明且可推广的 EEG 分析的标准、开源软件和计算流程。我们讨论了脑成像数据结构（BIDS）、层级事件描述符（HED）、FAIR 数据原则以及社区报告指南在提高数据互操作性和可重用性方面的作用。我们回顾了主要的 EEG 分析平台，包括 Brainstorm、EEGLAB、FieldTrip、MNE-Python 和 SPM，以及自动化预处理和质量控制流程。我们还介绍了用于数据集验证、整理、标准化事件注释和可扩展队列级分析的支持基础设施。最后，我们提供了实用建议，强调标准化数据组织、完整报告分析参数和软件环境、代码共享、预注册、自动化质量控制以及跨可行流程的稳健性分析。这些实践共同为更透明、可复现且可跨数据集、实验室和分析工具推广的 EEG 研究结果奠定了基础。

## Abstract
Reproducibility, replicability, robustness, and generalizability are essential but distinct requirements for reliable electroencephalography (EEG) research. Achieving these goals remains challenging because EEG datasets vary substantially across acquisition systems, file formats, experimental paradigms, participant populations, event annotations, and recording conditions. In addition, differences in preprocessing choices, software implementations, parameter settings, and computational environments can substantially influence analytical results. This overview examines the standards, open-source software, and computational pipelines that support transparent and generalizable EEG analysis. We discuss the role of the Brain Imaging Data Structure (BIDS), Hierarchical Event Descriptors (HED), FAIR data principles, and community reporting guidelines in improving data interoperability and reuse. We review major EEG analysis platforms, including Brainstorm, EEGLAB, FieldTrip, MNE-Python, and SPM, as well as automated preprocessing and quality-control pipelines. We also describe supporting infrastructure for dataset validation, curation, standardized event annotation, and scalable cohort-level analysis. Finally, we provide practical recommendations emphasizing standardized data organization, complete reporting of analysis parameters and software environments, code sharing, preregistration, automated quality control, and robustness analyses across plausible pipelines. Together, these practices provide a foundation for EEG findings that are more transparent, reproducible, and generalizable across datasets, laboratories, and analytical tools.
