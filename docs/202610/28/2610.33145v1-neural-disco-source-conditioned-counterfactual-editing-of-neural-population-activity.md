## 摘要
理解神经活动如何编码行为变量和感觉变量是系统神经科学中的一个关键挑战。这需要模型不仅能根据标签预测活动，还能支持源条件反事实编辑：给定记录的源响应，我们应当能够编辑一个已测量的行为或刺激标签，并预测神经活动会如何变化，同时保留其他已观测标签以及未被标签解释的源特异性变异。在此，我们引入了 Neural-DISCO，一个用于神经活动反事实建模的解纠缠表示学习框架。Neural-DISCO 将潜在空间划分为标签特异性分量（每个分量与一个已观测的行为或刺激标签相关联），以及一个残差潜在变量，用于捕捉未由已观测标签提供的变异。在模拟和真实神经记录数据集上，我们表明这种结构能够对已测量标签进行选择性编辑，以生成反事实神经响应，同时保留原始活动的其余内容。此外，为了在单神经元分辨率上了解行为和刺激标签如何被编码，我们将该解纠缠框架与特征归因方法结合，以识别对每个标签最重要的神经元。我们发现，解纠缠增强了在合成数据和真实数据中恢复已知功能细胞角色的能力。总之，这些结果支持 Neural-DISCO 作为神经活动反事实建模的框架，并为探索神经群体如何编码行为和感觉信息提供了实用接口。代码可在 https://github.com/TangLab-UBC/Neural-DISCO-neurips 获取。

## Abstract
Understanding how neural activity encodes behavioral and sensory variables is a key challenge in systems neuroscience. This requires models that go beyond predicting activity from labels and instead support source-conditioned counterfactual editing: given a recorded source response, we should be able to edit one measured behavioral or stimulus label and predict how neural activity would change while preserving other observed labels and source-specific variability not explained by the labels. Here, we introduce \textbf{Neural-DISCO}, a disentangled representation learning framework for counterfactual modeling of neural activity. Neural-DISCO partitions the latent space into label-specific components, each associated with an observed behavioral or stimulus label, together with a residual latent that captures variability not supplied through observed labels. Across simulated and real neural recording datasets, we show that this structure enables selective editing of measured labels to generate counterfactual neural responses while preserving the remaining content of the original activity. Further, to gain insight into how behavioral and stimulus labels are encoded at single-neuron resolution, we pair this disentangled framework with feature attribution methods that identify which neurons are most important for each label. We find that disentanglement enhances the recovery of known functional cell roles in both synthetic and real data. Together, these results support Neural-DISCO as a framework for counterfactual modeling of neural activity and provide a practical interface for probing how neural populations encode behavior and sensory information. Code is available at https://github.com/TangLab-UBC/Neural-DISCO-neurips.

# Neural-DISCO 论文总结

## 1. 论文的核心问题与整体含义

- 论文关注系统神经科学中的一个核心问题：**如何从神经群体活动中理解和预测行为、感觉变量的编码**。
- 现有模型大多只能做“给定标签预测神经活动”（label-conditioned generation），但无法很好回答“如果某个行为或刺激标签改变，同一神经群体响应会如何变化”这种反事实问题。
- 本研究提出 **源条件反事实编辑（source-conditioned counterfactual editing）**：给定一个已记录的源神经响应和若干观测标签，只编辑其中一个或多个标签，生成新的神经活动，同时尽量保留未编辑标签的信息以及未被观测标签解释的源特异性变异。
- 需要注意：论文中的“反事实”是**操作性、模型预测意义上的用法**，不是从观测数据中严格识别因果效应。
- 整体含义是：为神经科学提供一种可编辑的生成建模框架，既能按需改变行为或刺激标签，又能保留源响应的残余神经状态，从而支持更灵活的“what-if”分析。

## 2. 论文提出的方法论

### 2.1 核心思想

- Neural-DISCO 是一种**解纠缠表示学习框架**。
- 潜在空间被划分为：
  - $K$ 个标签特异性潜在变量 $z_a = \varphi_a(y_a)$，每个对应一个已观测标签 $y_a$；
  - 一个残差潜在变量 $u = \varphi_{\mathrm{res}}(x)$，由源神经响应 $x$ 编码，用于捕获未被标签解释的变异。
- 完整干净表示：
  $$z = (z_1, \dots, z_K, u), \qquad d_{\mathrm{tot}} = \sum_{a=1}^{K} d_a + m$$
- 生成器将拼接后的潜在表示映射为神经元的发放率：
  $$r_\theta(\tilde z) = G_\theta(\tilde z)$$
  输出通过 softplus 保证为正。

### 2.2 关键训练技巧：带噪残差瓶颈

- 训练期间，残差潜在变量被注入高斯噪声：
  $$\tilde u = u + \epsilon, \qquad \epsilon \sim \mathcal N(0, \sigma^2 I_m)$$
  干净残差 $u$ 只在测试和编辑时使用。
- 损失函数由 Poisson 负对数似然和残差激活惩罚组成：
  $$L(\theta, \{\varphi_a\}, \varphi_{\mathrm{res}}) = \frac{1}{N} \sum_{s=1}^N \mathbb E_{\epsilon^{(s)}} \left[ \sum_{\ell=1}^n \left( r^{(s)}_{\theta,\ell} - x^{(s)}_\ell \log r^{(s)}_{\theta,\ell} \right) \right] + \lambda \frac{1}{N} \sum_{s=1}^N \left\| u^{(s)} \right\|_2^2$$
- 条件分布假设神经元之间相互独立，服从 Poisson：
  $$p_\theta(x \mid \tilde z) = \prod_{\ell=1}^n \mathrm{Poisson}\left(x_\ell \mid r_{\theta,\ell}(\tilde z)\right)$$
- 噪声和范数惩罚共同构成信息瓶颈，迫使模型将已观测标签信息路由到标签特异性潜在变量，而残差只保留源特异信息。

### 2.3 残差通道容量解释

- 论文给出 Proposition 1，在自然对数意义下，训练时带噪残差通道满足：
  $$I(S; \tilde U) \leq \frac{m}{2} \log\left(1 + \frac{\hat P}{m\sigma^2}\right)$$
  其中 $S$ 是训练样本索引，$U_S = \varphi_{\mathrm{res}}(X_S)$，$\hat P = \frac{1}{N}\sum_{s=1}^N \|\varphi_{\mathrm{res}}(x^{(s)})\|_2^2$。
- 进一步有：
  $$I(Y_{a,S}; \tilde U) \leq I(S; \tilde U), \qquad I(Z_{a,S}; \tilde U) \leq I(Y_{a,S}; \tilde U)$$
- 该结果表明：训练时的带噪残差通道容量受噪声水平和残差平均能量限制，有助于抑制标签信息泄漏到残差中。但论文也明确说明，这不等同于解纠缠的身份保证，也不直接约束测试时使用的干净残差。

### 2.4 源条件编辑流程

- 给定源对 $(x, y)$，先计算：
  $$z_a = \varphi_a(y_a), \quad u = \varphi_{\mathrm{res}}(x)$$
- 编辑标签 $a$ 时，只替换其标签潜在变量：
  $$\hat z_a = \varphi_a(\hat y_a), \qquad \hat z = (z_1, \dots, z_{a-1}, \hat z_a, z_{a+1}, \dots, z_K, u)$$
- 生成编辑后的发放率：
  $$\hat r = G_\theta(\hat z)$$
- 需要采样时：
  $$\hat x_\ell \sim \mathrm{Poisson}(\hat r_\ell)$$

### 2.5 神经元级标签归因

- 使用 Integrated Gradients 度量每个标签对每个神经元生成器 pre-softplus 输出的贡献。
- 路径从零标签和零残差出发，直线插值到源输入。
- 对每个标签，先对 32 个随机源样本的带符号归因取平均，再对标签输入维度或残差维度取平均绝对值。
- 标签级归因：
  $$IG_{\ell, y_a}(z; b) = (y_a - b_{y_a}) \odot \int_0^1 \nabla_{y_a} g_\ell(z(\alpha)) \, d\alpha$$
- 该归因用于识别哪些神经元对特定标签最敏感。

## 3. 实验设计

### 3.1 数据集与场景

- **RatInABox 仿真数据**
  - 包含 100 个位置细胞、100 个头部方向细胞、100 个速度细胞。
  - Neural-DISCO 接收位置和头部方向作为观测标签，速度被故意保留在残差中。
  - 提供 ground-truth 反事实发放率，可直接比较编辑效果。

- **Macaque 到达运动电生理数据（MC Maze / NLB）**
  - 137 个记录单元，来自中心向外到达任务。
  - 编辑手部位置、手部速度和眼动位置块。
  - 没有 ground-truth 反事实神经响应，使用仅由真实神经活动训练的 CEBRA 解码器评估“生成活动是否解码为目标行为”。

- **Allen Visual Coding Neuropixels 数据**
  - 32 个记录会话，漂移光栅刺激期间的小鼠视觉皮层记录。
  - 速度编辑：观测标签为运行速度和光栅方向，时间频率被隐藏，要求通过残差保留。
  - 方向编辑：观测标签为方向和 TF，运行速度被隐藏，要求通过残差保留。
  - 使用数据集提供的单位指标（running modulation p-value、global orientation selectivity index）验证归因质量。

### 3.2 Baseline 与对照

对比的方法包括：

- Neural-DISCO（完整模型）
- 无正则化消融（$\lambda = \sigma = 0$，架构匹配）
- 零残差对照（编辑时将源残差置零）
- pi-VAE
- NEDS
- 高斯 GLM
- Poisson GLM

其中 pi-VAE、NEDS 和 Poisson GLM 没有同一套源条件残差编辑接口，因此在反事实评估中使用其目标条件生成接口。论文明确说明这一差异，并把它作为一种比较而非断言所有模型都基于同一接口设计。

### 3.3 评估指标

- **RatInABox**：编辑种群与 simulator target rates 的 $R^2$；细胞类型恢复 AUC；编辑-保存联合分数 SEP。
- **MC Maze**：编辑后活动对目标行为的解码 $R^2$；源和目标的解码 $R^2$ 分别作为负对照和经验上界。
- **Allen**：速度 RMSE、TF 平衡准确率、方向平衡准确率、速度保存 RMSE、running-modulation AUC、orientation-selectivity correlation 等。
- **SEP 联合分数**：
  $$S_{EP} = \frac{2EP}{E + P}$$
  其中 $E$ 为编辑保真度，$P$ 为保留分数，用于概括“既编辑成功又保留其他信息”的能力。

- **客观性较好**：使用了统一的解码器、固定的交叉验证划分、明确的种子和超参数；对不能直接使用源条件编辑接口的 baseline 也给出了公平性说明。
- **潜在局限**：
  - 真实数据没有 ground-truth 反事实响应，解码器评估只是间接代理。
  - 一些 baseline（如 pi-VAE、NEDS）在反事实编辑接口上并非原生设计，可能低估其实际能力。
  - 解码器性能可能受训练数据量和任务相关性影响，论文虽然做了对照，但不能完全排除验证偏差。
  - 实验集中在运动与视觉两种模态，其他神经记录类型尚未覆盖。

## 6. 论文的主要结论与发现

- Neural-DISCO 能够在模拟和真实神经数据中实现**选择性的源条件编辑**：改变目标标签时，活动向目标状态移动，同时较好地保留未编辑标签和残差源特异信息。
- 在 RatInABox 中，模型能够编辑位置或头部方向，同时保留未观测的速度信息于残差中；编辑后的发放率与 simulator ground truth 高度一致，$R^2$ 接近 0.88–0.96。
- 在 MC Maze 中，Neural-DISCO 生成活动的目标解码 $R^2$ 接近目标 spike 的参考值：手部位置 0.895、手部速度 0.772、眼动位置 0.630；未正则化对照则基本保持源样行为，呈现负目标解码 $R^2$。
- 在 Allen 32 会话中，速度编辑降低了速度 RMSE；方向编辑有更高的目标方向准确率和更好的 TF 保存。残差归因与 Allen 单位指标一致：随着瓶颈强度增强，running-modulation AUC 和 orientation-attribution correlation 提高。
- 解纠缠提高了神经元级归因质量，能更好地恢复已知功能细胞角色（如位置细胞、头部方向细胞、速度细胞）。
- 信息论容量界解释了训练时带噪残差为什么能减少标签泄漏，但同时也强调了这并不能保证完全的因果或统计独立。

## 7. 优点

- **问题新颖**：聚焦于“源条件反事实编辑”，区别于传统 label-conditioned generation，更贴近神经科学中的反事实推理需求。
- **方法论清楚**：标签特异性潜在变量 + 带噪残差瓶颈的设计简单高效，并给出容量上界的理论解释。
- **实验设计扎实**：结合仿真 ground truth 和两个真实数据集，覆盖运动、视觉与行为状态等多个维度。
- **可解释性突出**：将编辑框架与 Integrated Gradients 归因结合，提供单神经元级别的标签归因。
- **可重复性好**：提供了代码链接、详细超参数、随机种子、数据集信息、checklist 和算力报告。
- **诚实处理因果语义**：明确指出反事实是模型预测而非因果识别，对编辑的语义边界有较多讨论。

## 8. 不足与局限

- **反事实解释的因果基础较弱**：编辑不提供因果识别保证，只能解读为模型在学到的因子分解下的预测。
- **真实数据缺乏 ground truth**：主要依赖解码器和数据集指标评估，不能直接证明编辑后的神经活动在生物学上是真实的。
- **模型是静态的**：没有显式建模时间动态或试次间转变，可能不适合需要时间展开神经系统动态的场合。
- **瓶颈存在权衡**：残差通道太弱会导致重构和隐藏标签保留变差；太强又会导致标签泄漏，编辑失效。λ 的选择依赖验证分数，尚无自适应统一准则。
- **解纠缠的身份限制**：论文明确说明，仅靠不对称噪声不能保证解纠缠身份，尤其在标签高度相关、缺失变量或分布偏移时可能失效。
- **实验范围仍有限**：主要覆盖大鼠仿真、灵长类到达任务和小鼠视觉；其他物种、脑区和更复杂行为任务中的表现尚待验证。
- **部分 baseline 比较存在口径差异**：pi-VAE、NEDS 和 Poisson GLM 并非为源条件编辑设计，其目标条件生成接口在编辑任务中的比较可能不完全对等。
