## 摘要
Wilson-Cowan 模型是“神经群模型”的一个经典例子——一种描述大规模神经元网络活动的简化但强大的方法。它特别有趣之处在于，即使形式相对简单，它也能产生令人惊讶的多种行为，从稳定节律到复杂振荡。影响这些动力学的一个关键因素是时间延迟的存在，它反映了信号在神经元之间传递所需的时间。本文对 Wilson-Cowan 模型进行了易懂的介绍，重点关注这些时间延迟如何影响其行为。我们探讨了模型背后的核心概念，综述了现有文献，并介绍了一些专门用于分析此类延迟微分方程的数值技术。我们还提供了一个实用的、可动手操作的教程，介绍如何使用 DDE-BIFTOOL 软件包，并演示其在 Wilson-Cowan 模型上的应用。可下载的代码使读者能够重现我们的结果，并进一步探索模型动力学，其中包括所有计算的 MATLAB 代码、用于延拓的 DDE-BIFTOOL 以及仿真代码的 Python 版本。

## Abstract
The Wilson-Cowan model is a classic example of a ``neural mass model'' - a simplified yet powerful way to describe the activity of large networks of neurons. It is particularly interesting because, even in its relatively simple form, it can produce a surprising variety of behaviours, from steady rhythms to complex oscillations. A key factor influencing these dynamics is the presence of time delays, reflecting the time it takes for signals to travel between neurons. This article offers an accessible introduction to the Wilson-Cowan model, focusing on how these time delays affect its behaviour. We explore the core concepts behind the model, survey the existing literature, and introduce some numerical techniques specifically designed for analysing such delay differential equations. We also provide a practical, hands-on tutorial on using the DDE-BIFTOOL software package, demonstrating its application to the Wilson-Cowan model. Downloadable code allows the reader to reproduce our results and to explore the model's dynamics further, including MATLAB code for all computations, using DDE-BIFTOOL for the continuation, and Python versions of simulation codes.
