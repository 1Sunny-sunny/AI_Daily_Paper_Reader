## 摘要
解释时间序列模型既需要定位证据，也需要从中提取有意义的知识。然而单个时间步并不是语义单元：有意义的模式跨多个样本存在，而非存在于任何一个样本中。因此逐时间步的显著性具有噪声、高维且不稳定。现有方法通过引入固定大小的窗口并将其视为合作博弈中的独立参与者来解决这一问题。评估此类参与者联盟需要定义“基线”区域，先前工作通过固定反事实（例如平线、噪声或频谱替代）来处理。这一选择往往主导了最终解释，掩盖了模型的真实决策。为了解决这些问题，我们提出了GRAIL，一个基于区域的时间序列解释框架，使用领域特定区间，例如心电图（ECG）搏动的P波和QRS波群，作为参与者。我们使用人类可读的特征描述每个区域，并通过流形上的条件生成器生成反事实基线。这种参与者选择还支持非时间特征：静态协变量作为单例参与者加入，并与时间区域在同一尺度上进行归因，因此患者的表格证据（例如年龄、性别）可以直接与信号进行权衡。我们通过Owen值以及公共随机数方差缩减将预测归因于特征。在合成数据和真实数据上的实验结果表明，所提出的框架在匹配的流形内和流形外算子评估下产生忠实且稳健的解释，为领域专家提供有意义的知识。

## Abstract
Explaining a time-series model requires both locating the evidence and extracting meaningful knowledge from it. Yet a single timestep is not a semantic unit: the meaningful patterns live across many samples, not in any one of them. Per-timestep saliency is therefore noisy, high-dimensional, and unstable. Existing methods address this by introducing fixed-size windows and treating them as independent players in a cooperative game. Evaluating a coalition of such players requires defining a ``baseline'' region, which prior work tackles with fixed counterfactuals (e.g., a flat line, noise, or a spectral surrogate). This choice frequently dominates the resulting explanation, obscuring the model's true decisions.   To address these issues, we propose GRAIL, a region-based time-series explanation framework that uses domain-specific intervals, such as the P-wave and the QRS complex of an electrocardiogram (ECG) beat, as players. We describe each region with human-readable features and generate counterfactual baselines with an on-manifold conditional generator. Such a choice of players also admits non-temporal features: static covariates enter as singleton players attributed with the temporal regions on one scale, so a patient's tabular evidence (e.g., age, sex) is weighed directly against the signal. We attribute the predictions to the features via Owen values with common-random-number variance reduction. Experimental results on both synthetic and real data show that the proposed framework produces faithful and robust explanations, evaluated under matched on- and off-manifold operators, offering meaningful knowledge to domain experts.
