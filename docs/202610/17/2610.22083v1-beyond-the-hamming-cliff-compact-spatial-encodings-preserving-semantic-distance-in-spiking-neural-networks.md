## 摘要
通过在使用 SpiNNaker 硬件运行的脉冲神经网络之前，用格雷、温度计、约翰逊和混合编码对输入信号进行预处理，Davies 等人（2025）解决了标准二进制表示中导致“汉明悬崖”的语义-空间差异问题。连续的语义模式在输入层被表示为一组同时脉冲，从而保持超低延迟处理。在每种方案下对多个连续值训练网络，并测量准确率、所需的稳态缩放和假阳性率，结果表明消除悬崖是必要但不充分的：格雷编码可消除悬崖，但几乎不保留全局距离结构；而温度计和约翰逊编码以随值域增长的码宽保持语义距离。所提出的混合编码将三者作为单一参数的极限情况包含在内，以更小的码宽恢复了大部分结构。研究表明稳态因子在每个已训练模式周围设定了一个容差半径，因此仅编码方式的选择就决定了网络将哪些值视为相似。

## Abstract
By pre-processing input signals with Gray, Thermometer, Johnson and hybrid encodings before passing them to spiking neural networks running on SpiNNaker hardware, Davies et al.(2025) address the semantic-spatial disparity that causes the ``Hamming cliff'' in standard binary representations. Continuous semantic patterns are presented as a set of simultaneous spikes at the input layer, preserving ultra-low latency processing. Training the network on multiple continuous values under each scheme, and measuring accuracy, required homeostatic scaling and false-positive rates, shows that removing the cliff is necessary but not sufficient: Gray encoding removes it yet retains little global distance structure, whereas Thermometer and Johnson preserve semantic distance at a code width that grows with the value range. The proposed hybrid encodings contain all three as limiting cases of a single parameter, recovering most of that structure at a fraction of the width. The homeostatic factor is shown to set a radius of tolerance around each trained pattern, so that the choice of encoding alone decides which values the network treats as similar.
