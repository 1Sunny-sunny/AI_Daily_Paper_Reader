## 摘要
皮层内运动解码器在会话间性能会下降，因为所记录的单元集合会发生变化，且持续记录的单元其放电与行为的关系也可能改变。大多数现有方法在每个新会话上更新网络权重，或依赖无标签神经活动，而这些方法不能直接揭示此类变化。我们提出 APST，一种关联剖面条件化的集合-时序 Transformer，它在所有网络权重冻结的情况下适应新会话。借助少量带标签的校准试验，APST 以闭式解计算出的四维关联剖面概括每个单元的放电与行为之间的关系。这些剖面作为条件输入到集合注意力编码器，该编码器可接受任意数量和顺序的单元，其后接一个因果 Transformer 进行流式解码。在两只猴子的留出 DANDI688 会话上，APST 的速度 $R^2$ 达到 0.78 和 0.81，而仅使用神经活动的变体分别为 0.40 和 0.58，并且达到或超过在同一批试验上微调的 RNN。在 FALCON 私有留出评估中，它在 M1、M2 和 H1 上分别获得 0.65、0.42 和 0.44 的 $R^2$。

## Abstract
Intracortical motor decoders degrade across sessions because the set of recorded units changes and persisting units can alter how their firing relates to behavior. Most existing methods update network weights on each new session or rely on unlabeled activity, which does not directly reveal such changes. We present APST, an Association Profile-conditioned Set-Temporal transformer that adapts to new sessions with all network weights frozen. From a few labeled calibration trials, APST summarizes how each unit's firing relates to behavior in a four-dimensional association profile computed in closed form. The profiles condition a set-attention encoder that accepts any number and order of units, followed by a causal transformer for streaming decoding. On held-out DANDI688 sessions from two monkeys, APST reaches velocity $R^2$ of $0.78$ and $0.81$, versus $0.40$ and $0.58$ for a variant that uses neural activity alone, and matches or exceeds an RNN fine-tuned on the same trials. On FALCON private held-out evaluation, it attains $R^2$ of $0.65$, $0.42$, and $0.44$ on M1, M2, and H1.

## 1. 论文的核心问题与整体含义

- **研究背景与问题**：皮层内脑机接口（intracortical BCI）通过植入电极阵列记录神经活动并解码运动意图。然而，随着记录天数增加，电极相对于神经组织可能发生微移动，导致以下变化：
  - 记录到的神经单元（单神经元或多单位/通道）集合发生变化：部分单元丢失、漂移或新增。
  - 持续记录的单元即使仍然存在，其放电与行为之间的关联也可能改变。
- **现有方法的局限**：
  - 多数方法在每个新会话上更新网络权重（如微调），需要在部署时进行反向传播，存在过拟合少样本的风险。
  - 一些方法依赖无标签目标会话活动进行对齐，但无标签活动无法直接揭示“单元—行为关联变化”这一关键漂移来源。
- **本文核心思想**：利用少量有标签校准试验（labeled calibration trials）从每个单元的放电中提取其与行为的关联概况（association profile），并将该概况作为条件输入，使一个源会话训练好的解码器在所有权重冻结的情况下适应新会话。该方法避免目标会话反向传播，同时能显式利用行为标签来解决关联漂移。

## 2. 论文提出的方法论

### 2.1 关联概况（Association Profile）

- **目标**：用少量校准试验 $\mathcal{C}_s = \{(X_{s,j}, Y_{s,j})\}_{j=1}^{M_s}$，为每个单元 $u$ 计算一个静态的四维向量 $p_{s,u}$，概括其放电与行为的关系。
- **一般形式**：通过带正则化的加权最小二乘拟合：

$$
a_{s,u}^{\text{raw}} = \arg\min_{v \in \mathbb{R}^{d_\phi}} \sum_t \omega_{s,t} \left( r_{s,t,u} - \phi_{s,t}^\top v \right)^2 + \eta \|v\|_2^2,
$$

其中 $r_{s,t,u}$ 为单元 $u$ 在样本 $t$ 的响应，$\phi_{s,t}$ 为行为协变量，$\omega_{s,t}$ 为非负权重。该闭式解只需一次校准数据遍历，不产生目标会话梯度。

- **两种归纳方式**：
  - **方向调谐概况（M2 与 DANDI688）**：对二维运动，使用一阶谐波方向调谐模型，拟合系数 $a_{s,u}$、$d_{s,u}$，计算调制深度 $\rho_{s,u} = \sqrt{a_{s,u}^2 + d_{s,u}^2}$，再加上基线 $b_{s,u}$，得到四维概况 $p_{s,u} = \left[ a_{s,u}, d_{s,u}, \rho_{s,u}, b_{s,u} \right]^\top$（经源会话均值与标准差标准化）。
  - **SVD 压缩概况（M1 与 H1）**：对高维行为（16 通道 EMG 或 7 维速度），将行为分为非负状态，计算行为加权关联矩阵 $A_s \in \mathbb{R}^{N_s \times K}$，然后用源会话池化关联矩阵的奇异值分解（SVD）前四个右奇异向量 $V_4$ 将 $A_s$ 投影到四维，再按源会话统计标准化，得到四维概况 $P_s = [p_{s,1}^\top; \dots; p_{s,N_s}^\top]$。

### 2.2 概况条件化的单元身份（Unit Identity）

- **活动签名**：校准试验中单元 $u$ 的分箱脉冲活动 $x_{s,j,u}$ 经过共享线性层与 ReLU，再在试验上平均，得到活动签名 $h_{s,u}$。
- **FiLM 条件化**：概况 $p_{s,u}$ 通过 FiLM 层生成缩放参数 $\gamma_{s,u}$ 和偏移参数 $\beta_{s,u}$：

$$
[\gamma_{s,u}; \beta_{s,u}] = W_o \operatorname{ReLU}(W_i p_{s,u} + b_i) + b_o,
$$

$$
\tilde{h}_{s,u} = (1 + \gamma_{s,u}) \odot h_{s,u} + \beta_{s,u}.
$$

然后将 $\tilde{h}_{s,u}$ 与 $p_{s,u}$ 拼接，经过身份 MLP $g$ 得到单元身份 $e_{s,u}$。$W_o$ 和 $b_o$ 零初始化，训练从纯拼接开始，保证初始稳定。

### 2.3 集合-时序流式解码器（Set-Temporal Streaming Decoder）

- **单元 token 构建**：
  - 首先用共享因果卷积 $\psi$ 对当前及前 4 个时间 bin 的实时活动进行映射，得到 $l_{s,u,t}$。
  - 将缓存的单元身份投影 $W_e e_{s,u}$ 加到 $l_{s,u,t}$ 上，再拼接概况 $p_{s,u}$，经过 token MLP $f$ 和层归一化，得到单元 token $z_{s,u,t}$。
- **集合注意力**：
  - 使用 $k=8$ 个可学习 slot 查询 $S$，对单元 token 集合 $Z_{s,t}$ 做多头交叉注意力（set attention）。填充 mask $m_s$ 排除填充单元，保证对单元顺序和数量不变。
  - 输出经 slot 矩阵展平并线性映射为 256 维群体 token $q_{s,t}$。
- **因果 Transformer**：
  - 以 $q_{s,t}$ 为起始，经过 4 层 pre-LN 因果 Transformer，每层包含残差注意力与 FFN。
  - 每层内部使用滑动因果窗口，注意力 logits 加入可学习的相对时间偏置（类似 ALiBi）。
  - 解码器总感受野 $R = 5 + \sum_\ell (w_\ell - 1)$，按任务时间结构设定，并在四层中均匀分配。
  - 每层维护 key/value cache 以约束流式状态，不随会话历史增长。
- **输出平滑**：最终层归一化和任务专用 readout 得到原始预测 $\hat{y}_{s,t}$，推理时采用因果 EMA：$\tilde{y}_{s,t} = \alpha \tilde{y}_{s,t-1} + (1-\alpha)\hat{y}_{s,t}$，其中 $\alpha = 1/3$，会话边界重置。

## 6. 论文的主要结论与发现

- **主结果**：
  - DANDI688 留出会话上，APST 速度 $R^2$ 为 0.78（Sub-C）和 0.81（Sub-M），显著高于 Activity-only 变体的 0.40 和 0.58。
  - 在相同校准试验上，APST 的性能达到或超过微调 RNN（RNN-FT 的 $R^2$ 为 0.77 和 0.70）。
  - FALCON 私有留出评估中，APST 在 M1、M2、H1 上分别获得 $R^2 = 0.65 \pm 0.11$、$0.42 \pm 0.10$、$0.44 \pm 0.15$。在无目标会话梯度的同类方法中，M2 和 H1 最高，M1 略低于 SPINT（0.01）。
  - APST 超过基于梯度的 NDT2 Multi（M1 上 0.59）并在 M2 上接近（0.42 vs 0.43），在 H1 上匹配私有标签 RNN oracle（0.44）。
- **样本效率**：
  - 在 8 个校准试验时，APST 在 Sub-C 上达到 0.75、Sub-M 上 0.77，而 RNN 微调分别为 0.64 和 0.47。Sub-C 上 8 个 APST 试验超过 RNN 微调使用 16 个试验的性能。
- **消融发现**：
  - 与 Activity-only 相比，概况在三个 FALCON 任务上提升 0.03（M1）、0.18（M2）、0.20（H1）。
  - Profile shuffle 在所有五个设置中都低于 Activity-only，说明概况被用作单元特定身份，而不是会话级汇总。
  - 条件位点消融显示 token 级条件承载大部分收益，身份级条件额外成本低且可保留。
- **计算效率**：
  - 校准阶段计算量极小，且不需要目标会话反向传播，适合部署。

## 7. 优点

- **冻结权重适配**：无需在部署时更新网络权重，避免少样本过拟合和反向传播开销，更适合在线 BCI 场景。
- **显式利用行为标签**：用闭式关联概况直接刻画单元—行为关系变化，比仅用无标签活动更能解决关联漂移。
- **通用四维接口**：通过方向调谐和 SVD 投影两种归纳方式，将不同行为维度统一到四维概况，使同一架构处理平面与高维任务。
- **集合不变性**：set attention 使模型可接受任意数量、任意顺序的单元集合，适应跨会话单元丢失/新增。
- **流式友好**：滑动窗口因果注意力 + key/value cache 约束状态量，适合实时解码。
- **消融扎实**：Activity-only、Static、Profile shuffle、条件位点消融等设计清晰，能够排除多种替代解释。
- **对比公平性**：FALCON 采用官方私有评估，DANDI688 使用留出会话，且与多种梯度式/无梯度式方法比较。

## 8. 不足与局限

- **概况估计器仍为任务手工设计**：方向调谐和 SVD 压缩概况分别针对不同任务设计，源会话的 SVD 基、行为状态划分等需人工确定，尚未实现跨数据集统一学习。
- **条件位点分工未充分解释**：身份级与 token 级条件在多数任务上差异很小，但 H1 上 token 条件明显更关键，原因尚不清楚。
- **部分基准性能仍非最优**：在 FALCON 的 M1 上略低于 SPINT，在 H1 上低于 NDT2 Multi（0.52）和私有标签 oracle，说明方法仍有提升空间。
- **算力与训练细节披露不足**：未报告源模型训练的 GPU 类型、数量、训练时间，以及完整超参数表，影响可重复性和成本评估。
- **消融统计有限**：开发集消融图使用三种子均值，未提供多次运行的标准误/置信区间，不同条件之间的差异是否显著难以判断。
- **仅使用公开数据**：结论基于公开记录，未在更复杂、植入时间更长或临床 BCI 场景中验证。
- **校准标签依赖**：相比 SPINT 等无标签方法，APST 需要少量有标签校准试验，尽管这类标签在临床 BCI 中常可通过提示动作获得，但在某些自由行为场景中可能不可用。
