## ABSTRACT 

Brain–computer interfaces decode neural activity, yet class-label supervision (CLS) leaves relationships among classes implicit. We propose Language as Su-pervision (LaS), which aligns neural features with natural-language class descrip-tions through learned projections and predicts classes using candidate text proto-types. We evaluate seven encoder architectures with independently trained mod-els for visual, motor, and speech decoding from scalp and intracranial recordings. LaS improves speech-decoding accuracy by up to 17.15 pp over matched CLS baselines. Its representations support candidate-set reuse and label-supervised subject and session adaptation, while LaS enables conditional unseen-frequency decoding in steady-state visual evoked potential (SSVEP) responses. Correct class–description correspondence supports this generalization, and dual-sided at-tribution visualization shows neural and textual contributions to the same class-matching score. These findings suggest that text descriptions can serve as general-purpose references for learning and interpretation in neural decoding. 

## 1 INTRODUCTION 

Brain–computer interfaces (BCIs) use representations of scalp electroencephalography (EEG) or intracranial recordings for communication and control, such as finger-level robotic hand control (Ding et al., 2025) and speech neuroprostheses (Willett et al., 2023). Classical decoding combines engineered features with classifiers or template matching (Ramoser et al., 2000; Tangermann et al., 2012; Nakanishi et al., 2018). Neural decoders learn signal rep-resentations jointly with task-specific classifiers (Lawhern et al., 2018; Schirrmeister et al., 2017). EmotionCLIP uses templated descriptions for emotion recognition (Yan et al., 2026), while EEG-PRIME combines class prototypes with task instructions and multilevel conditioning (Zhang et al., 2026). We study class descriptions as a supervision and prediction interface through neural– text alignment, using paired CLS comparisons that retain established encoder architectures. We introduce Language as Supervision (LaS; Figure 1) with three contributions. (1) LaS uses class descriptions as references for learning and candidate prediction, aligning neural features with text embeddings through learnable projections. (2) Paired evaluations across seven encoders show de-coding gains in motor imagery (MI), steady-state visual evoked potential (SSVEP), and speech de-coding from scalp EEG and intracranial stereo-EEG (sEEG). LaS supports candidate configuration through class descriptions, subject/session adaptation, and conditional unseen-frequency prediction. (3) Theory and controlled language experiments characterize alignment behavior. We propose a dual-sided attribution visualization scheme that shows neural signal components and prompt words contributing to the same class-matching score. 

## 2 RELATED WORK 

2.1 SEMANTIC REPRESENTATIONS FOR CLASSIFICATION 

Semantic class representations link supervision to candidate prediction. Semantic output codes use class attributes as learning targets, including unseen-word fMRI decoding (Palatucci et al., 2009). DeViSE links visual features to text-derived class-name representations for unseen-class predic-tion (Frome et al., 2013); Ba et al. (2015) generate classifier weights from descriptions for classes without training images. CLIP combines large-scale contrastive image–text learning with predic-tion by candidate-description similarity (Radford et al., 2021), demonstrating competitive zero-shot recognition, frozen-feature transfer through linear probes, and improved robustness over ImageNet supervision on the natural shifts studied. Its dataset transfer and instance-level pairing differ from our class holdouts and repeated descriptions. BLIP-2 connects a frozen image encoder and frozen large language model through a Q-Former (Li et al., 2023); CLAP extends contrastive alignment and candidate matching to audio for zero-shot classification (Elizalde et al., 2023). 2.2 LANGUAGE -A LIGNED NEURAL DECODING 

Neural–text alignment methods differ in their sources of textual supervision, the units paired during training, and how text is used at prediction. BrainCLIP maps fMRI representations into a visual– language space using visual and text supervision (Ma et al., 2025). Clinical EEG studies use paired reports: Gijsen & Ritter (2025) combine EEG crops, report segments, and multiple-instance learn-ing for label-efficient phenotyping. Their shuffled-report control changes patient–report pairings, whereas ours reassigns fixed class descriptions. EEG-CLIP learns from EEG–report alignment, uses class text prototypes for zero-shot prediction, and visualizes gradients of EEG–text similarity with respect to frequency-domain inputs (Ndir et al., 2025). Class descriptions also support direct EEG recognition: EmotionCLIP inserts emotion names into 16 templates and classifies by EEG–text matching (Yan et al., 2026). The EEG-PRIME preprint combines class-name prototypes, task in-structions, and multilevel conditioning across EEG tasks, and compares text encoders (Zhang et al., 2026); some downstream fine-tuning settings use task-specific classification heads. LaS builds on prototype classification and neural–text alignment, examining class descriptions as supervision and candidate references across independently trained decoders.

## 5 ANALYSIS AND DISCUSSION 

5.1 CLASS CORRESPONDENCE AND LANGUAGE CONFIGURATION 

Figure 5a–c compares training prompt configurations: fixed correct prompts (P0), a fixed derange-ment of seen-class descriptions (P1; π(c)̸ = c for every seen class), and random sampling of five correct training templates (P2). Panels (a,b) use one fixed prompt per class at inference; P2 uses P0 prompts. P1 maps closed-set predictions through the inverse permutation and uses true unseen descriptions for unseen-class prediction. P1 averages five derangement environments within subject or class split; Speech P2 averages three training seeds per subject. Closed-set P0/P1 differences are nonsignificant, whereas P1 reduces unseen-only SSVEP accuracy to near chance ( p < . 001 ). P1 reassigns an unchanged raw text embedding set, testing class– description correspondence while preserving embedding relationships. With full-row-rank seen text embeddings and defined prototypes, a text projection can restore all seen prototypes while the neural branch remains fixed (Appendix C.1). With fixed P0 prompts at inference, P2 worsens SSVEP closed-set ( p < . 001 ) and unseen-only decoding ( p < . 05 ), with nonsignificant MI/Speech differences. Panel (c) compares P0 and P2 using an ensemble of five held-out templates, none used in either training configuration. P2 improves MI and worsens closed-set SSVEP (both p < . 001 ); Speech and unseen-only SSVEP differences are nonsignificant. Models are trained independently for each dataset and encoder; transfer between datasets and record-ing systems remains to be evaluated. We observed unseen-class decoding in SSVEP, but not in Speech. Initial nonstationarity in SSVEP responses limits transfer from RW training to IW evalua-tion in Table 1 (Appendix D). Online control and long-term decoding stability also require evalua-tion. Future work could extend LaS from class-level prediction to real-time decoding of continuous be-havior and closed-loop control. Language could help neural interfaces learn users’ goals through interaction and generalize to new tasks. Language-guided feedback may also help users develop transferable control skills. 

## 6 CONCLUSION 

LaS uses natural-language class descriptions as references for supervision and prediction in neural decoding. Evaluations of independently trained models cover visual, motor, and speech decoding with scalp and intracranial recordings, showing its applicability to different encoder architectures. The learned representations support candidate-set reuse and label-supervised adaptation, and LaS enables conditional unseen-frequency decoding in SSVEP. Theoretical and language analyses char-acterize loss bounds and class correspondence; dual-sided attribution visualization shows contribu-tions from neural signal components and prompt words to the same class-specific matching score. These findings suggest that language can provide a reusable interface through which neural decoding systems can be configured and extended as users’ needs evolve.

A.3 STEADY -S TATE VISUAL EVOKED POTENTIALS (SSVEP) 

Data and main comparison. We use the SSVEP Benchmark dataset of Wang et al. (2017). It contains 35 participants and 40 stimulus classes. Each participant completed six blocks, each with one trial per class. Neural models in the main performance comparison use nine channels (Pz, PO5, PO3, POz, PO4, PO6, O1, Oz, O2) at 250 Hz. For each trial and channel, we subtract the mean over the 0.5-s pre-stimulus interval. A sixth-order Butterworth 6–64 Hz band-pass filter is applied with filtfilt to the complete recorded segment before window extraction. This processing path applies no further resampling or referencing. Each extracted window is standardized channelwise using its own statistics. Stimulus onset is t = 0 . An initial window (IW) of length L occupies [0 .14 , 0.14 + L) s. For random-window (RW) training, a valid sample-aligned start a is drawn uniformly with 0.14 ≤ a ≤

5.00 − L; all channels are extracted over the same interval [a, a + L). The matched neural-encoder comparison uses RW training and IW evaluation at 0.6, 0.8, and 1.0 s. Approximately 300,000 RW windows are generated from each fold’s training partition. The relevant time-domain inputs receive contiguous temporal masking at ratio 0.3 under the same condition for paired CLS and LaS encoders. Appendix D.2 defines the augmentation operation. Participants are divided into seven groups of five. In each fold, one group is evaluated, another is used for validation, and the remaining five groups (25 participants) are used for training. Each group serves as the evaluation group in turn. This subject split defines the Table 1 encoder comparison. 18 Table A.7: SSVEP protocol for the paired encoder comparison in Table 1.

D.1 SSVEP R ESPONSES AND SHORT -W INDOW EVALUATION 

An SSVEP is an oscillatory visual response whose frequency follows a periodic stimulus (Vialatte et al., 2010). The benchmark used here presents 40 targets distinguished by frequency and phase, with 5 s of stimulation per trial (Wang et al., 2017). Decoding commonly uses a short segment from such a trial. The benchmark study reported a mean visual latency of approximately 137 ms and recommended a shift of approximately 140 ms when extracting analysis windows (Wang et al., 2017). We use t0 = 0 .14 s after stimulus onset as a common analysis origin; physiological latency may vary among subjects. An initial window (IW) of length L spans [t0, t 0 + L); an onset offset δ

shifts it to [t0 + δ, t 0 + δ + L). Window length and onset offset are varied separately below. D.2 WINDOW AUGMENTATION AND CLOSED -S ET RESULTS
