## 摘要
Nimbus Studio是一个用于脑机接口（BCI）实验的可视化流水线平台：研究人员可在公共基准数据集或自己的记录上组装预处理、特征提取、解码和评估，并提供交叉验证评估协议（包括留一被试交叉验证）、BIDS导出以及自带Python模型类。对于任何此类平台，其数值是否可信都是一个合理的问题。我们通过一项对等研究来回答这个问题：在三个公共数据集（运动想象BNCI-2014-001/004；P300 BNCI-2014-009）上，在两种协议（每被试会话留出法，以及通过平台的planned-CV驱动执行的汇总留一被试交叉验证）下，对六条标准BCI解码流水线（CSP+LDA、黎曼MDM、通过平台自带代码节点实现的切空间逻辑回归、P300 xDAWN+LDA，以及深度ShallowConvNet和EEGNet）分别通过Nimbus Studio执行引擎和独立手写参考实现（直接基于MNE-Python、scikit-learn、pyriemann和braindecode构建）进行了评估。每条确定性流水线都与参考实现完全一致（在所有54个会话留出被试运行和所有CSP/MDM分组交叉验证折中，最大差异为0.00个百分点），包括通过自带代码节点和交叉验证编排的流水线；其余分组交叉验证单元在浮点精度范围内一致（最差情况为0.06个百分点，约每折一个试次）。随机深度模型在种子到种子的训练变异性范围内一致，该变异性通过两侧多种子重跑估计。因此，该平台的执行引擎在协议、范式和可扩展性层面上计算出的科学与参考技术栈相同。该平台可在https://studio.nimbusbci.com/获取，完整的测试装置和逐被试结果随本文一同提供，以供独立验证。

## Abstract
Nimbus Studio is a visual pipeline platform for brain-computer interface (BCI) experiments: researchers assemble preprocessing, feature extraction, decoding, and evaluation over public benchmark datasets or their own recordings, with cross-validated evaluation protocols (including leave-one-subject-out), BIDS export, and bring-your-own Python model classes. Whether its numbers can be trusted is a fair question for any such platform. We answer it with a parity study: six standard BCI decoding pipelines (CSP+LDA, Riemannian MDM, tangent-space logistic regression through the platform's bring-your-own-code node, P300 xDAWN+LDA, and the deep ShallowConvNet and EEGNet) were evaluated on three public datasets (motor-imagery BNCI-2014-001/004; P300 BNCI-2014-009) under two protocols (per-subject session holdout and pooled leave-one-subject-out cross-validation via the platform's planned-CV driver), once through Nimbus Studio's execution engine and once through independent, hand-written reference implementations built directly on MNE-Python, scikit-learn, pyriemann, and braindecode. Every deterministic pipeline matched the reference exactly (0.00 points maximum difference across all 54 session-holdout subject-runs and all CSP/MDM grouped-CV folds), including pipelines through the bring-your-own-code node and the CV orchestration; the remaining grouped-CV cells agree to floating-point precision (worst case 0.06 points, about one trial per fold). The stochastic deep models agreed within seed-to-seed training variability, estimated with multi-seed reruns on each side. The platform's execution engine therefore computes the same science as the reference stack across protocols, paradigms, and extensibility surfaces. The platform is available at https://studio.nimbusbci.com/, and the complete harness and per-subject results accompany this paper for independent verification.

## 1. 论文的核心问题与整体含义

- **研究背景**：脑机接口（BCI）研究通常依赖少量标准 Python 库（如 MNE-Python、scikit-learn、MOABB、braindecode、pyriemann），以手写脚本组合流水线。可视化流水线平台虽承诺提升可复现性、共享协议并降低门槛，但引入一个信任问题：**平台画出的流水线图，是否真的等价于研究者手写脚本所计算的内容？**

- **核心问题**：验证 Nimbus Studio 可视化 BCI 流水线平台的执行引擎，是否能在标准 BCI 解码任务上，复现基于规范库独立编写的手写参考实现。

- **整体含义**：若平台的结果与参考脚本一致，则研究者可以放心在正式研究中使用该平台；否则，平台生成的数字就不可信。论文通过“对等研究（parity study）”提供外部可复现证据，回应这种信任问题。

## 2. 论文提出的方法论

论文的核心方法不是提出新算法，而是**双实现对照验证**：每条流水线分别用两种方式实现，并在完全匹配的数据、超参数、数据划分和随机种子的条件下比较结果。

- **平台侧实现**：通过 Nimbus Studio 的图形节点组装流水线，由其生产执行引擎、planned-CV 驱动和自带代码（BYO）节点执行。

- **参考侧实现**：用一份不导入任何平台代码的独立脚本实现，直接调用 MNE-Python、scikit-learn、pyriemann 和 braindecode 等规范库。

- **匹配条件**：
  - 输入数据字节级一致；
  - 超参数完全一致；
  - 训练/测试划分一致；
  - 随机种子固定为 42（种子 43、44 仅用于估计深度模型训练变异性）。

- **主要流水线及关键设置**：

  - **CSP + LDA**：8 个 CSP 分量；scikit-learn 线性判别分析；无特征缩放。
  - **黎曼 MDM**：Ledoit-Wolf 协方差估计；黎曼度量。
  - **切空间 + 逻辑回归**：OAS 收缩协方差；切空间嵌入；多分类逻辑回归（最多 2000 次迭代）。平台侧通过 BYO Python 模型节点在隔离 worker 进程中运行。
  - **xDAWN + LDA**：MNE 的 xDAWN，每个事件类型 2 个分量；应用于展平后的滤波 epochs；随后使用 scikit-learn LDA。仅用于 P300 数据集的 LOSO 协议。
  - **ShallowConvNet**：使用 braindecode 的 ShallowFBCSPNet；30 个训练 epoch；batch size 64；Adam 优化器，学习率 $10^{-3}$；20% 分层验证集用于最佳 checkpoint 选择。
  - **EEGNet**：使用 braindecode 的 EEGNet；平台默认参数 $F_1=8$，$D=2$，dropout $0.25$，时间卷积核长度约为采样率的一半；训练循环与 ShallowConvNet 相同。

- **滤波设置**：运动想象流水线使用 4 阶 Butterworth 带通滤波，频带 8–30 Hz，零相位（filtfilt）；P300 流水线使用 1–30 Hz 的相同滤波设计。滤波均通过 MNE-Python 的公开 API 在两侧执行。

- **比较指标**：主要报告测试准确率（%），并计算差异 $\Delta$ = Nimbus 结果 − 参考结果，单位为百分点。

## 3. 实验设计

- **数据集**：

  - BNCI-2014-001：运动想象，22 通道，250 Hz，4 类，9 名被试，每被试 576 个试次。
  - BNCI-2014-004：运动想象，3 通道，250 Hz，2 类，9 名被试。
  - BNCI-2014-009：P300 拼写器，16 通道，256 Hz，目标/非目标二分类，10 名被试，每被试 1728 个 epochs，3 个 sessions。

- **评估协议**：

  - **会话留出法（session holdout）**：用标记为 `*train` 的 sessions 训练，用 `*test` 的 sessions 测试；划分来自数据包元数据，两侧一致。报告每名被试的测试准确率。
  - **留一被试交叉验证（LOSO）**：将所有被试合并为一个 cohort，每次留出一名被试作为测试集。平台侧通过其 planned-CV 驱动执行，参考侧通过手写逐被试循环实现。报告所有 out-of-fold 预测的 pooled accuracy，以及每个留出被试对应的 fold accuracy。

- **对比基准**：

  - 直接比较平台侧与参考侧的结果，而不是与某个外部排行榜比较。
