## ABSTRACT 

Irregular time series require models to answer temporal queries at arbitrary co-ordinates, yet existing approaches typically retain observation-dependent repre-sentations that must be repeatedly resolved for each query. We introduce HiPPO Functional Memory (HiPPO-FM), a functional-memory attention operator that compiles an irregular history into a reusable coordinate-addressable state. Instead of storing observation-indexed tokens or latent trajectories, HiPPO-FM writes observations into a fixed-rank functional space and performs direct coordinate evaluation through matched functional geometry. Kernel-smoothed HiPPO co-ordinates and Gram-based readout define a shared write/read mechanism, while observed-support self-attention enables content-dependent representations before compression. We characterize the induced finite-dimensional query space and derive an error decomposition separating functional geometry approximation from learned-memory mismatch. Across continuous-coordinate reconstruction, irregular representation learning, real-world extrapolation, and event-sequence prediction, HiPPO-FM consistently improves strong irregular time-series baselines, achieving strong reconstruction accuracy on Spiral, competitive performance across 20 UEA datasets, improved real-world extrapolation, and superior results on several irregu-lar event benchmarks. After encoding, the compact functional state can be reused across different query sets without reprocessing the observation history. 

## 1 INTRODUCTION 

An irregular time series is observed at times determined by data collection and queried at times specified by the task. Clinical measurements and environmental observations arrive at uneven intervals, while downstream analysis may require interpolation at missing times, extrapolation beyond the observed interval, or evaluation at a different temporal resolution (Rubanova et al., 2019; Schirmer et al., 2022). These requests operate on the same history at different query coordinates. The representation retained from that history therefore determines how new temporal coordinates can be evaluated. Existing approaches handle irregularity through continuous latent dynamics, time-aware attention, or structured representations of the observed samples. Latent ODEs and Neural CDEs model continuous hidden trajectories (Rubanova et al., 2019; Kidger et al., 2020); mTAN and ContiFormer introduce continuous-time structure into attention (Shukla & Marlin, 2021; Chen et al., 2023); and patch- or graph-based methods reorganize irregular observations before prediction (Zhang et al., 2024; Liu et al., 2026a). These approaches substantially improve how irregular histories are processed. In observation-indexed readouts, however, a requested coordinate is still resolved through a representation tied to the observed history. The form of this retained representation determines both how temporal queries access the history and what information must remain available for subsequent prediction. 

How can an irregular history be compressed into a function-valued memory that supports direct evaluation at arbitrary temporal coordinates? We address this question by giving the retained state an explicit continuous coordinate semantics. Observations are written into a shared functional coordinate system, and requested times are evaluated in the same system. We introduce HiPPO Functional Memory (HiPPO-FM) , a functional-memory attention operator that compiles an irregular history into a fixed-rank, coordinate-queryable state: 

DP 7 −→ BP , O(R) = Ψ θ (R)BP ,

where P is the observed support, R is the requested support, and BP ∈ RM ×d contains the retained functional coefficients. Prediction at a new coordinate is obtained by evaluating these coefficients through its functional features rather than resolving a new query against the full observation-indexed history. After encoding, the history-specific state occupies O(M d ) storage, independent of the number of observed timestamps, and the same state can be evaluated on different query sets. HiPPO-FM combines Legendre polynomial modes with interdomain kernel geometry to construct its temporal coordinate functions (Gu et al., 2020; Lazaro-Gredilla & Figueiras-Vidal, 2009). The same geometry governs the observation write and coordinate read, with a matched Gram solve accounting for correlations among the functional coordinates. Masked self-attention acts before the write, so content interaction determines what enters memory while the functional coordinates determine how that information is stored and queried. This MHA-to-FM ordering preserves the functional query space while allowing content-dependent representations to be formed before compression. The resulting state admits an explicit functional interpretation. The raw memory consists of interdo-main functionals of the kernel field induced by the projected observations, and the matched decoder restricts coordinate dependence to a finite-dimensional functional space. We characterize this space and derive a pointwise decomposition of approximation error into functional-geometry error and learned-memory mismatch. The coordinate-wise readout also makes the retained state reusable across different query sets without changing the prediction associated with a fixed requested coordinate. We study these properties through continuous-coordinate reconstruction, irregular representation learning across 20 UEA datasets, real irregular extrapolation on PhysioNet, and controlled functional-2memory diagnostics. Together, these settings evaluate both the predictive behavior of the representa-tion and its ability to support repeated coordinate queries. Our contributions are: • Coordinate-queryable functional attention. We introduce an attention operator that compiles an irregular history into a fixed-rank functional state and performs prediction by direct coordinate evaluation. The retained state supports arbitrary query sets with history-length-independent post-encoding storage. • Matched functional memory with pre-write content interaction. HiPPO-derived coordinates and interdomain kernel geometry define a common functional system for memory write and coordinate readout, while observed-support self-attention forms content-dependent representations before functional compression. • Functional analysis and reusable inference. We establish the semantics of the retained coeffi-cients and their finite query space, derive a geometry–memory error decomposition, and study the resulting representation across reconstruction, classification, extrapolation, and repeated-query evaluation. 

## 2 RELATED WORK 

Irregular Time-Series Modeling. Continuous-time models handle irregular observations through latent dynamics or time-aware interactions, including Latent ODEs, Neural CDEs, CRU, mTAN, and ContiFormer (Rubanova et al., 2019; Kidger et al., 2020; Schirmer et al., 2022; Shukla & Marlin, 2021; Chen et al., 2023). Recent forecasting methods instead reorganize irregular observations through warping, patches, graphs, or point-based representations (Zhang et al., 2023; Yalavarthi et al., 2024; Zhang et al., 2024; Hu et al., 2025; Liu et al., 2026b;a). Frequency-based modeling provides another way to summarize irregular observations, as in TFMixer (Qiu et al., 2026). HiPPO-FM differs in the representation retained after encoding: it stores a coordinate-queryable functional state rather than an observation-indexed collection of tokens, patches, graph nodes, or latent trajectories. 

Compact and Functional Memory. Linear attention and memory-efficient sequence architectures compress sequence interactions into compact statistics or latent states (Katharopoulos et al., 2020; Jaegle et al., 2022; Feng et al., 2024). HiPPO represents signal histories through structured orthogonal polynomial projections (Gu et al., 2020), while interdomain kernel methods define function-valued features through linear functionals (Lazaro-Gredilla & Figueiras-Vidal, 2009). Recent functional attention and memory-inspired operators explore basis-coefficient representations beyond token-level attention (Kiyohara et al., 2026; Xiao et al., 2026). HiPPO-FM differs in using these coordinate functions to define both a retained functional state and its direct temporal readout; Section 3 develops this operator and its representation properties.

The theorem applies to a fixed geometry; separately trained configurations may also differ through their learned kernels and optimization trajectories. 3.5 REUSABLE FUNCTIONAL STATES 

After encoding, HiPPO-FM retains a history-specific functional state SP = ( BP , t min , s P ), which is independent of the requested query set. A new query set can therefore be evaluated directly through the coordinate readout without recomputing the observation history. This separates history encoding from coordinate evaluation and allows the same functional state to support multiple downstream query resolutions. The persistent storage of the functional state is O(M d ), independent of the number of observed timestamps N . For a new query set with NR points, the readout requires only functional feature construction and coefficient evaluation, while the encoder, functional write, and geometry computation are performed once and reused across queries. Detailed complexity accounting and implementation details are provided in Appendix B.

## 5 CONCLUSION 

We introduced HiPPO-FM, a functional-memory attention operator that maps irregular observations to a fixed-rank, coordinate-addressable state. HiPPO-derived functional coordinates and matched kernel geometry define both memory construction and arbitrary-coordinate readout, with content interaction applied on the observed support before compression. The resulting state has O(M d )

post-encoding storage and can be reused across query sets. Experiments evaluate this representation through Spiral reconstruction, 20 UEA classification datasets, PhysioNet extrapolation, and repeated-query diagnostics. The method therefore provides an explicit interface for encoding an irregular history once and evaluating the retained functional state at requested coordinates. Across these experiments, it performs strongly on controlled reconstruction and PhysioNet extrapolation, remains competitive on UEA, and supports consistent repeated querying. Observed-support self-attention still has quadratic encoding cost, while the functional write can be sensitive to sampling density and finite-rank geometry. Future work should study lighter encoders and density-aware or adaptive functional bases.

Neonate records seizure-start events from 79 patients; only 48 patients have at least two seizures. BookOrder contains buy and sell events with sequences clipped to length 500 and a maximum inter-event gap of 70, while StackOverflow records user badge-reward histories over two years. The real-data folds follow the partition counts above; MIMIC, StackOverflow, and BookOrder use five folds, whereas Neonate and Traffic use four folds. The event objective evaluates the next-event mark and time from each observed prefix.
