## 摘要
贪心状态边界搜索（GSBS）识别相对稳定的神经活动模式之间的转变，但重复的候选评估使大规模分析成本高昂。HP-GSBS 是一个开源 Python 包，围绕可复用的区间贡献和相关性统计量重新组织搜索过程。流式候选缩减和局部细化进一步减少了重复工作；CPU、PyTorch CUDA 和 Triton 后端共享相同的顺序分割决策。在七个受控工作负载（每个包含两次实现）中，相同输入下的中位加速比为 154 至 1730 倍。所有 168 次优化执行均复现了原始边界和所选状态数，最大绝对 t 距离差异为 $1.88\times10^{-11}$。四个冻结 EEG 记录提供了补充验证，包括一个完整的从输入到分割的应用示例。批处理、版本化结果持久化和可选的低内存执行支持记录集合及更长输入。通过消除冗余计算，HP-GSBS 使既有的神经状态分割更快，同时保持其科学输出。

## Abstract
Greedy State Boundary Search (GSBS) identifies transitions between relatively stable neural activity patterns, but repeated candidate evaluation makes large analyses expensive. HP-GSBS is an open-source Python package that reorganizes the search around reusable interval contributions and correlation statistics. Streaming candidate reduction and local refinement further reduce repeated work; CPU, PyTorch CUDA and Triton backends share sequential segmentation decisions. Across seven controlled workloads with two realizations each, median same-input speedups range from 154 to 1730 times. All 168 optimized executions reproduce original boundaries and selected state counts, with maximum absolute t-distance difference $1.88\times10^{-11}$. Four frozen EEG recordings provide complementary validation, including a complete input-to-segmentation application example. Batch processing, versioned result persistence and optional low-memory execution support recording collections and longer inputs. By removing redundant computation, HP-GSBS makes established neural-state segmentation faster while preserving its scientific outputs.

- **问题背景**：自然体验是连续的，但神经活动往往在事件内部保持相对稳定，并在事件边界处发生转变。数据驱动的神经状态分割将这种时间组织与感知、记忆等认知过程联系起来。
- **核心方法**：贪心状态边界搜索（GSBS）用于识别神经状态转变的位置和数量，其状态级扩展揭示了皮层中部分嵌套的转变层级。
- **瓶颈**：GSBS 的计算成本主要来自搜索过程。每个候选边界都要反复重建状态模板并与观测序列比较；双边界搜索会使候选空间随区间长度呈二次增长；插入后的细化会重复计算未变化区间的统计量。这些成本在跨被试、刺激和特征集的分析中快速累积。
- **本文工作**：HP-GSBS 是一个开源 Python 包，通过可复用区间统计量、流式候选缩减、局部细化和多后端支持，在不改变科学输出的前提下大幅加速 GSBS。

## 2. 方法论

HP-GSBS 的核心是将 GSBS 计算重组为可复用的区间贡献和相关性统计量。

- **区间得分复用**
  - 设输入矩阵 $X\in\mathbb{R}^{T\times P}$，其中 $T$ 为时间点，$P$ 为特征数。
  - 对每个时间点标准化得到 $z_t$，定义前缀和
    $$
    A_b=\sum_{t<b}(x_t-\bar{x}_t\mathbf{1}),\qquad B_b=\sum_{t<b}z_t.
    $$
  - 区间 $[a,b)$ 对目标的贡献可写为
    $$
    F(a,b)=\frac{\Delta B_{ab}^T\,\Delta A_{ab}}{T\sqrt{P-1}\,\|\Delta A_{ab}\|_2},
    $$
    其中 $\Delta A_{ab}=A_b-A_a$，$\Delta B_{ab}=B_b-B_a$。
  - 替换一个状态 $[a,b)$ 为两个或三个状态时，只需计算增量：
    $$
    \Delta_1(i)=F(a,i)+F(i,b)-F(a,b),
    $$
    $$
    \Delta_2(i,j)=F(a,i)+F(i,j)+F(j,b)-F(a,b).
    $$
  - 预先构建区间得分表 $Q_{a,b}=F(a,b)$，使每个候选只需少量查表，而非重新计算模板。
  - 流式候选缩减按顺序评估合法候选并只保留最大值，避免额外的二次候选得分数组。
  - 窗口局部细化只重新评估请求的边界邻域，活动块缓存复用局部胜者，直到分区发生变化。

- **基于二维前缀的 t 距离计算**
  - GSBS 使用 Welch t 距离比较状态内相关性 $W$ 和相邻状态间相关性 $A$：
    $$
    TD=\frac{\mu_W-\mu_A}{\sqrt{v_W/n_W+v_A/n_A}}.
    $$
  - HP-GSBS 构建二维前缀表，分别记录合法时间对的计数、相关性和相关性平方，通过四个角点的矩形查询获得均值和无偏方差。得到区间端点后，评估一个分区只需 $O(K)$ 次查询，而不必重扫所有时间对。
  - 时间排除参数 $d_{\min}$ 编码在配对掩码中。

- **后端与实现**
  - CPU 后端使用 NumPy/SciPy 和 Numba 编译搜索。
  - PyTorch CUDA 后端批量执行矩阵乘法和前缀操作。
  - Triton 后端融合区间差分、点积和范数计算。
  - 三个后端共享顺序搜索控制器和细化逻辑，GPU 将预计算统计量传输到 CPU 控制器，保持顺序搜索依赖不变。
  - 默认使用 FP64，支持 Full-Q/Prefix2D 快速路径；可选 CPU 低内存模式用有界候选块和特征矩统计量避免完整配对表，但双边界候选域仍可能为二次。

## 6. 主要结论与发现

- HP-GSBS 通过区间统计量复用和流式/局部优化，将 GSBS 的计算成本大幅降低。
- 在七个受控工作负载中，相同输入下中位加速比为 154 至 1730 倍。
  - 中心配置：官方 64.7 s，CPU 0.142 s，PyTorch 0.081 s，Triton 0.099 s。
  - 在 $T=768$ 时，PyTorch 中位加速比达到 1730 倍。
- 所有 168 次优化执行均复现原始边界和所选状态数，最大绝对 t 距离差为 $1.88\times10^{-11}$。
- 四个冻结 EEG 记录验证了在真实数据上的数值一致性，所选状态数和边界历史完全匹配。
- CPU 上的加速独立于 GPU，说明计算复用的收益本身就很显著；GPU 进一步降低延迟。
- 低内存模式可在保持正确性的同时将长输入峰值内存从约 1.6 GB 降至约 0.2–0.5 GB，并显著缩短运行时间。
- 批处理吞吐实验表明：短输入任务适合 GPU 小批量批处理；高 $K$ EEG 任务更适合 CPU 多 worker 并行。
- 历史扩展工作负载显示，原先小时级任务可在不到 1 秒内完成。

## 7. 优点

- **科学输出保持严格一致**：不仅在最终状态数层面一致，还逐边界、逐状态模式、逐 t 距离检查，最大误差在浮点噪声量级。
- **可复用区间统计量设计巧妙**：用前缀表 $Q_{a,b}$ 将候选评估从重复模板重建变为常数时间查表，同时避免不必要的二次得分数组。
- **共享顺序搜索控制器**：CPU、PyTorch CUDA、Triton 三种后端共享同一决策逻辑，降低实现分歧风险。
- **多种执行模式**：提供吞吐优先的 Full-Q 路径和内存优先的低内存特征矩路径，适应不同资源约束。
- **批处理和版本化持久化**：支持记录集合处理、CPU worker 和 GPU 批处理、原子保存与断点恢复，便于研究流程集成。
- **可复现性材料完整**：论文提供数据、观测值、绘图代码、重跑协议和 Zenodo 归档，且可无需重新拟合即可重新生成所有图。

## 8. 不足与局限

- **实验规模与外部效度**
  - 受控基准只覆盖合成分段信号，真实 EEG 只有 4 个冻结记录，来自同一数据集；对其他神经模态（如 fMRI、MEG、不同采样率）的验证有限。
  - 性能数据来自单一笔记本级硬件，未展示多 GPU、服务器 CPU 或不同 GPU 架构下的表现。
- **低内存模式的限制**
  - 低内存模式使用特征空间矩统计，在相关性接近常数时可能损失精度；实现中通过有界分块和拒绝退化结果来缓解，但这仍属于实验性选项。

- **部分实验并非同一版本**
