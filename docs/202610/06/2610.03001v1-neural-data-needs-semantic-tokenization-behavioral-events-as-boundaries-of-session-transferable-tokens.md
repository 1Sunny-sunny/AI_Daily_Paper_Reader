## Abstract
Extracellular electrophysiology records a different set of neurons in every session. Neural foundation models embed each neuron and each session into their tokens, so every new session is an input they have never seen, and they fail to generalize to it. A tokenizer for new sessions needs a unit that every session shares and that carries behavior. Population activity offers such a unit. It evolves on a low-dimensional manifold that persists across neuronal turnover and across animals once sessions are aligned. This manifold changes regime at task events such as stimulus onset and movement onset. Within each regime the population occupies a state, the part of the manifold it spans between two events, and each state carries its own behavioral meaning. We propose Tokenization with States (TWS), which segments each trial, one repetition of the task, at these events and converts every state into tokens of population geometry, with no neuron or session embedding. On held-out International Brain Laboratory (IBL) sessions, TWS decodes movement even from regime boundaries that carry no information about the target, while a per-neuron foundation model pretrained on those sessions decodes at chance. Frozen after training on mice alone, TWS transfers to macaques and Utah arrays with only a linear probe. On reach direction, a target that its boundaries do not define, it achieves a Matthews correlation of 0.23, where the event time alone achieves $0.01$. For cross-session generalization, the token matters more than the model on top.

- **论文重写的核心主张**：对于跨会话泛化，**“token 是什么”比 token 之上的模型更重要**。

## 2. 方法论

### 2.1 总体思想
提出 **Tokenization with States（TWS）**，将每个 trial（任务的一次重复）按行为事件边界切分为 3 个状态：
- $S_0$：刺激前状态；
- $S_1$：刺激后到运动开始的状态；
- $S_2$：运动后状态。

每个状态都通过群体活动得到一个不含神经元身份的 token。

### 2.2 关键流程
对每个 trial 的群体活动 $X \in \mathbb{R}^{T \times N_s}$（$T$ 为时间 bin 数，$N_s$ 为该会话神经元数）：

1. **预处理**：对每个神经元进行 $\log(1+x)$ 变换，并做会话内 z-score 标准化（仅使用无标签活动）。

2. **软边界分割**：用 sigmoid 门控函数按已知事件时间（刺激开始 $b_{\text{stim}}$、首次运动 $b_{\text{move}}$）切分状态，并引入可学习偏移 $\Delta_1,\Delta_2$：
$$
w_1(t) = \sigma\left(\frac{b_{\text{stim}}-t}{\gamma}\right),
\quad
w_2(t) = \sigma\left(\frac{t-\tau_1}{\gamma}\right)\cdot\sigma\left(\frac{b_{\text{move}}-t}{\gamma}\right),
\quad
w_3(t) = \sigma\left(\frac{t-\tau_2}{\gamma}\right)
$$
其中 $\tau_1 = b_{\text{stim}}+\Delta_1$，$\tau_2 = b_{\text{move}}+\Delta_2$；$\gamma$ 为温度参数，偏移量由所有会话共享。

3. **状态加权汇总**：对每个状态 $k$，计算 $\bar{x}_k = \sum_{t} \bar{w}_k(t)\cdot x(t) \in \mathbb{R}^{N_s}$，得到该状态下每个神经元的平均发放水平。

4. **置换不变的聚合**：对每个状态：
   - 逐一神经元得到 $u_n = f_{\text{coord}}(p_n)+f_{\text{act}}(\bar{x}_{k,n})$；
   - 用共享**交叉注意力（CrossAttention）**聚合无序神经元集合，不引入位置编码；
   - 对每个状态生成 $k_{\dim}=2$ 个 token，维度 $d=256$；
   - 通过 **Gram-Schmidt 正交化**得到 Grassmannian 流形上的标准正交基 token。

因此每个 trial 从 $N_s$ 个神经元变为 $K \times k_{\dim} = 3 \times 2 = 6$ 个 token；该过程**对神经元顺序置换保持不变**。

5. **Backbone + 解码**：将 6 个 token 送入 backbone（默认 CNN），由线性探针（或每个状态一个线性头）预测行为目标。

### 2.3 预训练与微调
- **几何预训练**：无标签自监督，重建被遮蔽的状态均值，并促进连续状态的 Grassmannian 子空间接近正交，公式为：
$$
L = L_{\text{MSE}} + \lambda_{\text{div}}L_{\text{div}} + \lambda_{\text{geo}}L_{\text{geo}}
$$
其中 $L_{\text{div}}$ 强调状态 token 多样性，$L_{\text{geo}}$ 增加相邻状态子空间间测地距离。

- **行为微调**：在 token 上训练行为解码头。

## 3. 实验设计

### 3.1 数据集
论文在多个公开数据集上评估：

- **IBL Brain Wide Map**：243 个 Neuropixels 会话、109 只小鼠；主要基准。
- **Steinmetz 2019**：39 个 Neuropixels 会话、10 只小鼠。
- **Gallego et al.**：111 个 Utah 阵列会话、4 只猕猴；用于跨物种迁移实验。
- **NLB MC Maze**：23 个 Utah 阵列伪会话、1 只猕猴。

### 3.2 对比方法
- **逐神经元基础模型**：POYO；
- **逐会话/对齐方法**：CEBRA、NEDS；
- **对齐 PCA**：将每个会话旋转到共享 PCA 模板；
- **无对齐 PCA**：作为下限；
- **群体统计特征**：population statistics；
- **PerceiverIO**：与 TWS 相同的 backbone，但 token 不含神经元/会话嵌入；
- **事件时间信息**：仅使用一阶运动 bin（无神经数据）作为标签信息的上界参考。

### 3.3 评估协议
- **跨会话解码**：留一会话交叉验证（leave-one-session-out），对未见会话用线性 Ridge 探针；
- 对离散变量报告 **MCC**，连续变量报告 **R²**，并测量会话可识别性 $MI(h;\text{session})/H(\text{session})$。

### 3.4 主要结果
- 在 IBL 留出的 53 个会话上，TWS 运动解码 $0.565$、反应时间 $R^2=0.402$，显著优于 POYO、NEDS、CEBRA 等基线；
- 冻结 IBL 上训练的 TWS，在猕猴数据集上仅使用线性探针即可迁移，并在到达方向上取得 $0.23$ MCC；
- **边界消融实验**表明：移除或错位行为边界会大幅降低性能，说明 token 划分边界对语义提取至关重要；
- **Tokenizer × backbone 矩阵实验**显示，backbone 类型影响较小，而 tokenizer 替换会显著改变解码性能。

## 6. 主要结论与发现

- **语义 token（基于行为边界的状态 token）比神经元身份 token 更适合跨会话神经解码**；
- TWS 在不依赖神经元或会话嵌入的情况下，即可在完全未见会话上进行有效解码；
- **TWS 在跨会话上优于逐神经元模型**，即使后者已在目标数据上进行预训练；
- **事件边界本身为 token 提供了强先验**：边界位置消融实验表明，边界信息对运动与反应时间等目标非常重要，但这同时也意味着这些目标的部分可解码性来自边界而非纯神经活动；
- **会话身份与行为信息占据不同方向**：TWS 保留会话身份信息的比例低于 PerceiverIO 与 POYO，而保留行为可解码信息更多；
- **在少量标注会话条件下，TWS 的数据效率远高于基线**：仅 5 个会话训练的探针表现优于基线在所有会话上训练；
- 在 Type B 变量（如 choice、block 等依赖特定神经元的变量）上，所有跨会话方法接近随机，这与 TWS 的设计目标一致。

## 8. 不足与局限

- **对行为事件边界的依赖限制了应用范围**：仅适用于有明确任务事件和 trial 结构的实验数据，无法直接用于自由行为或连续记录数据。
- **边界信息泄漏问题**：在运动与反应时间等目标上，TWS 的优势部分可能来自标签定义与边界事件的强耦合，影响了“纯神经解码”结论的强度。
- **Type B 变量无法跨会话解码**：choice、block 等依赖特定神经元的变量在跨会话实验中几乎处于随机水平，说明 TWS 的能力边界明确但局限。
- **状态内时间轨迹被平均掉**：TWS 对每个状态只保留群体几何摘要，放弃了状态内的时间动态，可能丢失携带特定行为信息的高时间分辨率模式。
- **未报告算力与计算成本**：缺少 GPU 型号、训练时长等资源统计，不利于了解实际部署成本。
- **公平性问题仍存在**：TWS 与对比模型在是否可以使用行为事件边界上存在结构性差异，边界输入构成了一种额外先验信息。
- **跨物种迁移仍依赖线性探针与少量标签**，并非完全零样本解码。
