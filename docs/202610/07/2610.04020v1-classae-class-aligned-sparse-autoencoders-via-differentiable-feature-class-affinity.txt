# ABSTRACT 

Sparse Autoencoders (SAEs) began as an unsupervised tool for decomposing neu-ral representations into sparse, interpretable features, and are increasingly used not only for passive analysis but also for active interventions such as unlearning, bias mitigation, and concept editing. A central challenge for these editing and steering methods is reliably matching features to target concepts; most current approaches address this by computing post-hoc scores over an already-trained, frozen dictionary. We instead introduce ClasSAE, a novel method that both auto-matically assigns classes to features and guides the encoder toward class-separable representations during training. Specifically, we apply a differentiable top-k opera-tor to a trainable feature–class affinity matrix with per-feature budgets, coupling the features selected for each sample to the classes they are trained to represent. Because gradients flow through the selection of active features rather than only through their magnitudes, the encoder and the affinity matrix co-adapt rather than being fit in separate stages. The result is a dictionary that is both class-separable and class-annotated, with no need for post-hoc probing. We propose three variants for enforcing sparsity within this framework, which achieve comparable overall performance with slightly different trade-offs. Using CLIP ViT-L/14 embeddings on ImageNet, we show that the learned affinity matrix agrees closely with an independently estimated post-hoc feature-class matrix computed on held-out data. The model also supports direct class prediction from the encoder and affinity matrix alone, without a separately fitted classifier, and its more class-aligned encoder yields improved separation in Targeted Probe Perturbation evaluations. These results show that known concept annotations can be used not merely to locate relevant features in an SAE dictionary after training, but also to shape the dictionary itself during learning. Code is available at https://github.com/St0pien/ClasSAE .

# 1 INTRODUCTION 

Sparse autoencoders (SAEs) have become a leading tool for mechanistic interpretability, decomposing dense activations into sparse, putatively monosemantic features in a purely unsupervised way (Huben et al., 2024; Bricken et al., 2023; Templeton et al., 2024). However, recent work questions whether this unsupervised decomposition is even well-defined: Leask et al. (2025) show that SAEs do not converge to a canonical set of ground-truth units, and different random seeds or hyperparameters yield dictionaries that disagree substantially with one another (Paulo & Belrose, 2026). Despite this, SAEs are widely used not only for analysis but also for intervention , including activation steering, unlearning, and bias mitigation (Cywi´ nski & Deja, 2025; Ahsan & Wallace, 2026; Cho & Hockenmaier, 2025). All of these methods work by editing the small subset of features responsible for a target concept. This is exactly where the unsupervised nature of SAEs becomes a liability: since training has no access to the concepts practitioners care about, every such application must first solve a separate post-hoc matching problem, probing a frozen dictionary to infer which features correspond to which concept. This two-stage recipe inherits the instability noted above: a target concept may end up split across several features, entangled with other concepts, or absent from the dictionary altogether, and nothing during training prevents this. 1arXiv:2610.04020v1 [cs.CV] 2 Oct 2026 Figure 1: ClasSAE jointly learns a sparse dictionary and a class affinity matrix, enabling classifier-free class prediction and targeted editing: removing only the features exclusive to a class erases that class from the reconstruction while shared features are preserved. We observe that in most of these intervention settings, the relevant concepts are not in fact unknown: unlearning a category or mitigating bias along a known attribute both presuppose that the practitioner knows in advance which classes should be disentangled. Rather than hoping that an unsupervised SAE will isolate these concepts and searching for them afterwards, we argue that this knowledge should directly shape training. To this end, we introduce ClasSAE , an SAE that learns a class-annotated, class-separable dictionary directly during training rather than relying on post-hoc analysis. We provide a general visual overview of the proposed framework in Figure 1. Our contributions are as follows: • Automatic feature–class association. We learn a feature–class affinity matrix jointly with the SAE, removing the need for post-hoc probing to identify which features correspond to which class. • Class-aligned encoder–decoder. The encoder and decoder are trained so that the dictionary is class-separable by construction, rather than merely reconstruction-optimal with class structure emerging only incidentally. • Three sparsity variants under a shared framework. We propose three ways of enforcing sparsity in the latent representation, which trade off reconstruction quality against class alignment. • A single joint training objective. We combine these mechanisms into one end-to-end objective, so the dictionary and the affinity matrix co-adapt within one training process rather than being fit in separate stages. This general framework yields a single model with multiple applications: classification (Section 4), interpretability (Figure 2), and targeted concept editing (Section 4). • Experimental evaluation. We assess the agreement of ClasSAE’s affinity matrix with an independently estimated post-hoc feature–class matrix, its ability to support classifier-free class prediction, and its performance on Targeted Probe Perturbation, comparing against other SAE architectures and variants of our own method. 

# 2 RELATED WORK 

Sparse autoencoders and their failure modes. SAEs decompose activations into sparse linear combinations of learned directions (Sharkey et al., 2022; Bricken et al., 2023; Huben et al., 2024) and scale to frontier models (Templeton et al., 2024). Architectural work has concentrated on the sparsity constraint: k-sparse and top-k SAEs enforce an exact count (Makhzani & Frey, 2014; Gao 2et al., 2024); Gated SAEs decouple which features fire from how strongly (Rajamanoharan et al., 2024a); JumpReLU uses a discontinuous threshold (Rajamanoharan et al., 2024b); BatchTopK moves the budget from the sample to the batch, so individual samples may use more or fewer latents at fixed average sparsity (Bussmann et al., 2024); Matryoshka SAEs impose a nested hierarchy over dictionary prefixes (Bussmann et al., 2025; Zaigrajew et al., 2025). Lee et al. (2025) instead enforce approximate quasi-orthogonality among dictionary elements, which enables a Top-AFA activation function that removes the k hyperparameter entirely by choosing the number of active features whose reconstruction most closely matches the input’s L2 norm.

A parallel line documents what SAEs get wrong: SAEs do not reliably de-compose concepts into canonical units (Leask et al., 2025), and apparently monosemantic latents are absorbed 

into their children (Chanin et al., 2025); dictionaries are unstable across seeds, motivating constrained param-eterizations (Fel et al., 2025); much of the residual is linearly predictable “dark matter” (Engels et al., 2025); and the i.i.d. prior of per-token SAEs con-flicts with the temporal structure of language (Bhalla et al., 2026; Lubana et al., 2026). SAEBench (Karvonen et al., 2025) consolidates several of these diagnostics, one of which we adopt in our experiments (see Sec-tion 4). We hypothesize that these fail-ure modes stem, at least in part, from the absence of any external signal guiding the dictionary toward useful structure; the class-alignment mecha-nism we introduce in this work is one candidate for such a signal, though our focus here is on evaluating its practi-cal, measurable benefits rather than directly testing this broader hypothe-sis. 

Automatic feature interpretation and labeling. A separate line auto-mates the post-hoc labeling step itself. Bricken et al. (2023) establish the basic dictionary-learning setup that makes such labeling meaningful in the first place. Paulo et al. (2025) generate natural-language feature explanations at scale using LLMs and, notably, evaluate them via intervention rather than input examples alone. Gur-Arieh et al. (2025) show that input-only explanations are incomplete, since a feature’s meaning also depends on its effect on the output, and propose output-centric descrip-tions from steering/unembedding, finding input- and output-centric signals complementary. SALVE (Flovik, 2026) similarly correlates SAE features with visual concepts, using Grad-CAM (Selvaraju et al., 2016) and activation maximization to explain individual features. All of these approaches treat labeling as a separate step applied to an already-trained, frozen dictionary; ClasSAE instead produces class annotations as a direct byproduct of training, with no explanation pipeline required. 

SAEs as intervention mechanisms. SAEs are increasingly used to directly edit model behavior. SAEuron (Cywi´ nski & Deja, 2025) trains a BatchTopK SAE and scores features to find those tied to a target concept, then ablates or negatively scales them to unlearn it from diffusion models. SAEmnesia (Cassano et al., 2026b) is closest in spirit to ClasSAE: a two-stage scheme first trains an unsupervised SAE, then collapses each class onto a single latent coordinate. ClasSAE differs on both counts, using one joint objective rather than two stages, and a per-feature affinity matrix rather than one coordinate per class, so features can be shared across classes rather than duplicated. This avoids wasting capacity and, for unlearning, lets us ablate only class-exclusive features while shared features are preserved for 3retain accuracy. Cassano et al. (2026a) find SAEs good at locating concepts in diffusion models but show that direct feature ablation pushes activations off-manifold, causing artifacts, and use the located features to guide patch-swapping instead. CRISP (Ashuach et al., 2026) trains a LoRA adapter (Hu et al., 2022) guided by SAE features to suppress a target concept while preserving unrelated ones in LLM unlearning. Ahsan & Wallace (2026) apply the locate-then-ablate recipe to detect and mitigate racial bias in healthcare LLMs via probing. Unlike these approaches, which first train an SAE and then annotate its features, ClasSAE folds both goals into a single training objective. 

Concept supervision and differentiable selection. Relaxations of sorting and top-k include Gumbel reparameterizations (Jang et al., 2017) and optimal-transport formulations (Xie et al., 2020); we use LapSUM (Struski et al., 2025), which accepts a budget and returns weights summing exactly to it, giving a differentiable selection signal for the per-feature ki in ClasSAE. Concept activation vectors and interpretable basis decompositions map latent spaces to human-named ideas (Kim et al., 2018; Zhou et al., 2018), later automated (Ghorbani et al., 2019; Bykov et al., 2023), while Concept Bottleneck and Concept Embedding Models enforce such representations during training (Koh et al., 2020; Espinosa Zarlenga et al., 2022). ClasSAE sits between these traditions: the encoder and decoder stay unsupervised at inference, and only a budgeted auxiliary head carries class semantics.

An Out-of-the-Box Classifier Beyond annotation, the same construction gives ClasSAE a classifier for free: because M is trained to agree with the encoder’s own selections, the pair (SAE, M ) can be read directly as a ready-to-use classifier, with no additional training or fitting required. Prediction follows the same construction as the agreement loss itself: encode x, compute π(x), and score each class by π(x)⊤M (or π(x)⊤ ˆM for the post-hoc baselines); the predicted class is the argmax over this score. No separate classifier is fit at any point. With this construction we can report standard classification metrics in Table 3. ClasSAE L1 is the strongest predictor here, and the other two ClasSAE variants trained with true labels follow closely. The only real competitor is Standard, unsurprising given its strong showing in Table 2. More interesting is that Standard actually outperforms ClasSAE (the soft-gradient variant) on accuracy and F1, even though it has lower FVE in Table 1. We read this as evidence that reconstruction quality and class separability are, at some point, in direct competition: the soft-gradient ClasSAE trades some classification performance for the best FVE among the ClasSAE variants, while Standard’s comparatively poor reconstruction leaves more of its representational capacity free to encode class structure. 

Editing What You Named If the agreement loss genuinely reshapes the encoder rather than just labeling it, intervening on a target class should be easier and leak less into others. We test this with the standard TPP benchmark (Karvonen et al., 2025), at k ∈ { 20 , 200 , 600 } selected features per class, and a custom variant TPP PMI described in Section D; a further unlearning task on a joint classifier, using the same intervention, is reported in Section E. At TPP 20, ClasSAE Shuffle scores best, but this is an artifact of the top-k sensitivity we acknowledge in Section D rather than a real advantage: ClasSAE variants simply need more features to represent a class than an unsupervised encoder does. At TPP 600 and TPP PMI, all three ClasSAE variants lead, and at TPP 200 ClasSAE and ClasSAE Hard lead. ClasSAE Hard and ClasSAE L1 achieve this with the lowest edit strength of all architectures, and the soft-gradient ClasSAE with lower edit strength than every baseline except Top-AFA, whose TPP PMI score is near zero. This indicates a genuinely better-separated encoder. 

# 5 CONCLUSIONS 

We introduced ClasSAE, an SAE that automates feature-class association and guides the encoder toward class-separable representations, with three sparsity variants. We derived theoretical properties of this construction, motivating both the architecture and our evaluation design. Empirically, ClasSAE delivers a strong suite of downstream capabilities, including out-of-the-box classification and precise, low-strength intervention. It leads on annotation faithfulness, classification, and TPP at larger k and under PMI-graded editing, at the cost of somewhat lower reconstruction quality and weaker results at small TPP k. Across these trade-offs, we recommend ClasSAE Hard as the default variant, as it 9offers the best balance overall. Limitations SoftTopK is a major computational bottleneck, limiting scaling to larger dictionaries and to very large class counts, though 214 classes is already an unlikely regime in practice.

As a complement to the targeted probe perturbation results in Section 4, we evaluate the same PMI-graded intervention on a joint multi-class classifier rather than independent per-class probes, testing whether selective ablation still works when classes must be distinguished by a single shared decision boundary rather than C separate ones. Table 5 reports the drop in forget accuracy under the graded edit relative to baseline, minus the same drop under the shuffled edit ( Graded vs. Shuffled Forget Drop ); the drop in retain accuracy relative to baseline ( Retain Drop ); and Edit Strength , the mean L1 norm of the strength vector, as in Section 4. Baselines like JumpReLU tell the opposite story: they remain effective even after shuffling, meaning their selected features are largely interchangeable and carry little differentiated class information individually. # F QUALITATIVE EXAMPLE : P ATCH -T OKEN CLASS ALIGNMENTS 

As a further demonstration of ClasSAE’s applicability beyond the CLIP/ImageNet set-ting used throughout the paper, we train ClasSAE on patch tokens from DINOv3 (facebook/dinov3-vitb16-pretrain-lvd1689m ), assigning every patch token the class label of its parent image rather than any finer-grained, per-patch segmentation label. Despite this deliberately naive labeling scheme, in which a single whole-image class is spread uniformly across all 15 of an image’s patch tokens, we find that ClasSAE still learns individual features that fire specifically on the image region corresponding to their claimed class. Figure 2 shows two examples on an image containing both a Siamese cat and an American Stafford-shire terrier. The top row shows features claimed by “Siamese cat, Siamese,” each activating on the cat rather than the dog, with sharper spatial localization for the lower-budget, more specialist feature (feat. 1277, ki = 1 .0) than for the higher-budget, more generalist one (feat. 15, ki = 8 .0). The bottom row shows the analogous pattern for features claimed by “American Staffordshire terrier, Staffordshire terrier, American pit bull terrier, pit bull terrier,” localizing on the dog. This is a further example of how ClasSAE can be used in practice, extracting spatially meaningful, class-aligned features even from a naive, image-level labeling scheme with no segmentation supervision. 16
