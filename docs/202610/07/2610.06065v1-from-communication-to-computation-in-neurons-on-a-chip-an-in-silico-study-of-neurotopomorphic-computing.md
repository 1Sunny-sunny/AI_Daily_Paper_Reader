## 摘要
活体神经元网络通过循环的细胞与群体动力学转换输入，但目前尚不清楚哪种网络结构支持哪种计算。芯片上的神经元将这一问题转变为设计问题，因为微通道引导轴突生长并决定网络结构。我们引入了IC³，一种通信驱动计算的综合表征方法，它通过神经元动力学、功能性通信和结构支持来刻画网络状态。我们在计算机模拟中将九种结构实现为基于电导的脉冲网络，并在频率解码、时序顺序辨别和衰减记忆任务上对每种结构进行了测试。以前馈为主的电路解码效果最好。顺序链和微通道二极管具有最低的IC³，并且只募集了三分之一可及神经元，却在两项分类任务上取得了两个最高分。在所有结构中，IC³越高，分类得分越低。我们将这一新方向称为“神经拓扑形态计算”，其中神经元连接的物理组织被设计为计算基底的一部分。

## Abstract
Living neuronal networks transform inputs through recurrent cellular and population dynamics, yet it is unknown which network architecture supports which computation. Neurons-on-a-chip turn this question into a design problem because microchannels guide axonal growth and set the network architecture. We introduce IC$^3$, an Integrated Characterisation of Communication-Driven Computation, which characterizes network state through neuronal dynamics, functional communication, and structural support. We implemented nine architectures \textit{in silico} as conductance-based spiking networks and tested each on frequency decoding, temporal-order discrimination, and fading memory. Predominantly feedforward circuits decoded best. Sequential Chain and Microchannel Diode had the lowest IC$^3$ and recruited a third of reachable neurons, yet achieved the two highest scores on both classification tasks. Across architectures, higher IC$^3$ went with lower classification scores. We term this new direction \emph{neurotopomorphic computing}, in which the physical organisation of neuronal connectivity is engineered as part of the computing substrate.
