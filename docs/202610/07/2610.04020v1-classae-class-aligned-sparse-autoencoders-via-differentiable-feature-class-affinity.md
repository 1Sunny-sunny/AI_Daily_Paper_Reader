## 摘要
稀疏自编码器（SAE）最初是一种将神经表征分解为稀疏、可解释特征的无监督工具，如今不仅用于被动分析，还越来越多地用于主动干预，如遗忘（unlearning）、偏见缓解和概念编辑。这些编辑和引导方法的一个核心挑战是可靠地将特征与目标概念匹配；当前大多数方法通过在一个已训练且冻结的字典上计算事后分数来解决这一问题。我们则提出 ClasSAE，一种新方法，在训练过程中既自动为特征分配类别，又引导编码器生成类别可分离的表征。具体而言，我们将可微 top-k 算子应用于具有逐特征预算的可训练特征-类别亲和力矩阵，从而把为每个样本选择的特征与这些特征被训练来表示的类别耦合起来。由于梯度流经活跃特征的选择过程，而非仅流经其幅值，编码器与亲和力矩阵得以协同适应，而不是分阶段拟合。其结果是得到一个既类别可分离又带有类别标注的字典，无需事后探测。我们在此框架内提出了三种施加稀疏性的变体，它们在整体性能上相当，仅在权衡上略有不同。在 ImageNet 上使用 CLIP ViT-L/14 嵌入，我们表明学习到的亲和力矩阵与在留出数据上独立估计的事后特征-类别矩阵高度一致。该模型还支持仅凭编码器和亲和力矩阵直接进行类别预测，而无需单独拟合的分类器；并且其类别对齐程度更高的编码器在定向探针扰动（Targeted Probe Perturbation）评估中获得了更好的分离效果。https://github.com/St0pien/ClasSAE.

## Abstract
Sparse Autoencoders (SAEs) began as an unsupervised tool for decomposing neural representations into sparse, interpretable features, and are increasingly used not only for passive analysis but also for active interventions such as unlearning, bias mitigation, and concept editing. A central challenge for these editing and steering methods is reliably matching features to target concepts; most current approaches address this by computing post-hoc scores over an already-trained, frozen dictionary. We instead introduce ClasSAE, a novel method that both automatically assigns classes to features and guides the encoder toward class-separable representations during training. Specifically, we apply a differentiable top-$k$ operator to a trainable feature--class affinity matrix with per-feature budgets, coupling the features selected for each sample to the classes they are trained to represent. Because gradients flow through the selection of active features rather than only through their magnitudes, the encoder and the affinity matrix co-adapt rather than being fit in separate stages. The result is a dictionary that is both class-separable and class-annotated, with no need for post-hoc probing. We propose three variants for enforcing sparsity within this framework, which achieve comparable overall performance with slightly different trade-offs. Using CLIP ViT-L/14 embeddings on ImageNet, we show that the learned affinity matrix agrees closely with an independently estimated post-hoc feature-class matrix computed on held-out data. The model also supports direct class prediction from the encoder and affinity matrix alone, without a separately fitted classifier, and its more class-aligned encoder yields improved separation in Targeted Probe Perturbation evaluations. https://github.com/St0pien/ClasSAE.
