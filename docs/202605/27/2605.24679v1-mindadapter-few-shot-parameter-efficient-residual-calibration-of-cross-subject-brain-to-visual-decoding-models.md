## 摘要
由于严重的个体间差异导致系统性的被试特定功能失调，跨被试脑到视觉解码仍是脑机接口中的核心挑战。为解决这一问题，我们提出了 MindAdapter，一个面向预训练脑到视觉解码模型的参数高效少样本校准框架。MindAdapter 采用解耦的线性-残差级联对齐范式，通过冻结预训练的显式脑功能对齐骨干（粗调）并引入轻量级非线性残差适配器（微调），将全局跨被试对应关系与细粒度空间和语义校准所需的被试特定残差校正分离开来。为进一步保持全局表征稳定性，我们设计了一种拓扑锚定的双流流形约束，其中一小组共享刺激作为拓扑锚点，提供体素级配对监督，而语义流则通过冻结的视觉-语言解码器对非配对脑数据施加一致性。总体而言，MindAdapter 在注入被试特定校正的同时，保持了预训练过程中学习到的全局表征几何。在自然场景数据集（NSD）上的实验表明，MindAdapter 仅使用少量共享刺激就能显著提升跨被试视觉重建和检索的准确性，为个性化脑到视觉解码提供了一种实用且数据高效的解决方案。

## Abstract
Cross-subject brain-to-visual decoding remains a core challenge in brain-computer interfaces due to severe inter-individual variability that induces systematic subject-specific functional misalignment. To address this issue, we propose MindAdapter, a parameter-efficient few-shot calibration framework for pretrained brain-to-visual decoding models. MindAdapter adopts a decoupled linear-residual cascade alignment paradigm by freezing a pretrained explicit brain functional alignment backbone (coarse) and introducing a lightweight nonlinear residual adapter (fine), thereby disentangling global cross-subject correspondence from subject-specific residual corrections for fine-grained spatial and semantic calibration. To further preserve global representational stability, we design a topology-anchored dual-stream manifold constraint, where a small set of shared stimuli serves as topological pins with voxel-level paired supervision, while a semantic stream enforces consistency through a frozen vision-language decoder on unpaired brain data. Together, MindAdapter efficiently injects subject-specific corrections while maintaining the global representational geometry learned during pretraining. Experiments on the Natural Scenes Dataset (NSD) demonstrate that MindAdapter substantially improves cross-subject visual reconstruction and retrieval accuracy using only a few shared stimuli, offering a practical and data-efficient solution for personalized brain-to-visual decoding.

### 2. 论文提出的方法论

MindAdapter 框架的核心思想是 **解耦的线性-残差级联对齐**，将跨被试对齐分为全局粗调和个体微调两个阶段。

*   **核心思想与架构**:
    *   **冻结的预训练骨干 (Frozen Coarse Backbone)**: 使用一个预训练的线性脑转移矩阵 (Brain Transfer Matrix, BTM) 作为全局粗对齐模型 $F_0$，将源被试脑信号 $x_s$ 映射到目标被试空间，得到 $F_0(x_s)$。该模块参数被冻结。
    *   **轻量级非线性残差适配器 (Lightweight Residual Adapter)**: 在 $F_0$ 之上并联一个轻量级非线性残差适配器 $A_\theta$。校准后的最终映射为：
        $$F_\theta(x_s) = F_0(x_s) + A_\theta(F_0(x_s))$$
        适配器 $A_\theta$ 的目标是去学习并修正预训练模型 $F_0$ 产生的结构化残差 $r(x_s)$，即 $A_\theta(F_0(x_s)) \approx r(x_s)$。适配器本身是一个三层多层感知机 (MLP)。

*   **关键技术细节：拓扑锚定的双流损失函数**:
    为解决极少量样本下的过拟合和表征扭曲问题，MindAdapter 的优化基于两个互补的损失项：
    1.  **锚点流 (Anchor Stream) - 体素级监督**:
        *   在一小组共享刺激的配对数据 $\mathcal{P} = \{(x^{(i)}_s, x^{(i)}_t)\}^m_{i=1}$ 上计算。
        *   损失函数 $L_{\text{anchor}}$ 由两部分组成：MSE 损失 $||F_\theta(x^{(i)}_s) - x^{(i)}_t||^2$（提供强几何约束）和对比损失 $\ell_{\text{NCE}}$（提升辨别性对齐）。这些共享刺激如同“拓扑图钉”，锚定了目标被试体素流形的几何结构。
    2.  **语义流 (Semantic Stream) - 语义一致性监督**:
        *   在大量非配对的源被试数据 $\mathcal{U} = \{(x^{(j)}_s, c^{(j)}_s)\}^N_{j=1}$ 上计算。
        *   通过冻结的视觉解码器 $G$ 将校准后的脑信号投影到 CLIP 视觉-语义空间，并计算与源刺激 CLIP 嵌入 $c^{(j)}_s$ 的对比损失 $L_{\text{sec}} = \ell_{\text{NCE}}(G(F_\theta(x^{(j)}_s)), c^{(j)}_s)$。
        *   该损失项强制模型在数据稀缺时保持在预训练的视觉流形上，防止语义漂移。
    *   **联合优化**: 最终目标为两个损失项的加权和：$L(\theta) = \lambda L_{\text{anchor}} + L_{\text{sec}}$。

    *   **主要对比基准**: 与当前最优的跨被试解码模型进行对比，包括：

        *   **高层级语义指标 (High-Level)**: Inception, CLIP, EffNet-B, SwAV（衡量语义相似度）以及双向检索准确率（fwd_corr, bwd_corr）。

### 6. 论文的主要结论与发现

*   MindAdapter 仅需极少量的共享刺激（如 32-64 个）即可实现对跨被试脑视觉解码模型的**高效校准**，在图像重建质量和检索准确率上相比于 MindAligner 有显著提升。
*   **解耦的粗-细粒度范式是有效的**：冻结全局对齐骨干、仅微调轻量级非线性残差适配器的策略，既能纠正被试特定的错位，又能避免灾难性遗忘和过拟合。
*   **拓扑锚定双流损失至关重要**：配对的“锚点流”提供了关键的校正信号，而非配对的“语义流”则成功地维持了全局语义表征的稳定性，两者缺一不可。
*   该方法在保证高性能的同时，具备极高的**计算效率**，能将新被试的校准时间从数小时/天缩短至数分钟。

### 7. 优点

*   **方法设计巧妙**: 将复杂的跨被试问题解耦为“全局粗对齐 + 个体细校准”，思路清晰，且符合参数高效微调（PEFT）的思想潮流。
*   **数据效率极高**: 在仅需极少量共享数据的严苛条件下实现显著性能提升，非常贴近真实世界的部署需求。

### 8. 不足与局限

*   **重建细节仍存在瓶颈**: 虽然整体语义恢复良好，但在处理**细粒度物体几何、复杂空间布局和多物体组合**时，重建结果仍可能出现结构扭曲或细节错配（如论文图9的失败案例所示）。

*   **数据集依赖**: 所有实验均基于单一数据集（NSD），尽管是该领域的标杆，但其在更广泛、更多样的 fMRI 数据集上的泛化能力尚未验证。
*   **潜在偏差**: 论文未深入探讨该方法是否会放大训练数据中已存在的种族、性别或文化偏差，也未评估重建图像中可能存在的幻觉或虚构内容风险。
