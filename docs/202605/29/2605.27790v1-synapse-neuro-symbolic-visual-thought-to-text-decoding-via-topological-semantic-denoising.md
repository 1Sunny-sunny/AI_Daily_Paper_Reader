## 摘要
最近大语言模型的进展加速了开放词汇的脑电图到想象文本解码，其中在视觉感知期间记录的非侵入性神经活动被翻译成对所观察刺激的连贯自然语言描述。然而，现有系统仍然极易受到生物噪声的影响，受损的神经投射会在冻结的语言模型中引发幻觉或语义不稳定的生成。我们提出了 SYNAPSE（符号神经对齐用于精确语义提取），这是一个轻量级的神经符号框架，通过推理时的符号正则化来稳定神经文本生成。通过利用常识图结构和潜在范例来净化源自脑电图的语义候选，SYNAPSE 提高了语义稳定性，而无需进行端到端的大语言模型微调。在多个流行的脑电解码基准和冻结的大语言模型后端上的实验表明，与无约束提示基线相比，其表现出一致的提升，在对象标签消融下具有鲁棒性，并且性能可与资源密集型得多的微调系统相媲美，同时通过将原始脑电图处理完全限制在编码器堆栈内来保护生物特征隐私。

## Abstract
Recent advances in large language models have accelerated open-vocabulary EEG-to-imagined-text decoding, where non-invasive neural activity recorded during visual perception is translated into coherent natural language descriptions of viewed stimuli. However, existing systems remain highly vulnerable to biological noise, where corrupted neural projections induce hallucinated or semantically unstable generation in frozen language models. We introduce SYNAPSE (Symbolic Neural Alignment for Precise Semantic Extraction), a lightweight neuro-symbolic framework that stabilizes neural text generation through inference-time symbolic regularization. By purifying EEG-derived semantic candidates using commonsense graph structure and latent exemplars, SYNAPSE improves semantic stability without end-to-end LLM fine-tuning. Experiments across popular EEG decoding benchmarks and multiple frozen LLM backends demonstrate consistent gains over unconstrained prompting baselines, robustness under object-label ablation, and performance commensurate with substantially more resource-intensive fine-tuned systems, while preserving biometric privacy by localizing raw EEG processing entirely within the encoder stack.

### 2. 方法论

SYNAPSE 是一个轻量级的推理时干预层，位于冻结的 EEG 编码器和冻结的 LLM 解码器之间，核心思想是利用**外部常识图谱的符号结构**对神经信号中提取的语义候选进行拓扑净化，并结合**关系事实**和**潜在范例**来约束生成。

- **问题设定与前端**：  
  给定 EEG 数据 $X_i \in \mathbb{R}^{C \times T}$ 和目标描述 $s_i$，通过冻结的 SENSE 前端（ChannelNet 编码器 + MLP）提取语言对齐的潜在向量 $\mathbf{z}_i \in \mathbb{R}^{512}$。然后，通过与冻结词汇矩阵 $V$ 的余弦相似度计算，得到原始候选词集合 $\mathcal{W}_{\text{raw}}$：  
  $$\mathcal{W}_{\text{raw}} = \text{TopK}\left(\sigma\left(\frac{\mathbf{z}_i}{\|\mathbf{z}_i\|_2} \cdot \left(\frac{V}{\|V\|_2}\right)^\top\right), k=15\right)$$

- **知识图谱诱导与拓扑修剪**：  
  将候选词投影到常识图 ConceptNet 上，提取基于置信度阈值（$w_{\min}=1.0$）的诱导子图 $G=(V_G, E_G)$。为避免孤立噪声词，通过归一化度中心性 $C_D(v)$ 识别并移除不连通节点，但保留一个“神经优先级保护集” $P$（前 $m=5$ 个高置信度词），最终的净化词汇为：  
  $$\mathcal{W}_{\text{pruned}} = \{ v \in V_G \mid C_D(v) > 0 \lor v \in P \}$$

  遍历子图 $G$ 的边，选取与视觉相关的有意义关系类型（如 AtLocation, HasProperty），将三元组 $(u, r, v)$ 转换为自然语言断言，取前 $N_{\text{facts}}=5$ 个构成事实集合 $\mathcal{F}$，注入提示以提供常识约束。

- **语言解码**：

- 在 ImageNet-EEG 基准上，SYNAPSE（完全配置）在所有解码器上均取得了最优或次优的性能，且明显优于 SENSE 和 THOUGHT2TEXT。

- **拓扑修剪核心作用**：仅使用净化词袋（A6）的表现已能与微调方法持平或超越，说明图谱去噪提供了比无约束提示或连接主义参数更新更强健的正则化。
- **THINGS EEG2 结果**：尽管在高密度概念下绝对指标下降，SYNAPSE 仍使某些基线（如 Qwen2.5-7B）从灾难性崩溃大幅恢复，体现了在开放词汇规模下符号干预的价值。
- **紧凑模型获得最大收益**：小模型容易因噪声产生注意力分散，SYNAPSE 通过清洗输入极大地减轻了这一问题，使小模型能媲美微调大模型。

### 7. 优点

- **轻量级与效率**：无需端到端微调 LLM，仅通过推理时符号操作即可稳定生成，大幅节约计算资源。
- **隐私保护**：原始 EEG 信号完全本地化在编码器栈处理，仅将净化后的离散符号或嵌入发送至 LLM（尽管仍依赖于外部 API 时隐私不完全）。
- **模块化设计**：清晰地将感知与逻辑解耦，允许根据需求独立升级编码器或知识图谱。
- **强鲁棒性**：对物体标签消融不敏感，在噪声密集的 THINGS 数据集上仍能显著提升小模型表现。
- **实验严谨**：跨数据集、跨模型、跨评测指标，并配合细致的消融与定性分析，结论可信。

### 8. 不足与局限

- **知识图谱覆盖限制**：框架依赖 ConceptNet 的完整性，对于罕见或弱连接的概念，可能无法有效净化，甚至误删有效词。
- **噪声子图逃逸**：如果多个语义错误的词在知识图谱中具有密集连接，它们会形成非零度中心性的子图，从而逃过拓扑修剪，可能仍导致幻觉。
- **范例检索的脆弱性**：在密集潜在空间中，最近邻检索可能引入略微错位的训练范例，对高容量模型（如 GPT-4o-mini）反而引起轻微的性能扰动。
- **下游生成上限**：属于检索增强范式，生成质量最终受限于前端检索的质量，而该检索建立在带噪的神经投影之上，而非清晰的文本查询。
- **隐私不完全**：尽管原始 EEG 不离开本地，但实验中使用了商业 API 端点（如 GPT-4o-mini），使得端到端隐私仍依赖于本地部署所有模型。
- **数据集规模**：评估被试数量较少（6 人以内），大规模实际场景下的个体差异适应性尚未验证。
- **缺乏计算量报告**：未说明图谱构建、检索等推理额外开销的定量数据，以及在不同硬件上的延迟。
