## 摘要
密集自注意力在学习之前将所有 token 对视为同等合理，这种交互各向同性的先验可能与结构化信号不匹配。对于脑电图（EEG）等结构化、低信噪比（SNR）信号，依赖关系沿电极轴和时间轴组织，而均匀先验使每个 token 暴露于大量无关交互。我们提出自适应各向异性注意力（AAA），将注意力分成两条路径：时间路径中，每个 token 在时间上关注自身电极的 token；空间路径中，它在同一时间步关注其他电极的 token。一个小型门控为每个 token 预测两条路径输出的凸组合：两个非负权重且和为 1。在六项 EEG 下游任务上，所得模型 AXON（AXis-factorized Operator Network，轴向分解算子网络）在线性探测和全量微调下均比密集基线提高了平均平衡准确率。我们表明两条路径（时间与空间）都是必要的，加权和优于仅选择其中一条路径；大部分收益来自门控在网络的每一层学习到不同的时间/空间平衡。受控音频频谱实验表明，轴向分解可迁移到 EEG 之外。这些结果说明，让注意力与结构化信号的自然轴对齐能提供有用的归纳偏置。

## Abstract
Dense self-attention treats all token pairs as equally plausible before learning, an interaction-isotropic prior that can be mismatched to structured signals. For structured, low signal-to-noise ratio (SNR) signals such as EEG, dependencies are organized along the electrode and time axes, and this uniform prior exposes each token to many irrelevant interactions. We introduce Adaptive Anisotropic Attention (AAA), which splits attention into two paths: a temporal path, where each token attends to the tokens of its own electrode across time, and a spatial path, where it attends to the tokens of the other electrodes at the same time step. A small gate predicts, for every token, a convex combination of the two path outputs: two non-negative weights that sum to one. On six EEG downstream tasks, the resulting model, AXON (AXis-factorized Operator Network), improves mean balanced accuracy over a dense baseline under both linear probing and full fine-tuning. We show that both paths (temporal and spatial) are necessary and that the weighted sum beats a hard choice of one path; most of the benefit comes from the gate learning a different temporal/spatial balance at each layer of the network. Controlled audio spectrogram experiments show that axis factorization transfers beyond EEG. These results suggest that aligning attention with the natural axes of structured signals provides a useful inductive bias.

## 1. 论文的核心问题与整体含义

- 论文针对**轴结构化信号**（如 EEG、音频频谱）上的 Transformer 注意力设计问题。
- 密集自注意力在训练前把所有 token 对视为同等可能的交互，这是一种**交互各向同性先验**。对于 EEG 这类低信噪比、依赖沿**电极轴**和**时间轴**组织的信号，该先验会让每个 token 暴露于大量无关交互。
- 在掩码自编码（MAE）预训练中，密集全局注意力可能鼓励**重建捷径**：例如用一个跨电极和时间的宽泛平均来估计被掩码 patch，从而稀释对下游任务（如运动想象、癫痫检测）至关重要的局部、轴特异信号。
- 因此论文提出**自适应各向异性注意力**，让注意力结构与信号的天然轴对齐，并由模型学习每条轴的使用程度。

## 2. 论文提出的方法论

核心思想是**将密集注意力替换为两条轴受限路径的加权混合**，而不是让每个 token 直接关注所有其他 token。

### 2.1 输入与 token 网格

- 脑电窗口被划分为 $C$ 个电极、每个电极 $T$ 个时间 patch，形成二维网格 $\Omega = C \times T$。
- 每个 token 记作 $i = (c_i, t_i)$，其中 $c_i$ 是电极索引，$t_i$ 是时间 patch 索引。
- token 嵌入由 patch 投影和位置编码组成；电极的 3D 头部坐标会通过线性投影加入位置编码。

### 2.2 时间路径与空间路径

- **时间路径**：token $i$ 只关注同一电极上的所有时间 patch，即
  $$T(i)=\{j\in\Omega:c_j=c_i\},\quad |T(i)|=T.$$
- **空间路径**：token $i$ 只关注同一时间步上的所有电极，即
  $$S(i)=\{j\in\Omega:t_j=t_i\},\quad |S(i)|=C.$$
- 两条路径使用**独立的 QKV 和输出投影**，允许各自学习不同的特征空间。
- 时间路径输出记为 $T(x)_i$，空间路径输出记为 $S(x)_i$。

### 2.3 自适应门控混合

- 最简单的变体 **AXON-Fixed** 每层学习一个标量 $\ell$，并通过 sigmoid 得到共享权重：
  $$y_i = \lambda T(x)_i + (1-\lambda) S(x)_i,\quad \lambda=\sigma(\ell)\in(0,1).$$
- **AXON-TokenGated** 用一个小 MLP 为每个 token 预测权重：
  $$(\alpha_i,\beta_i)=\mathrm{softmax}\bigl(g(\mathrm{sg}(x_i))/\tau\bigr),$$
  其中 $g$ 是两层 MLP，隐藏宽度为 $d/4$，GELU 激活，输出层零初始化；$\mathrm{sg}$ 表示停止梯度；温度 $\tau$ 从 2.0 退火到 1.0。
- 最终输出为凸组合：
  $$y_i=\alpha_i T(x)_i+\beta_i S(x)_i,\quad \alpha_i+\beta_i=1.$$
- 门控可以随内容、通道-时间位置、层和输入样本变化。

### 2.4 两时间窗口

- EEG 信息存在于不同时间尺度，因此最终 AXON 的时间路径包含两个窗口：
  $$T_{\mathrm{ms}}(x)_i=\lambda_s T_{\mathrm{short}}(x)_i+(1-\lambda_s)T_{\mathrm{long}}(x)_i,\quad \lambda_s\in[0,1].$$
- 短窗口只看 5 个连续时间 patch，长窗口看整个可见窗口；每层学习一个 $\lambda_s$，初始偏向长窗口以利于早期重建。

### 2.5 全局路径变体

- 论文还测试了加入第三个密集全局路径的变体 **AXON-withGlobal**：
  $$y_i=\alpha_i T(x)_i+\beta_i S(x)_i+\gamma_i G(x)_i,\quad \alpha_i+\beta_i+\gamma_i=1.$$
- 最终 AXON **不使用**全局路径，因为实验表明其在 EEG 上会损害下游迁移。

## 3. 实验设计

### 3.1 预训练

- 使用掩码自编码（MAE）在混合 EEG 语料上预训练，包括 TUH-EEG、I-CARE 以及两个内部临床 EEG 数据集。
- 预处理后统一重采样到 200 Hz，10 秒窗口，21 个标准 10–20 电极，$T=11$ 个 patch。
- 掩码率为 55%，使用时空块掩码；编码器只处理可见 token，轻量解码器重建掩码 patch。
- 预训练 50 个 epoch，batch size 4096。

### 3.2 下游任务

六项公开 EEG 下游任务：

- **motor**：运动想象，BCI Competition IV 2a，4 类；采用线性探测和全量微调。
- **bcic**：运动想象 BCI，4 类。
- **workload**：认知负荷，STEW 数据集，2 类。
- **hmc**：睡眠分期，5 类。
- **siena**：癫痫检测，2 类。
- **adftd**：痴呆诊断，AD/FTD/健康对照，3 类。

评估协议：

- 所有数据集采用**被试互斥划分**，所有模型共享相同划分。
- 同时报告**线性探测（LP，冻结编码器）**和**全量微调（FT）**下的平衡准确率（BAC）。
- 主结果选择验证集最佳 LP checkpoint，而不是最终 epoch。

### 3.3 对比方法

- **Dense**：密集自注意力基线。
- **Dense-L**：参数匹配的密集基线，扩大隐藏维度以匹配 AXON 参数量。
- **Divided-ST**：顺序时间-空间注意力基线（基于 ViViT）。
- **AXON-Fixed**：固定每层共享门控。
- **AXON-TokenGated**：逐 token 门控，但只有单一时间窗口。
- **AXON**：最终模型，逐 token 门控 + 两时间窗口 + 无全局路径。
- **AXON-withGlobal**：带第三条密集全局路径的变体。
- 此外还对比了六个已发布 EEG 基础模型：EEGPT、LaBraM、CBraMod、BIOT、CSBrain、REVE。

### 3.4 音频实验

- 在 AudioMAE 配方下，对时间-频率频谱进行同样的轴向分解。
- 使用 AudioSet-2M 预训练（约 2M 片段），下游任务包括 AudioSet（mAP）、ESC-50（准确率）、SpeechCommands（准确率）。
- 比较 Dense、Fixed gate、Token gate、Token+Global 四种注意力变体。
- 还在 18K 和 200K 片段规模上做了小规模验证。

## 6. 论文的主要结论与发现

- **AXON 在 EEG 上显著优于密集基线**：平均 LP 从 0.550 提升到 0.579，平均 FT 从 0.606 提升到 0.656；相比参数匹配的 Dense-L 和 Divided-ST 也有稳定提升。
- **两条轴路径都是必要的**：强制只用时间路径或只用空间路径会分别导致约 17.5% 和 22.0% 的平均性能下降。
- **软混合优于硬选择**：硬 argmax 路由导致约 12.2% 的下降。
- **门控的主要收益来自每层不同的时间/空间平衡**，而不是精确的逐 token 内容路由；用层平均门控替换学习门控只损失约 2.1%，而打乱 token-门控对应关系只损失约 1.3%。
- **全局密集路径在 EEG 上是有害的**：AXON-withGlobal 虽然重建损失相当，但下游 LP/FT 均下降；有效秩分析显示它降低了特征多样性，尤其影响运动想象任务。
- **轴向分解可以迁移到音频**：在 AudioSet、ESC-50、SpeechCommands 上，因子化变体普遍优于密集基线；但与 EEG 不同，音频上 Token+Global 在多数指标上表现最好。
- 与六个已发布 EEG 基础模型相比，AXON 在统一协议下取得最高的平均 LP 和 FT，领先次优模型 REVE 超过 5 个 LP 点。

## 7. 优点

- **归纳偏置明确**：将注意力与 EEG/音频的自然轴对齐，减少了无关的全对全交互。
- **门控设计灵活**：允许每层、每 token 学习不同的时间/空间平衡，且通过停止梯度和温度退火使训练稳定。
- **多尺度时间处理**：显式分离短窗口和长窗口，利于同时捕捉瞬时事件和缓慢背景。
- **实验控制严格**：包含参数匹配基线、Divided-ST 基线、位置编码控制、全局路径消融等，增强了结论可信度。
- **分析深入**：门控干预、有效秩、CKA、电极掩盖实验从多个角度解释了模型行为。
- **跨模态验证**：
