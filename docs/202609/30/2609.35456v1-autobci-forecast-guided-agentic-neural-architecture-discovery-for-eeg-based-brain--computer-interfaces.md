## 摘要
基于EEG的脑机接口支持广泛的应用，但在多种任务上表现良好的解码架构设计仍然具有挑战性。我们提出AutoBCI，一个智能体框架，其中设计者智能体与预测者智能体支持跨任务发现和选择EEG解码架构。设计者智能体执行池引导架构发现（PGAD），通过在情绪识别、运动想象和睡眠分期等多个EEG任务上的训练和验证来生成和优化架构。预测者智能体执行基于早期知识的性能估计（PEEK），利用架构代码、训练协议和早期学习曲线预测完整预算下的验证性能，并选择有潜力的候选架构继续训练。在涵盖运动想象、情绪识别和睡眠分期的14个EEG数据集上，我们使用包括Opus 5.5和GPT 5.6 Sol在内的六种LLM评估AutoBCI，并将搜索过程所选架构与十个基线进行比较：六个传统EEG模型和四个基础模型。AutoBCI与Claude Opus 5.5发现的架构实现了64.16%的平均测试平衡准确率（bAcc），而该指标上最强基线REVE为63.87%。使用十个观测轮次，PEEK将平均验证bAcc预测的平均绝对误差从2.20个百分点降低到1.36个百分点，相对于最佳观测分数基线降低了38.1%。

## Abstract
EEG-based brain-computer interfaces support a broad range of applications, yet designing decoding architectures that perform well across diverse tasks remains challenging. We introduce AutoBCI, an agentic framework in which a Designer Agent and a Forecaster Agent support the discovery and selection of EEG decoding architectures across tasks. The Designer Agent performs Pool-Guided Architecture Discovery (PGAD), generating and refining architectures through training and validation across multiple EEG tasks, such as emotion recognition, motor imagery, and sleep staging. The Forecaster Agent performs Performance Estimation from Early Knowledge (PEEK), using architecture code, the training protocol, and early learning curves to predict full-budget validation performance and select promising candidates for continued training. Across 14 EEG datasets spanning motor imagery, emotion recognition, and sleep staging, we evaluate AutoBCI with six LLMs, including Opus 5.5 and GPT 5.6 Sol, and compare the architectures selected by the search procedure against ten baselines: six conventional EEG models and four foundation models. The architecture discovered by AutoBCI with Claude Opus 5.5 achieves 64.16% average test balanced accuracy (bAcc), compared with 63.87% for REVE, the strongest baseline on this metric. Using ten observed epochs, PEEK reduces mean absolute error in predicting average validation bAcc from 2.20 to 1.36 percentage points, a 38.1% reduction relative to the best-observed-score baseline.

## 1. 论文的核心问题与整体含义

- **研究背景**：脑机接口（BCI）中的 EEG 解码任务涵盖运动想象、情绪识别、睡眠分期等多种场景，不同任务在空间覆盖、时间尺度和标签空间上差异显著，难以设计一个跨任务通用的高性能解码架构。
- **核心问题**：传统 EEG 解码模型（如 EEGNet、TSception、DeepSleepNet）依赖人工设计的结构先验，跨任务选择合适架构的人工负担重。虽然已有自动化神经架构搜索（NAS）和智能体方法，但大多针对单一任务优化，缺乏跨任务共享架构的自动发现与早期筛选机制。
- **整体含义**：论文提出 AutoBCI，一个由“设计者智能体”和“预测者智能体”组成的智能体框架，旨在通过跨任务验证反馈自动生成、评估和筛选 EEG 解码架构，同时利用早期训练信息预测全预算性能以减少搜索成本。

## 2. 论文提出的方法论

### 2.1 总体框架
AutoBCI 包含两个核心智能体：
- **设计者智能体（Designer Agent）**：执行池引导架构发现（PGAD），生成并迭代优化候选架构。
- **预测者智能体（Forecaster Agent）**：执行基于早期知识的性能估计（PEEK），从架构代码和早期学习曲线预测全预算验证性能，指导训练资源的分配。

### 2.2 池引导架构发现（PGAD）
- **候选生成**：每轮由 LLM 生成完整 PyTorch 模型代码和架构假设。第一轮全部为全新提案；后续轮次由上一轮高分父架构的细化变体与全新探索组成。
- **跨任务评估**：每个候选架构在 $K=3$ 个任务家族（情绪识别、运动想象、睡眠分期）上分别独立训练。任务分数定义为每个任务内所有数据集在公共 epoch 上的平均验证平衡准确率的最大值：
  $$s_{a,k} = \max_{1 \le e \le E} \frac{1}{|D_k|} \sum_{d \in D_k} b_{a,d}(e)$$
  架构分数为三个任务分数的等权平均：
  $$S_a = \frac{1}{K} \sum_{k=1}^{K} s_{a,k}$$
- **池选择与细化**：维护一个跨轮次的持久候选池，根据 $S_a$ 选择 $P$ 个父架构，每个父生成 $Q$ 个单组件细化，同时生成 $U$ 个全新探索，满足 $N = PQ + U$。最终在候选池中选择 $S_a$ 最高的架构作为冠军。

### 2.3 基于早期知识的性能估计（PEEK）
- **性能预测**：在候选架构仅训练前 $e_0$ 个 epoch 时，预测者智能体根据架构代码 $C_a$、观察到的训练/验证历史 $H_{a,k}^{1:e_0}$ 和训练协议 $\pi_k$，预测每个任务的全预算任务分数：
  $$\hat{s}_{a,k} = F_{\text{LLM}}(C_a, H_{a,k}^{1:e_0}, \pi_k)$$
  预测值必须不低于已观察到的最高验证分数。组合预测为三个任务预测的等权平均：
  $$\hat{S}_a = \frac{1}{K} \sum_{k=1}^{K} \hat{s}_{a,k}$$
- **候选选择**：根据 $\hat{S}_a$ 对候选排序，保留前 $N_{\text{keep}}$ 个候选继续训练到全预算 $E$。只有完成全部三个任务训练的候选才有资格进入 PGAD 池。

### 2.4 关键设计细节
- 所有候选参数小于 100 万，排除循环/递归架构。
- 训练协议统一：AdamW、batch size 512、BF16 全精度、余弦退火、40 epoch 预算。
- 验证集用于选择检查点和架构，测试集仅用于最终评价。

## 3. 实验设计

### 3.1 数据集与场景
- **14 个公开 EEG 数据集**，分为三个任务家族：
  - **运动想象（MI，8 个数据集）**：BCIC-IV-2a、OpenBMI-MI、BCIC-Upperlimb、Cho2017、HighGamma、PhysioNet-MI、SHU-MI、Shin2017A。统一输入 65 通道 × 4 秒，7 类。
  - **情绪识别（ER，3 个数据集）**：SEED、SEED-IV、SEED-V。输入 65 通道 × 4 秒，7 类。
  - **睡眠分期（SS，3 个数据集）**：Sleep-EDF、ISRUC、HMC。输入 8 通道 × 30 秒，5 类。
- 数据集内统一电极布局和类别，但各任务独立训练和评估。

### 3.2 基准对比方法
- **6 个传统 EEG 模型**：EEGNet、DeepConvNet (DCN)、TSception、EEG-Conformer、AttnSleep、FAST。
- **4 个基础模型**：LaBraM、CBraMod、LEAF、REVE。传统模型从头训练，基础模型微调。
- **AutoBCI 使用 6 个 LLM 进行架构搜索**：Claude Sonnet 5、DeepSeek V4.1 Flash、Gemini 3.8 Flash、Qwen3.8 Flash、GPT-5.6 Sol、Claude Opus 5.5。

### 3.3 搜索协议
- $R=6$ 轮，每轮 $N=8$ 个候选，$P=2$ 个父架构、$Q=3$ 个细化、$U=2$ 个新探索。
- 每个候选在三个任务上独立训练 40 epoch，共 $RN=48$ 个架构提案，最多 $KRN=144$ 个任务训练运行。
- 最终冠军基于验证集选择，测试集仅用于最终报告。

- **并行方式**：每个候选/任务作为独立进程在单个 GPU 上运行，由协调器根据 GPU 可用性调度并行作业；未明确说明同时使用的 GPU 数量。

  - 结果提升幅度较小（平均测试 bAcc 仅高 0.29 个百分点），且在其他指标（wF1、Kappa）上未全面超越最强基线。

## 6. 论文的主要结论与发现

- **架构发现**：AutoBCI 与 Claude Opus 5.5 发现的冠军架构在平均测试 bAcc 上达到 64.16%，超过最强基线 REVE 的 63.87%，但 REVE 在平均 wF1 和 Cohen’s Kappa 上仍领先。
- **搜索过程**：所有六个 LLM 引导的搜索均提升了其最佳验证分数；Opus 最终验证 bAcc 最高（66.26%），Qwen 提升幅度最大（+16.90 pp）但最终分数最低。
- **早期预测**：在 10 个 epoch 时，PEEK 将组合分数预测的 MAE 从最佳观测分数基线的 2.20 pp 降低到 1.36 pp，相对降低 38.1%；但在 16 个 epoch 时，最佳观测分数基线聚合 MAE 更低（0.88 vs 1.18 pp）。
- **候选筛选**：保留 3 个候选可保留 91.7% 的全预算赢家，并节省约 44.9% 的训练 epoch（估计 GPU job-hours 从 68.58 降至 38.85）。保留 2 个时赢家保留率为 83.3%，节省 54.9%。

## 7. 优点

- **创新的智能体协作框架**：将架构生成与早期性能预测解耦为两个智能体，设计合理，可分别优化或替换。
- **跨任务公平评估**：每个候选在三个任务家族上独立训练，使用等权平均任务分数进行选择，避免了单任务偏差。
- **实用的成本节约机制**：PEEK 利用早期学习曲线和架构代码进行预测，在 10 个 epoch 内显著降低预测误差，并能在保持较高赢家保留率的同时节省约 45% 的训练成本。
- **多 LLM 与多数据集验证**：在 14 个数据集、6 个 LLM 上进行搜索，结果具有较好的普适性证据。
- **详细的实验记录与可复现性**：提供了完整的提示词、数据划分、训练配置和架构代码，并进行了训练精度等补充实验。

## 8. 不足与局限

- **性能提升有限**：仅在平均测试 bAcc 上以 0.29 pp 的微弱优势超过 REVE，且在 wF1 和 Kappa 上未全面超越；统计显著性未报告，提升的鲁棒性存疑。
- **PEEK 的稳定性**：在 DeepSeek 模型上，10 个 epoch 时 PEEK 的 MAE 反而从 1.97 pp 增加到 3.63 pp；在 16 个 epoch 时聚合 MAE 不如最佳观测分数基线，说明预测增益高度依赖 LLM 和观察窗口。
- **任务覆盖有限**：仅涵盖运动想象、情绪识别和睡眠分期，未涉及其他常见 BCI 任务（如稳态视觉诱发电位、错误相关电位等），跨任务通用性证据有限。
- **模型复杂度未深入讨论**：AutoBCI 冠军架构参数量远小于 REVE 等基础模型，但论文未系统分析参数效率与性能的关系，也未在相同参数量约束下比较基线。
- **搜索成本与随机性**：每轮生成 8 个候选，经过 6 轮，每个候选全训练 40 epoch，总体计算量较大。仅报告单次搜索的结果，未评估多次搜索的方差；不同 LLM 的表现差异较大，可能受提示工程和模型随机性影响。
- **候选筛选的局限性**：PEEK 的筛选策略会改变后续轮次的父本选择，但论文仅在已记录的候选批次上回顾性评估，未实际在线执行筛选后的搜索，因此节省成本的实际闭环效果未知。
