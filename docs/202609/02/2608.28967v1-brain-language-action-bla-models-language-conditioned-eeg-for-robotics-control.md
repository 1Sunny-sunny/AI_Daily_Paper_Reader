## 摘要
基于脑电图（EEG）的机器人控制通常被表述为直接分类问题，其中神经电信号被映射到一组固定的离散动作。然而，EEG信号的可分性有限且噪声较高，使得该方法难以扩展到精细的机器人控制空间。我们提出脑-语言-动作（BLA）模型，这是一个利用语言来条件化神经表征解释以生成机器人动作的框架。在BLA中，一组少量且可可靠区分的脑状态可以通过语言定义的控制映射动态关联到不同动作，从而使较少的神经类别能够应用于更大的全局动作空间。我们使用BCI Competition IV 2a数据集中的运动想象EEG，开发了一个用于无人机控制的概念验证BLA。系统分两阶段训练。首先，我们使用受试者特定的四类运动想象分类评估多个候选EEG编码器架构，将250Hz、3.5秒、22通道的EEG样本转换为五个128维脑token嵌入。其次，将这些嵌入投影到预训练大语言模型（LLM）的嵌入空间中，并与语言指令联合微调，以自回归方式生成结构化的三token无人机动作。在四个神经状态和七种飞行动作组合之间的840种可能语言定义映射中，所得BLA在评估期间实现了90%的逐token准确率。这些结果初步证明，语言条件化可以扩展基于EEG的机器人接口的有效控制范围，而无需相应增加可直接区分的神经状态数量。

## Abstract
Electroencephalography (EEG)-based robotic control is commonly formulated as a direct classification problem, in which electrical neural signals are mapped to a fixed set of discrete actions. However, the limited separability and high noise of EEG signals make it difficult to scale this approach to fine-grained robotic control spaces. We introduce Brain-Language-Action (BLA) models, a framework in which language conditions the interpretation of neural representations for robotic action generation. In a BLA, a small set of reliably distinguishable brain states can be dynamically associated with different actions through a language-defined control mapping, allowing a small number of neural classes to apply to a larger global action space.   We develop a proof-of-concept BLA for drone control using motor-imagery EEG from the BCI Competition IV 2a dataset. The system is trained in two stages. First, we evaluate multiple candidate EEG encoder architectures using subject-specific four-class motor-imagery classification, converting 250Hz, 3.5-second, 22-channel EEG samples into five 128-dimensional brain-token embeddings. Second, these embeddings are projected into the embedding space of a pretrained large language model (LLM) and jointly fine-tuned with language instructions to autoregressively generate structured three-token drone actions. Across 840 possible language-defined mappings between four neural states and seven flight action combinations, the resulting BLA achieves 90% per-token accuracy during evaluation. These results provide an initial demonstration that language conditioning can expand the effective control range of EEG-based robotic interfaces without requiring a corresponding increase in the number of directly distinguishable neural states.

## 1. 核心问题与整体含义

- **研究背景**：脑机接口（BCI）通常将脑电信号（EEG）直接分类为固定动作；运动想象（motor imagery）EEG 是常用的神经控制范式。
- **核心问题**：EEG 信号噪声大、类别可分性有限，传统“EEG → 固定动作”的直接映射方式难以扩展到精细、大规模的机器人控制空间。
- **整体含义**：提出 **脑-语言-动作（Brain-Language-Action, BLA）模型**，让语言动态定义少量可区分神经状态在机器人控制中的含义，从而在不增加神经类别数量的前提下，扩大 EEG 机器人接口的有效控制范围。
- **关键思想类比**：BLA 仿照视觉-语言-动作（VLA）模型（如 RT-2）的思路，用语言作为条件信号来重新解释另一模态（这里是 EEG）的表示。

## 2. 方法论

### 2.1 BLA 总体架构

BLA 由三部分组成：

1. **脑编码器** $B_\theta$：将 EEG 窗口 $X$ 编码为神经嵌入 $E$：  
   $$E = B_\theta(X)$$
2. **脑到语言投影模块** $P_\phi$：将神经嵌入投影到预训练语言模型的嵌入维度：  
   $$Z = P_\phi(E)$$
3. **预训练语言模型**：联合处理投影后的脑嵌入和语言指令，生成动作序列：  
   $$A = f(Z, L)$$

输入拼接形式为：  
$$H = [Z; \text{Embed}(L)]$$

核心区别在于，BLA 的动作映射是语言条件化的：  
$$a = g(c, L)$$  
同一神经状态 $c$ 在不同语言指令 $L$ 下可以对应不同动作。

### 2.2 脑编码器预训练阶段

- 使用 **BCI Competition IV 2a** 运动想象数据集。
- EEG 输入：$875 \times 22$（3.5 秒，250 Hz，22 通道）。
- 将 875 个时间步划分为 5 个 patch，每个 patch 为 175 个时间步；每个 patch 编码为 128 维向量：  
  $$e_i \in \mathbb{R}^{128}, \quad i=1,\dots,5$$  
  $$E = [e_1, e_2, e_3, e_4, e_5] \in \mathbb{R}^{5 \times 128}$$
- 预训练目标：四类运动想象分类，分类头为轻量 MLP：  
  $$\hat{y} = C_\psi(E) \in \mathbb{R}^{4}$$
- 评估了 9 种候选编码器：MLP、RNN、LSTM、GRU、CNN、subtractive CNN、Transformer、subtractive Transformer、Inception 型 EEG 编码器。
- 每个受试者独立训练；训练 30 epochs，学习率 $10^{-3}$，batch size 16，10% 留出评估，随机种子 2025。

### 2.3 BLA 微调阶段

- 选择预训练表现最好的 **EEG-Inception 编码器**作为脑编码器。
- 下游只使用受试者 1、3、7、8，因为其运动想象分类准确率较高。
- 语言模型：**Qwen3-0.6B**，嵌入维度 1024。
- 投影模块将每个 128 维脑嵌入映射到 1024 维：  
  $$Z = P_\phi(E), \quad Z \in \mathbb{R}^{5 \times 1024}$$
- 投影模块不进行独立预训练，而是与脑编码器、语言模型一起在 BLA 微调中学习。
- 微调设置：30 epochs，batch size 16，学习率 $10^{-3}$，10% 留出评估，随机种子 2025。

### 2.4 无人机动作表示

- 动作序列为三个 token：  
  $$A = [a_{\text{horizontal}}, a_{\text{yaw}}, a_{\text{vertical}}]$$
- 分别控制前后移动、左右偏航、上升/下降。
- 每个 token 取自三个离散动作值：  
  $$a_i \in \{\text{ACT\_0}, \text{ACT\_1}, \text{ACT\_2}\}$$
- 其中 $\text{ACT\_0}$ 表示负向运动，$\text{ACT\_1}$ 表示中立，$\text{ACT\_2}$ 表示正向运动。
- 七种飞行动作包括：前进、后退、左转、右转、上升、下降、悬停。
- 动作 token 以自回归方式逐个生成。

### 2.5 语言条件控制映射

- 每条语言指令定义四个运动想象类别到七个飞行动作的映射：  
  $$m_L : C \to A$$
  其中 $C = \{c_{\text{left}}, c_{\text{right}}, c_{\text{feet}}, c_{\text{tongue}}\}$，$A$ 为七种动作序列集合。
- 四个神经状态互不相同地映射到从七个动作中选出的四个动作，因此映射总数为排列数：  
  $$P(7,4) = 7 \times 6 \times 5 \times 4 = 840$$
- 训练目标：给定 EEG 证据和语言映射，自回归生成正确动作 token；单独使用 EEG 或语言都不足以确定完整动作。

## 3. 实验设计

### 3.1 数据集

- **BCI Competition IV 2a**：
  - 9 名受试者；
  - 四类运动想象任务：左手、右手、脚、舌头；
  - 22 个 EEG 通道；
  - 250 Hz 采样率；
  - 每个样本为非重叠 3.5 秒窗口，即 $875 \times 22$。

### 3.2 基准与评估指标

- **脑编码器预训练基准**：四类运动想象分类准确率。
- **BLA 微调评估指标**：生成的三个动作 token 的逐 token 准确率（per-token accuracy）。
- 训练/测试划分：每个受试者随机留出 10% 作为评估集；固定随机种子 2025。

### 3.3 对比方法

- **脑编码器阶段**：比较了 9 种架构：MLP、RNN、LSTM、GRU、CNN、subtractive CNN、Transformer、subtractive Transformer、EEG-Inception。
