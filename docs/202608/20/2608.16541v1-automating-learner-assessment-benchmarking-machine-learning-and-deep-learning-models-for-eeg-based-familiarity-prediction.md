## 摘要
学习的客观评估仍然是教育中的一个根本性挑战。脑电图（EEG）为了解知识获取的神经关联（包括认知熟悉度）提供了一个直接、非侵入性的窗口。本研究对十五种机器学习（ML）和深度学习（DL）模型进行了基准测试，用于跨两个认知领域的基于EEG的熟悉度预测：面孔（事实性知识）和数学方程（概念性知识）。使用来自23名参与者的连续EEG数据，我们提取了六个频段的频谱特征（功率谱密度）。我们表明，尽管标准的 stratified 交叉验证由于相邻 epochs 之间的时间泄漏而产生人为偏高的分类性能（使用 CNN 时 F1 分数高达 0.9853），但严格的试验独立验证（Group K-Fold）将峰值性能降至 0.6038 F1 分数（使用 CNN），这仍然在统计上显著高于 25% 的随机水平。这凸显了试验独立评估对于避免高估模型泛化能力的至关重要性。此外，特征重要性和 SHAP 分析显示，颞区和额区的 Gamma 和 Beta 振荡是熟悉度最关键的生物标志物。这项工作为教育技术中基于 EEG 的认知监测建立了现实的基准。

## Abstract
Objective assessment of learning remains a fundamental challenge in education. Electroencephalography (EEG) provides a direct, non-invasive window into the neural correlates of knowledge acquisition, including cognitive familiarity. This study benchmarks fifteen machine learning (ML) and deep learning (DL) models for EEG-based familiarity prediction across two cognitive domains: faces (factual knowledge) and mathematical equations (conceptual knowledge). Using continuous EEG data from 23 participants, we extract spectral features (Power Spectral Density) across six frequency bands. We show that while standard stratified cross-validation yields artificially high classification performance (up to 0.9853 F1-score using CNN) due to temporal leakage across neighboring epochs, a rigorous trial-independent validation (Group K-Fold) drops the peak performance to 0.6038 F1-score (using CNN), which is still statistically significant above the 25% chance level. This highlights the critical necessity of trial-independent evaluation to avoid overestimating model generalizability. Furthermore, feature importance and SHAP analysis reveal that temporal and frontal Gamma and Beta oscillations are the most critical biomarkers for familiarity. This work establishes a realistic benchmark for EEG-based cognitive monitoring in educational technologies.

## 2. 论文提出的方法论

### 2.1 数据采集与实验范式

- 通过预实验问卷确定被试对每个刺激的熟悉/不熟悉标签。

### 2.2 预处理流程

预处理在 MATLAB EEGLAB 中完成，主要步骤包括：

- 带通滤波 1–50 Hz，降采样至 128 Hz；
- 坏通道插值；
- 基线去除；
- 连续数据人工伪影剔除；
- 提取刺激前 500 ms 至刺激后 2000 ms 的 epochs；

- ICA 分解，平均每个被试去除 2.1 个眼动/眨眼成分；
- 反投影并减去伪影成分。

### 2.3 特征提取

- 使用滑动窗口，窗口大小 64 个样本，重叠率 87.5%。

- 计算六个频段功率：
  - Delta：1–4 Hz
  - Theta：4–8 Hz
  - Alpha：8–13 Hz
  - Beta：13–30 Hz
  - Low Gamma：30–50 Hz
  - High Gamma：50–100 Hz

- 最终数据集共 3960 个样本：1292 个陌生方程、1267 个熟悉方程、668 个陌生面孔、733 个熟悉面孔。

### 2.4 类别不平衡处理

- 虽然同一认知领域内熟悉/不熟悉类别较平衡，但方程样本明显多于面孔样本。
- 论文使用 **成本敏感学习**：按类别频率的倒数设置类别权重，主指标采用 **weighted F1-score**。

### 2.5 验证协议

论文设计了两种交叉验证协议，以对比时间泄漏的影响：

- **Stratified K-Fold（有泄漏）**：
  - 随机打乱 epochs；
  - 相邻滑动窗口来自同一 trial，可能同时出现在训练集和测试集；
  - 会人为抬高性能。
- **Group K-Fold（试验独立）**：
  - 按唯一 trial block ID 分组，共 37 个独立 blocks；
  - 同一 trial 的所有 epochs 被整体放入同一折；
  - 防止相邻窗口跨训练/测试泄漏；
  - 但由于数据匿名化未保留被试标识，**仍不能完全保证跨被试独立**。

## 3. 实验设计

### 3.1 数据集与场景

- 单一 EEG 数据集，来自 23 名被试，包含两类刺激：
  - 人脸：事实性知识；
  - 数学方程：概念性知识。
- 主任务为 **4 分类**：
  - 熟悉方程；
  - 陌生方程；
  - 熟悉面孔；
  - 陌生面孔。
- 基准线：
  - 理论随机水平：25%；
  - 经验随机分层 F1 基线：26.72%。

### 3.2 主要对比实验

- **主 4 类任务**：15 个模型分别在 Stratified K-Fold 和 Group K-Fold 下比较。
- **域分离二分类任务**：
  - 仅域分类：方程 vs. 面孔；
  - 仅方程熟悉度：熟悉 vs. 陌生方程；
  - 仅面孔熟悉度：熟悉 vs. 陌生面孔。
- 域分离任务使用 **Leave-One-Group-Out（LOGO）** 验证，即每次留出一个 trial block 作为测试集。
- 由于每个 block 只包含单一类别，因此 LOGO 下报告的是 **LOGO Mean Recall**，而不是常规 F1-score。

### 3.3 统计验证与可解释性分析

- 对 trial 级聚合 PSD 特征进行 Welch t 检验，并用 Benjamini-Hochberg FDR 校正。
- 对熟悉度相关三个任务进行 **1000 次排列检验**，打乱 trial-group 标签并重复 LOGO，生成零分布。
- 排列检验使用 HistGradient Boosting 作为代表模型，因为 CNN 等深度模型计算成本过高。
- 使用 Random Forest 特征重要性分析频段和通道贡献。
- 使用 SHAP 对 DNN 进行模型解释。
