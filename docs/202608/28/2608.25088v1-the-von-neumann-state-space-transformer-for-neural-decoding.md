## 摘要
皮层计算具有显著的低维性：由神经群体活动承载的少数潜变量，引导着单个神经元更高维的响应。我们的目标是样本效率——即在有限数据和较小参数预算下也能良好解码的模型。在标准 Transformer 层中，前馈块对每个 token 应用相同的算子。我们提出一种受冯·诺依曼启发的有效计算假说，作为神经解码的替代方案：控制器先解码一条指令，再执行针对特定 token 的算子；而通常的实现——专家的软混合——只混合其输出，而非算子本身。我们引入冯·诺依曼状态空间 Transformer（VN-SST），一种记忆增强 Transformer，其前馈块是一个低秩指令库：一个共享的基础算子加上一小组学习到的低秩指令，由此每个 token 的编码合成该 token 实际使用的权重矩阵。该编码从所携带状态空间记忆的低维投影中读取，因此一条缓慢的潜轨迹充当指令指针——这类似于低维动力学可能如何路由皮层计算。在三个运动皮层神经解码基准上，VN-SST 的数据效率远高于现代 Transformer，且每个基准都联合预测脉冲并解码行为。该模型在数据最稀缺的基准上大幅领先，在另外两个基准上也位居前列，并且能把更长的上下文转化为上升而非下降的准确率。我们评估表明，该网络将一个大指令库压缩为每个 token 几个比特，因此程序容量充当控制通道，而非提升准确率的杠杆。同一模型在两个用于语言建模的小型文本基准上也具有更高的参数效率，这提示了一种通用机制。

## Abstract
Cortical computation is strikingly low-dimensional: a handful of latent variables, carried in a neural population's activity, steer the higher-dimensional responses of individual neurons. Our aim is sample efficiency-models that decode well from limited data and at small parameter budgets. In a standard Transformer layer, the feed-forward block applies the same operator to every token. We suggest a von-Neumann inspired hypothesis of efficient computation as an alternative for neural decoding: a controller decodes an instruction and then executes a token-specific operator; the usual realization-a soft mixture of experts-only blends their outputs, not operators. We introduce a von-Neumann State-Space Transformer (VN-SST), a memory-augmented Transformer whose feed-forward block is a low-rank instruction bank: a shared base operator plus a small set of learned low-rank instructions, from which a per-token code synthesizes the weight matrix actually used at that token. The code is read from a low- dimensional projection of a carried state-space memory, so a slow latent trajectory acts as an instruction pointer-mirroring how low-dimensional dynamics may route cortical computation. On three motor-cortex neural-decoding benchmarks, VN-SST is far more data-efficient than a modern Transformer, each jointly predicting spikes and decoding behavior. This model wins by a wide margin on the scarcest benchmark, leads on the other two, and turns longer context into rising rather than falling accuracy. We evaluated that the network compresses a large instruction bank to a few bits per token, so program capacity acts as a control channel, not an accuracy lever. The same model is also more parameter-efficient on two small text benchmarks used for language modeling (LLMs), suggesting a generic mechanism.

## 1. 论文的核心问题与整体含义

- 本文关注**神经解码中的样本效率**问题：神经群体活动虽然维度很高，但控制其变化的核心潜变量通常只占少数；因此，好的解码模型应当能在**有限数据和小参数量**下有效工作。
- 标准 Transformer 的前馈块（FFN）对每个 token 使用**相同的、固定的权重矩阵**，缺乏与输入动态匹配的“算子选择”机制。
- 受冯·诺依曼体系结构启发，论文提出一种新的计算假说：**控制器解码指令，执行单元运行针对当前 token 的特定算子**；而传统的专家混合（MoE）只是混合输出，并不真正改变算子本身。
- 整体含义是：在数据稀缺、模型较小的情况下，**可编程的前馈算子**可能是比单纯增加参数更有效的归纳偏置；这也与皮层由低维潜变量路由计算的现象相呼应。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将 Transformer 的前馈块替换为**低秩指令库**：一个共享基础算子加上 $K$ 个可学习的低秩指令，由每个 token 的代码动态合成实际使用的权重矩阵。
- 每个 token 的代码 $c_t$ 从**携带的状态空间记忆的低维投影**中解码得到，因此一条缓慢变化的低维轨迹充当“指令指针”，选择当前要执行的算子。

### 2.2 模型结构：VN-SST

VN-SST 保留了 Transformer 的层结构，但替换了两个关键模块：

- **三条并行的记忆通路**替代普通注意力：
  - **局部感官缓冲**：带因果窗口 $w$ 的局部多头注意力，捕捉窗口内短期结构。
  - **选择性状态空间（慢动态）**：对角、输入依赖的 SSM，携带跨段状态 $s$；其低维读出 $y_{\mathrm{ssm},t}$ 用作指令指针。
  - **快权重联想记忆（情景记忆）**：基于 delta 规则的矩阵记忆 $M$，写入预测误差，实现内容寻址召回。
- **可编程前馈算子**替代固定 SwiGLU：
  - 对通用投影 $W$，权重按以下方式合成：
    $$W(t)=W_0+\sum_{k=1}^{K} c_{t,k}\, U_k V_k^\top,$$
    其中 $W_0$ 是共享基础算子，$U_k V_k^\top$ 是第 $k$ 条秩 $r$ 指令，$c_{t,k}$ 是 token 代码的第 $k$ 个分量。
  - 实际计算时不是物化整个权重矩阵，而是先投影到指令库，再按代码缩放，最后通过 $U$ 读出：
    $$W_{\mathrm{in}}(t)u_t = W_{\mathrm{in},0}u_t + \sum_{k=1}^{K} c_{t,k}\, U_k\big(V_k^\top u_t\big).$$
  - 输入投影和输出投影分别使用各自的低秩指令库，但共享同一个代码 $c_t$。
- **指令指针**由 token 本身和 SSM 状态的低维投影共同解码：
  $$c_t = \tanh\Big(\mathrm{MLP}\big([u_t; P\, y_{\mathrm{ssm},t}]\big)\Big) \in [-1,1]^K,$$
  其中 $P\in\mathbb{R}^{m\times d}$，$m\ll d$，将高维状态压缩为低维控制信号。

### 2.3 训练与记忆携带

- 序列以长度 $L$ 的连续段处理，使用截断 BPTT；状态 $(s,M)$ 跨段传递并定期 detach。
- SSM 和 delta 规则记忆采用精确并行形式（对数深度关联扫描、分块 WY 三角求解），训练可在 GPU 上向量化。

## 3. 实验设计

### 3.1 数据集与任务

- **神经解码基准**：来自 Neural Latents Benchmark 的三个运动皮层记录：
  - **MC RTT**：DANDI 000129，M1 区，随机目标伸手，解码手指速度，130 个神经元。
  - **MC Maze**：DANDI 000128，M1/PMd 区，迷宫伸手，解码手部速度，182 个神经元。
  - **Area2 Bump**：DANDI 000127，体感 2 区，解码手部速度，65 个神经元。
- 每个基准被构造成**联合神经编解码任务**：从同一隐藏状态同时预测下一时间 bin 的群体脉冲（自回归继续）和解码行为速度。损失为：
  $$L = \mathrm{MSE}_{\text{next-spike}} + \lambda\, \mathrm{MSE}_{\text{decode}},\quad \lambda=10.$$
- 脉冲以 50 ms 分箱、高斯平滑、z 评分；主要评价指标是行为解码 $R^2$（因为单次脉冲预测接近噪声地板，两个模型差异不大）。

### 3.2 对比方法

- **现代 Transformer 基线**：decoder-only 结构，包含 pre-norm RMSNorm、RoPE、因果多头自注意力、SwiGLU 前馈块。
- **线性参考**：无记忆岭回归解码器（短因果历史），用于说明非平凡基线。
- **语言建模附加检查**：在 tiny-Shakespeare 和 WikiText-2 两个字节级 BPE 文本语料上，将 VN-SST 与 Transformer 对比。

### 3.3 实验设置细节

- 固定深度 4 层（神经编解码），宽度缩放使两个架构参数范围对齐（Transformer 宽度 40–80，VN-SST 宽度 24–48，因为 VN-SST 有固定开销）。

- **数据效率显著提升**：在数据稀缺的 MC RTT 基准上，VN-SST 解码 $R^2$ 为 0.351，Transformer 为 0.207；在另两个基准上 VN-SST 也领先（Area2 Bump: 0.696 vs 0.632；MC Maze: 0.716 vs 0.655）。

## 7. 优点

- **新颖的架构设计**：将“可编程算子”思想具体化为可学习的低秩指令库，从状态空间记忆的低维读出合成 token 特定权重，而不是简单地混合专家输出。
- **机制可解释性强**：指令代码是从缓慢低维状态中解码的，与神经科学中低维潜变量路由计算的直觉一致；指令库的参与比率和熵提供了可量化的“程序使用量”指标。
