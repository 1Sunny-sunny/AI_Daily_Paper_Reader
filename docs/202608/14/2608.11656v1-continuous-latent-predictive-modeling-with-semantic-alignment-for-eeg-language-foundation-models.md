## 摘要
近年来，脑电基础模型的进展表明，大规模预训练有望实现跨被试、记录环境和数据集的通用神经解码。然而，主流预训练范式面临关键挑战：掩码自编码往往优先考虑低层信号重建而非任务相关语义，而自回归建模则在连续神经动态与离散 token 空间之间产生不匹配。为应对这些挑战，需要新的策略来有效对齐连续脑电表示与自然语言语义，并使其能够与大语言模型集成。为此，我们提出了脑潜变量预测模型（BLPM），一个脑电-语言基础模型，将异构脑电解码任务重新表述为连续语义嵌入预测问题。BLPM 引入连续脑电潜变量预测（CELP）编码器，通过潜目标预测学习可迁移表示。在这些表示的基础上，多查询语义分解（MQSD）模块提取任务相关信息，并根据语义关系在共享潜空间中对齐连续脑电表示与文本语义。多个基准上的实验表明，其在多种任务上具有一致的泛化性能，确立了连续潜语义预测作为脑电-语言基础模型的有效范式。

## Abstract
Recent advances in EEG foundation models have demonstrated the potential of large-scale pretraining to enable generalizable neural decoding across subjects, recording environments, and datasets. However, dominant pretraining paradigms face key challenges: masked autoencoding tends to prioritize low-level signal reconstruction over task-relevant semantics, while autoregressive modeling creates a mismatch between continuous neural dynamics and discrete token spaces. To address these challenges, new strategies are needed to effectively align continuous EEG representations with natural-language semantics and enable their integration with large language models. Accordingly, we propose Brain Latent Predictive Model (BLPM), an EEG-language foundation model that reformulates heterogeneous EEG decoding tasks as a continuous semantic embedding prediction problem. BLPM introduces a Continuous EEG Latent Predictive (CELP) encoder that learns transferable representations through latent target prediction. Building on these representations, a Multi-Query Semantic Decomposition (MQSD) module extracts task-relevant information and aligns continuous EEG representations with textual semantics within a shared latent space according to their semantic relationships. Experiments across multiple benchmarks demonstrate consistent generalization performance across diverse tasks, establishing continuous latent semantic prediction as an effective paradigm for EEG-language foundation models.

- 脑电（EEG）基础模型近年来通过大规模自监督预训练，在跨被试、跨记录环境与跨数据集的神经解码上展现出潜力。
- 但主流预训练范式存在两个关键矛盾：
  - **掩码自编码（MAE）**倾向重建低层信号结构，对波形细节、噪声和个体差异敏感，难以显式组织任务相关语义，且与语言模型语义空间脱节。
  - **自回归建模**将连续 EEG 信号量化成离散 token 后做 next-token 预测，会丢失区分任务相关神经状态的连续判别模式，并引入不必要的表示瓶颈。
- 因此，论文提出 **BLPM（Brain Latent Predictive Model）**，核心思想是：**将异构 EEG 解码任务重新表述为连续语义嵌入预测问题**，在连续潜空间中直接对齐 EEG 表示与自然语言语义，避免离散 token 化和自回归生成。

## 2. 论文提出的方法论

BLPM 主要由三阶段组成，整体框架如图 1 所示。

### 2.1 连续 EEG 潜预测编码器（CELP Encoder）

- **输入分块**：对 EEG 信号 $X_{EEG} \in \mathbb{R}^{C \times T}$，按长度 $L$ 切分为 $P$ 个不重叠段，得到 $X \in \mathbb{R}^{C \times P \times L}$，总 token 数 $N = C \times P$。
- **双分支 patch 嵌入**：
  - 时间分支：1D 卷积提取局部时间动态；
  - 频谱分支：对每个 patch 做 FFT，将幅度谱线性投影到相同维度；
  - 两者相加融合，再施加深度可分离卷积位置编码，展平得到位置编码后的 token 序列 $\tilde Z \in \mathbb{R}^{N \times d}$。
- **联合潜预测预训练**：受 JEPA 启发，包含在线编码器 $f_\theta$、目标编码器 $f_{\bar\theta}$ 和嵌入预测器 $g_\phi$。
  - **结构化多块掩码**：包括时间跨度掩码和通道块掩码，鼓励模型利用时间连续性、通道依赖和跨 token 上下文。
  - **在线编码器**只处理可见 token：$H_v = f_\theta(\tilde Z_{M_v})$。
  - **目标编码器**处理完整序列，参数通过指数移动平均（EMA）更新：$\bar\theta^{(k)} \leftarrow m_k \bar\theta^{(k-1)} + (1-m_k)\theta^{(k)}$。
  - **嵌入预测器**根据可见上下文和可学习掩码 token 预测被掩码位置的潜表示：$\hat H_{M_p} = g_\phi(H_v, m + p_{M_p})$。
  - **损失函数**：在潜空间计算 Smooth L1 损失，目标为层归一化后的目标编码器输出 $h_{t,i}$：
    $$
    \mathcal{L}_{CELP} = \frac{1}{|M|}\sum_{M_p \in M}\frac{1}{|M_p|}\sum_{i \in M_p}\rho\left(\hat h_i, \mathrm{LN}(h_{t,i})\right)
    $$
    其中 $\rho(\cdot,\cdot)$ 为 Smooth L1 损失。
- 预训练完成后，丢弃预测器，在线编码器作为 EEG 编码器骨干，输出 $H_{EEG} \in \mathbb{R}^{C \times P \times d}$。

### 2.2 多查询语义分解与语义对齐（MQSD）

- 冻结 CELP 编码器，将 $H_{EEG}$ 展平为 token 序列 $h \in \mathbb{R}^{N \times d}$，作为交叉注意力的 key 和 value。
- **语言引导语义查询**：固定 $M$ 个语义查询，对应时间动态、频谱特性、空间关系、形态模式等因素。每个查询经 LLM 输入嵌入层得到 $Q_m \in \mathbb{R}^{L_{max} \times d_{LM}}$。
- **多查询 EEG 分解**：
  - 每个查询独立对 EEG token 做交叉注意力：$R_m = \mathrm{CrossAttn}(Q_m, h, h)$；
  - 沿语言 token 维度做掩码平均池化：$\tilde s_m = \mathrm{Pool}_{tok}(R_m)$；
  - 线性投影到 LLM 隐藏维度：$s_m = P_h(\tilde s_m) \in \mathbb{R}^{d_{LM}}$；
  - 汇总为 $S_q = [s_1; s_2; \dots; s_M] \in \mathbb{R}^{M \times d_{LM}}$。
- **语言初始化语义嵌入预测器**：
  - EEG token 也投影到 LLM 嵌入空间：$u = P_u(h) \in \mathbb{R}^{N \times d_{LM}}$；
  - 拼接 $[S_q; u]$ 输入语义嵌入预测器 $G$（预训练 LLM 解码器层，使用双向注意力而非因果掩码）；
  - 取前 $M$ 个查询状态 $H_q = H_{1:M}$，平均池化后映射到文本嵌入空间：$z_e = \mathrm{norm}(P_e(h_{pred}))$。
- **文本语义目标**：每个类别标签 $y$ 表示为自然语言文本 $\ell_y$，用预训练文本编码器得到 $z_y = \mathrm{norm}(E_{text}(\ell_y))$。
- **对齐损失**：双向多正样本 InfoNCE：
  $$
  A_{ij} = z_{e,i}^\top z_{y,j}/\tau
  $$
  $$
  \mathcal{L}_{align} = \frac{1}{2}\left[L_{e \to t} + L_{t \to e}\right]
  $$
  相同语义文本的样本互为正对，避免同类样本被当作负样本。

### 2.3 多任务指令调优与语义匹配推理

- **指令条件语义预测**：任务指令 $s_k$ 嵌入为 $T_k$，拼接 $[T_k; S_q; u]$ 输入非因果 LLM 预测器，得到查询状态 $H_q^{(k)}$，经共享答案预测头 $P_a$ 得到预测答案嵌入 $\hat z$。
- **调优损失**：同样使用双向多正样本 InfoNCE，对齐 $\hat z$ 与对应的目标语义嵌入 $z_y$。
- **推理**：对任务 $k$ 的候选标签文本编码为 $z_c$，通过余弦相似度匹配：
  $$
  \hat y = \arg\max_{c \in C_k} \hat z^\top z_c
  $$
  无需自回归生成，且候选标签集可作为输入灵活变化。

## 3. 实验设计

### 3.1 数据集与场景

- **预训练**：TUEG（Temple University Hospital EEG Corpus），包含 69,652 段记录、14,987 名被试、总计 27,062 小时临床 EEG。
- **下游任务（7 个）**：
  - COG-BCI：心理负荷三分类；
  - Mental Arithmetic：心理压力二分类；
  - TUAB：异常 EEG 二分类；
  - TUEV：临床事件六分类；
  - PhysioNet-MI：运动想象四分类；
  - FACED：九类情绪识别；
  - HMC：五类睡眠分期。
- 这些任务覆盖临床、睡眠、内部状态和 BCI 解码四类场景。

### 3.2 Benchmark 与评估协议

- 使用 **NeuralBench** 统一框架进行公平评估，配合 NeuralSet 复现各基线原始预处理流程。
- 评估指标：
  - 多分类：Balanced Accuracy、Cohen’s Kappa、Weighted F1；
  - 二分类：Balanced Accuracy、AUPRC、AUROC。
- 每个模型选择验证集最佳 checkpoint，测试集上报告 5 个随机种子的均值与标准差。

### 3.3 对比方法

- **任务特定模型**：EEGNet、EEGConformer（每个任务单独训练）。
- **EEG 基础模型**：BIOT、LaBraM、CBraMod、REVE、LUNA（每个数据集单独微调，带任务特定分类头）。
- **BLPM**：统一多任务模型，使用指令条件语义嵌入预测，无任务特定分类头。
