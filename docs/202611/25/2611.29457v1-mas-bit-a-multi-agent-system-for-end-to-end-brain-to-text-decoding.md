## 摘要
语音脑机接口旨在通过将神经活动转化为文本恢复交流，然而端到端解码器在准确性上历来落后于级联系统。我们提出了面向脑到文本的多智能体系统（MAS-BIT），这是第一个从颅内记录进行端到端脑到文本解码的多智能体框架。MAS-BIT 协调三个专用智能体：解读连续神经表征的神经智能体、解码软音素后验概率的语音智能体，以及仲裁智能体，该仲裁智能体整合它们的互补证据并直接访问神经表征以生成最终转录。专家智能体通过基于词元嵌入的潜在通信与仲裁者交流，将连续消息构建为词元嵌入的概率加权组合。这些消息保留备选词元假设，并提供一个可微接口，通过该接口，句子级监督跨参与者联合训练神经编码器和专用智能体。MAS-BIT 在 Brain-to-Text '24 和 '25 基准上取得了最先进的端到端解码性能，在 '24 上词错误率为 6.929%，在 '25 公开测试集上为 3.606%（私有测试集为 3.892%）。这些结果在 '25 公开数据集上超越了已发表的 BIT 级联系统，并在 '24 上缩小了差距，且无需集成独立训练的模型或使用外部语言模型重评分。

## Abstract
Speech brain-computer interfaces aim to restore communication by translating neural activity into text, yet end-to-end decoders have historically trailed cascaded systems in accuracy. We introduce a Multi-Agent System for BraIn-to-Text (MAS-BIT), the first multi-agent framework for end-to-end brain-to-text decoding from intracortical recordings. MAS-BIT coordinates three specialized agents: a neural agent that interprets continuous neural representations, a phonetic agent that decodes soft phoneme posteriors, and an arbitration agent that integrates their complementary evidence with direct access to neural representations to generate the final transcription. The expert agents communicate with the arbiter through token-embedding-based latent communication, constructing continuous messages as probability-weighted combinations of token embeddings. These messages retain alternative token hypotheses and provide a differentiable interface through which sentence-level supervision jointly trains the neural encoders and specialized agents across participants. MAS-BIT achieves state-of-the-art end-to-end decoding performance on the Brain-to-Text '24 and '25 benchmarks, with word error rates of 6.929% on '24 and 3.606% on the '25 public test set (3.892% on the private test set). These results surpass the published BIT cascade on the '25 public set and narrow the gap on '24, without ensembling independently trained models or using external language-model rescoring.

## 2. 方法论

### 2.1 总体架构

- MAS-BIT 包含三个语言智能体：
  - **神经专家 $N$**：读取连续神经表征 $Z_N$。
  - **语音专家 $P$**：读取软音素后验加权嵌入 $Z_P$。
  - **仲裁智能体 $A$**：同时读取 $Z_N$ 和两个专家的潜在消息。
- 三个智能体共享冻结的 Qwen3-ASR-1.7B 文本解码器主干，但各自使用独立的 LoRA 适配器。
- 输入使用两个 BIT 初始化的神经编码器，通过参与者特定输入投影处理同一段神经记录。

### 2.2 神经与语音证据构建

- 设神经特征为 $X$，两个编码器输出隐藏状态为 $H_1,H_2$。
- 融合后的连续神经表征为：

$$Z_N = J\big([\mathrm{LN}(H_1);\mathrm{LN}(H_2)]\big)$$

其中 $J$ 是两层投影器，把拼接后的 768 维映射到语言模型宽度 2048 维。

- 每个编码器通过音素读出层产生音素后验：

$$Q_j = \mathrm{softmax}(H_j W_{C,j}+b_{C,j})$$

- 两个编码器的期望音素嵌入相加，得到语音接口：

$$Z_P = Q_1 U_{ph,1} + Q_2 U_{ph,2}$$

其中 $U_{ph,j}$ 是 41 类音素对应的可学习嵌入表。

### 2.3 潜在通信机制

- 每个专家先贪婪生成草稿 $\hat{y}^r$，然后以该草稿作为上下文重新计算下一个 token 的对数概率 $\ell_t^r$。
- 在温度 $\tau=1$ 下，选取概率最大的 16 个 token，构造概率加权 token 嵌入：

$$a_{t,v}^r = \frac{\exp(\ell_{t,v}^r/\tau)}{\sum_{u\in K_t^r}\exp(\ell_{t,u}^r/\tau)}$$

$$\bar{m}_t^r = \sum_{v\in K_t^r} a_{t,v}^r E_v$$

其中 $E_v$ 是冻结 token 嵌入，$K_t^r$ 是 top-16 token 集合。

- 加入可学习角色嵌入 $e_r$ 后得到最终消息：

$$m_t^r = \bar{m}_t^r + e_r$$

- 仲裁智能体输入为：

$$Z_A = [Z_N; M_N; M_P]$$

其中 $M_N,M_P$ 是神经专家和语音专家的消息序列。

### 2.4 训练目标与阶段

- 三个智能体都使用教师强制交叉熵损失，分别为 $L_{CE}^N, L_{CE}^P, L_{CE}^A$。
- 加入中间层 CTC 辅助损失，最终损失为：

$$L = L_{CE}^N + L_{CE}^P + L_{CE}^A + 0.3\,L_{CTC}^{(7)} + 0.05\,\rho\,\frac{L_{CTC}^{(3)}+L_{CTC}^{(5)}}{2}$$

其中 $\rho$ 在编码器开始更新后的第一个 epoch 内从 0 线性增加到 1。

- 训练采用分阶段策略：

$$\text{Align }5 \to \text{Enc }5 \to N\,5 \to P\,5 \to A\,5 \to \text{Joint }40$$

即先对齐 5 个 epoch，再编码器适应 5 个 epoch，然后分别训练神经专家、语音专家、仲裁器各 5 个 epoch，最后联合优化 40 个 epoch，总计最多 65 个 epoch。

## 3. 实验设计

### 3.3 消融与对照实验

主要包括以下对照：

- **Single agent, two views**：单一智能体同时接收神经和音素视图。
- **Rank-24 adapter**：扩大单智能体 LoRA 容量，匹配三个 rank-8 适配器参数量。
- **Borealis-5B backbone**：把解码器换成 4B 音频训练模型。
- **Sequential dual-view refinement**：匹配参数和三轮解码，但不是专用专家，而是串行细化。
- **Hard-text communication**：用离散 token 嵌入替代概率加权消息。
- **Detached latent messages**：保留 top-16 加权消息，但切断仲裁损失对消息的梯度。
- **Message-only arbiter**：仲裁器只接收专家消息，去掉直接神经输入 $Z_N$。
- **Two neural experts**：用第二个神经专家替代语音专家。
- **Separate participant training**：每个参与者单独训练。
- **No staged training**：从第一个 epoch 更新全部适应参数。
- 此外还有固定权重下的 **消息掩码干预**、**token 支持度 $k$ 变化**、**RSA 表征分析**等实验。

## 6. 主要结论与发现

- MAS-BIT 在 Brain-to-Text ’24 holdout 上达到 **6.929% WER**，在 ’25 public 上达到 **3.606%**，private 上达到 **3.892%**，建立新的端到端 SOTA。
- 相比单模型 BIT 端到端，T12 和 T15 public 的 WER 分别下降 **8.74** 和 **7.45** 个百分点；相对改进为 **55.8%** 和 **67.4%**。
- 相比 BIT End-to-End + Ensemble，MAS-BIT 仍分别降低 **3.29** 和 **4.15** 个百分点。
- MAS-BIT 在 T15 public 上超过已发表的 BIT 级联系统 **0.454** 个百分点；在 T12 上把差距缩小到 **0.58** 个百分点。
- 在复现级联比较中，MAS-BIT 在所有候选句子数 $K=1$ 到 $100$ 下均优于复现 cascade。
- 推理资源显著低于级联系统，主机内存低至约 1/10 到 1/25，GPU 显存约 1/3，解码速度约 1.8 倍于级联、2.3–3.6 倍于 LightBeam。
- 消融实验证明：
  - 专用专家优于容量匹配的单一解码器。
  - 潜在可微消息优于离散文本消息。
  - 直接神经输入对仲裁器的正确恢复至关重要。
  - 音素证据与神经证据互补。
  - 跨参与者联合训练和分阶段训练都能降低 WER。
- 仲裁器能在两个专家都错时恢复正确句子，其中许多无法通过简单重组两个草稿得到，说明它不只是做“草稿选择或拼接”。

## 7. 优点

- **方法论创新**：首次把多智能体分工、潜在连续通信和信号接地仲裁引入脑到文本解码，设计合理。
- **可微通信接口**：token 嵌入概率加权消息既保留备选假设，又让句子级目标能通过消息反向传播训练上游专家和编码器。
- **性能强**：在无需集成或外部 LM 重评分的情况下，建立端到端 SOTA，并在部分场景超过级联系统。
- **效率突出**：共享冻结主干 + LoRA 适配器使推理资源大幅低于传统 WFST 级联系统。
- **实验严谨**：设置了容量匹配、参数匹配、串行细化等多种对照，避免把收益简单归因于参数增加或多轮解码。
- **分析深入**：包括词级互补性、消息掩码、token 支持度、RSA 表征对齐等，揭示了模型为何有效。
- **可复现性好**：代码和模型权重公开，详细的附录参数、prompt、优化器、数据增强等有较多说明。

## 8. 不足与局限

- **参与者样本有限**：只在 T12 和 T15 两名参与者上评估，泛化到更多患者和电极配置仍未知。
- **离线评估**：编码器使用双向注意力，专家先草稿后仲裁的顺序设计不适合低延迟在线流式场景。
- **训练算力披露不足**：未明确训练 GPU 型号、数量、训练总时间，只有推理硬件和资源测量。
- **公开测试集风险**：代码和权重公开，但论文本身没有详细描述防止测试集过拟合的机制；T15 部分 baseline 子集未指定，外部对比存在轻微不公平风险。
- **阶段训练超参数较多**：五阶段训练、不同优化器、中间 CTC 权重等设计较多，对超参数调优成本较高。
- **通信轮次固定**：仅采用单轮专家到仲裁者通信，没有探索多轮协商或自适应仲裁。
- **隐私与伦理限制**：论文提到扩展到 inner speech 需要用户同意和隐私保护，目前尚未涉及。
