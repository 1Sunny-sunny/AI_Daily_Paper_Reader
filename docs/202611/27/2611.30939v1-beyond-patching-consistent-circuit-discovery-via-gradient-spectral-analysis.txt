Abstract
Mechanistic interpretability seeks to reverse-engineer neural networks by iden-
tifying small, faithful subgraphs—circuits—that implement specific behaviors.
The dominant paradigm scores each unit by replacing its clean activation with
a corrupted counterpart as causal intervention. While effective, this approach
rests on a brittle prerequisite: the structure prompt pairs are task-specific, ex-
pensive to engineer, and silently couple the discovered circuit to prompt-design
choices. In this work, we propose Spectral Circuit Analysis (SCA), a gradient-
spectral pipeline that achieves consistent circuit discovery along both axes: sta-
ble across input formulations of the same task, and natively exposing struc-
ture shared across tasks. Our contributions are threefold. First, we provide a
counterfactual-free reframing of circuit discovery: causally relevant directions are
recoverable from the spectral structure of forward gradients across paraphrases,
with leading directions concentrating task signal and trailing ones absorbing para-
phrase noise—yielding circuits tied to the task rather than the prompt. Second,
we introduce SCA, a block-wise SVD pipeline that extracts a task subspace
per architectural block and redistributes spectral energy onto constituent units
via a consistency-weighted share, producing per-unit rankings competitive with
attribution-patching baselines under strictly less supervision. Finally, on twelve
circuit-discovery tasks in GPT-2 Small and Pythia-160M, SCA performs compara-
bly or exceeds EAP-family methods under the standard recovery-score protocol
and recovers IOI canonical heads with Precision@K = 1.0 in top-10 slices on
GPT-2 Small; the same machinery extends to a unified cross-task analysis clas-
sifying units as universal, family-shared, or task-specific and exposing composi-
tional structure invisible to per-task analyses. Our code and data are available at
https://github.com/YujieZhangzz/Spectral-Circuit-Analysis.

Introduction
Mechanistic interpretability seeks to reverse-engineer neural networks by identifying small, faithful
subgraphs—circuits—that implement specific behaviors [34, 6]. Case studies on indirect object
identification [44], factual recall [26, 27], and in-context learning [35] share a precise geometric
premise: high-level task variables admit low-dimensional, often near-linear representations in trans-
former activation space [36, 23, 9, 41], with inter-layer communication itself routed through low-rank
channels [29]. Circuit discovery, at its core, is the recovery of low-rank task-relevant structure.
The dominant operationalization casts this recovery as a problem of causal intervention. Beginning
with causal mediation analysis [43] and matured through automated discovery [5], first-order ap-
proximations [40, 15, 21], and differentiable mask optimization [2], this paradigm scores each unit
by replacing its clean activation with a corrupted counterpart, the best-practice studies mapping the
space [16, 46]. Across this lineage, however, the recovered circuit depends sensitively on the chosen

contrast: corruption choices change recovered components in unpredictable ways [46], circuits discov-
ered on a fixed template do not always generalize across paraphrases [32], and distinct counterfactual
designs for the same task can induce systematically different circuits [13, 8]. As task suites grow,
this coupling between counterfactual design and recovered circuit motivates complementary methods
that operate without contrast construction—pursued recently via information-flow attribution [7],
contextual decomposition [18], and sparse-feature circuits [24]. Independently, cross-task investi-
gations [28, 12] suggest that a substantial fraction of circuit machinery is shared across tasks, yet
existing pipelines discover circuits one task at a time and only compare post hoc.
We pursue consistent circuit discovery along both axes: a single procedure stable across input
formulations of the same task and natively exposing structure shared across tasks. Our key observation
is that the information identifying causally relevant units is already encoded in the spectrum of the
forward task gradient, recoverable from semantically related prompts alone. Two properties make
this spectrum a natural target. First, task-relevant computation in transformers is intrinsically low-
rank: rank-one MLP edits install factual associations [26], singular vectors of weight matrices
align with token features [30], and modest-dimensional per-head subspaces capture in-context
arithmetic [20]. The forward gradient inherits this geometry—its dominant directions form a low-rank
subspace not generally aligned with per-unit coordinate axes, calling for spectral rather than unit-
wise decomposition. Second, this subspace is invariant under semantic-preserving transformations:
paraphrases of one prompt elicit gradients that share a task-specific subspace while differing only in
surface-form noise. singular value decomposition (SVD) on stacked paraphrase gradients exploits
this directly—leading directions concentrate consistent task signal, trailing ones absorb paraphrase-
specific variation—yielding a circuit description tied to the task rather than to any particular prompt.
Building on this, we propose Spectral Circuit Analysis (SCA), a gradient-spectral pipeline that
applies SVD to per-paraphrase gradients block-wise within each (layer, type) block and redistributes
spectral energy to attention heads and MLP units via a consistency-weighted share. The block-
wise design follows a recurring pattern in transformer analysis: low-rank structure aligns with
the architecture’s per-block decomposition. Parameter-efficient adaptation exploits this directly-
LoRA injects independent low-rank adapters per layer [19]—and circuit discovery reflects the same
geometry, with IOI units grouped into contiguous attention layers [44], factual recall localized to
mid-layer MLPs [26, 11], and induction heads concentrated in early-layer attention [35]. Units within
a block share residual-stream geometry and low-rank communication channels [29, 6], making a
shared spectral basis the natural object of analysis; cross-block structure then emerges from unit-level
subspace overlap, whose induced geometric similarity also provides the cross-task signal: classifying
units as universal, family-shared, or task-specific [4] within the same machinery. On twelve circuit-
discovery tasks in GPT-2 Small [37] and Pythia-160M [3], SCA performs comparably or exceeds
EAP-family baselines [40, 15] under the standard recovery-score protocol, and recovers IOI canonical
heads with Precision@K = 1.0 in top-10 slices on GPT-2 Small [44] ; Cross-task analysis exposes a
sharp layer-wise partition: early-layer attention is broadly universal [12, 28], while late layers host
narrow family-level circuits. Our contributions are as follow:
• A counterfactual-free reframing of circuit discovery. We show that causally relevant computa-
tional directions are recoverable from the spectral structure of forward gradients across paraphrased
prompts, complementing the patching paradigm with an input-consistent route.
• The SCA algorithm. A block-wise SVD pipeline that extracts a task subspace per architectural
block and redistributes spectral energy to constituent units via a consistency-weighted share,
yielding per-unit rankings competitive with state-of-the-art attribution patching while consuming
strictly less supervision.
• A unified cross-task analysis framework. The same per-unit subspaces that drive single-task
discovery directly support cross-task comparison, classifying units into universal, family-shared,
and task-specific roles and uncovering compositional structure.

Circuit discovery and the ranking protocol. A circuit discovery method A takes fθ and T as
input and outputs a description of the units most responsible for T . The form of this output varies:
greedy search produces a discrete subset [5], while attribution patching produces per-unit scalar

ranking: u(1), u(2), . . . , u(|U|) with I(u(1)) ≥I(u(2)) ≥· · · , where parenthesized subscripts denote
rank order. A circuit at any budget K is read off as the top-K prefix CK = {u(1), . . . , u(K)}. The
quality of A is measured by how rapidly the metric M(fθ | CK)—evaluated with units in CK replaced
by their corrupted activations while the remaining units retain their clean activations—departs from
the clean metric M(fθ) as K grows. We formalize this as the recovery score rA(K) in Section 4.

SCA: Our Proposed Method
3.1
Single-Task Circuit Discovery
We propose Spectral Circuit Analysis (SCA), a gradient-spectral pipeline that ranks units by their
participation in a task’s shared computation. Our key observation is that while single input gradients
are noisy, gradients of semantically equivalent paraphrases share a common direction in parameter
space that reflects the task itself; across units that read from and write to the same residual stream,
this direction generalizes to a low-dimensional semantic subspace on which their gradients jointly lie.

input recovers a ranking comparable to EAP-family attribution—isolating cross-instance subspace
geometry as the operative signal underlying SCA.

Late-layer attention hosts family- and task-specific circuits. Specialization concentrates in L7–L11
attention. We highlight four findings, each cross-validated against ablation lift in Table 1.
(i) The Numeric Comparison family is hosted by an exceptionally narrow circuit. Just two heads
(GTspec, principally L9H1, L10H7) drive the numeric comparison computation. Restoring the pro-
jection onto these two units yields a modest in-family lift of +0.32/ + 0.40, but with extreme
size-matched z-scores (zGT = +79.5, zGT$ = +46.2); all other ten tasks have |z| < 1. The in-
family/out-of-family ratio of |2.9| marks GT as the most computationally compressed family in our
suite.
(ii) The Factual Recall family is even more isolated. The 2-head broad set lifts PC (z =+119) and
CC (z =+67.6) and almost nothing else, giving an in/out ratio of |72.6|—the highest of any family
and consistent with entity→attribute retrieval being a highly localized operation.
(iii) The 7-unit IOI-specific cohort recovers the canonical IOI circuit [44]. Six of the seven SCA-
discovered IOI task-specific units— L7H3, L7H9 (S-Inhibition); L8H6 (S-Inhibition); L9H6, L9H9
(Name Mover); L10H2 (Backup Name Mover)—fall within Wang et al.’s 26-head canonical IOI
circuit, and all three layers of the canonical hierarchy (S-Inhibition, Name Mover, Backup Name
Mover) are recovered. The remaining unit (L8H3) is an immediate layer-mate of an S-Inhibition head
not in Wang’s enumeration. Causally, this cohort lifts only IOI (+0.67, z =+3.6); |z|<1 on every
other task. The fact that an importance-and-overlap procedure recovers a community-validated circuit
without using IOI as a target is, to our knowledge, the strongest external validation available for
unsupervised circuit-discovery methods of this type.
(iv) Single-head readers exhibit graded specificity. L8H11 carries the highest CC z-score (z =+46)
but exhibits real spillover into PC (z = +40), GB (z = +18), and GT (z = +18), identifying it as
an entity→attribute reader most strongly recruited by CC rather than as a strictly single-task head.
L10H11, by contrast, is genuinely PP-specific (zPP =+5.4, all other |z|<1).
5
Conclusion
In this work, we presented a gradient-spectral perspective on consistent circuit discovery, showing
that the information identifying causally relevant components is already encoded in the spectrum
of forward task gradients across paraphrased prompts. We demonstrated that prior gradient-based
attribution methods, by reducing per-instance gradients to component-wise scalars, are blind to the
rotated low-rank subspace structure that distinguishes task-relevant directions from task-irrelevant
ones. To address this, we proposed SCA, which applies block-wise SVD to paraphrase-derived
gradients and redistributes spectral energy to attention heads and MLP units via a consistency-
weighted share, yielding a circuit description that is stable across input formulations of the same
task. SCA performs comparably or exceeds EAP-family baselines on twelve circuit-discovery tasks
in GPT-2 Small and Pythia-160M, and the same per-unit subspaces that drive single-task discovery
9


directly support cross-task comparison, exposing universal infrastructure, narrow family-level circuits,
and compositional reuse patterns invisible to per-task analysis. We discuss limitations and future
work directions in Appendix A.

A
Limitation and Future Work
SCA’s spectral subspaces are interpretive lenses rather than guaranteed mediators; we validate them
via projection-based ablation (Table 1) but acknowledge that subspace recovery, like activation
patching [46], has design choices—paraphrase-set composition (whose underlying sign-consistency
distribution is itself model-dependent; see Appendix G.3), energy threshold η, layer-type aggrega-
tion—whose sensitivity warrants further study. Our experiments are confined to GPT-2 Small and
Pythia-160M; scaling SCA to billion-parameter models will require Gram-trick variants and is an
immediate next step. More broadly, we view SCA as complementary to the matched-counterfactual
paradigm rather than a replacement: counterfactual-driven methods provide direct causal interventions
on token-level contrasts, while paraphrase-driven spectral methods provide a task-level geometric
view. Combining the two—e.g., using SCA-discovered subspaces to seed targeted counterfactual
patching—appears to be a productive direction.
Outlook.
Several recent threads converge on the view that transformer computation is fundamentally
low-rank and task-conditioned [36, 41, 29, 20]. SCA offers one operationalization of this view:
it shows that the spectrum of the forward gradient, taken across paraphrases, is rich enough to
recover circuit-level structure, identify cross-task computational primitives, and surface compositional
patterns that single-task discovery cannot reveal. We hope this encourages further work on attribution
methods that leverage the geometric structure of model parameters and gradients beyond per-edge
causal intervention.
B
Extended Discussion on Related Work
Circuit Discovery and Attribution. Circuit-discovery methods differ primarily in how they quantify
component importance. Intervention-based approaches estimate importance via activation replace-
ment, including causal mediation analysis [43], ACDC [5], activation patching [26, 27], and its
first-order approximations [33, 40, 15, 21]. Counterfactual-free [32] alternatives instead rely on
different attribution objects: token-level propagation rules [7], causal graphs over dictionary-learned
features [24], or analytical layer-wise decompositions [18]. SCA likewise operates without counter-
factual prompts, but takes the cross-instance spectrum of task gradients as its attribution object.
Geometric Structure as a Discovery Procedure. There’s a line of research leverages low-rank
structure for mechanistic discovery. DAS [9] aligns interpretable variables with activation subspaces;
[26, 27] write rank-one updates to install factual associations; function vectors [41] are read out
and patched to trigger task execution; SVD-of-weights analyses [30] and inter-layer communication
studies [29] use singular directions as objects of interpretation. Closest to our spectral framing, Ahmad
et al. [1] apply SVD to a transformer’s pre-trained component weights and use an optimization-based
mask to identify functionally important singular directions within components. However, in SCA, the
SVD is taken over forward task gradients across paraphrases, not over frozen weights.

D.1
Edge Attribution Patching
Activation patching [44] measures the causal contribution of an internal component by replacing
its activation with a counterfactual value drawn from a corrupted run and observing the resulting
change in a task metric M. Let E denote the set of edges in the model’s computation graph between
attention heads, MLPs, and the residual stream. Applied exhaustively at the edge level, this procedure
requires one forward pass per edge, which scales poorly: even GPT-2 Small contains on the order of
104 edges between attention heads, MLPs, and the residual stream. Edge Attribution Patching (EAP)
and its variants approximate this effect with gradients, reducing the cost from O(|E|) forward passes
to a small constant number of forward–backward passes.

E.2.3
Family-Layout Robustness
The family-membership classifier of Section 3.2 is parametrized by the family layout F. Singleton-
as-family layouts are degenerate: a single-member family has no within-family pair, leaving withinF
undefined. We therefore evaluate two non-degenerate layouts in parallel:
• v1 (strict): F contains only the multi-task families specified a priori from the task taxonomy;
tasks not belonging to any such family are family-ineligible and can only be assigned by
gates G1, G3, or G4.
• v2 (catch-all): F additionally pools every otherwise-orphan task into a single catch-all
family, allowing all tasks to participate in G2 evaluation.
For each gate’s two aggregation choices (min, mean) we re-run the classifier under both layouts,
yielding four label assignments per unit. Units receiving the same headline label (UNIVERSAL,
FAMILY-F for the same F, TASK-t∗for the same t∗, or MIXED) under all four configurations are
tagged layout-stable; only layout-stable assignments enter the headline counts of Section 4, while
layout-sensitive units are reported separately.

Paraphrase Methodology
F.2.1
Approach
F.3
Approach
All paraphrase templates were generated by a large language model and then verified by the
authors. Specifically, Anthropic’s Claude (Sonnet/Opus, accessed through the Claude.ai web
interface) was prompted to produce candidate paraphrase templates for each task, given the original
clean / corrupted stimulus and the task-specific hard invariants (last-token preservation, entity-
count preservation, no answer-leaking vocabulary in the template frame, etc.). The model also
generated the verification scripts that statically and dynamically check these invariants. The authors
then manually inspected each template for fluency and semantic equivalence, edited or rejected
templates that failed inspection, and ran the verification scripts on every generated paraphrase pair.
Templates that did not pass all hard invariants were discarded; only templates that passed both human
inspection and automated verification are included in the released datasets.
The released datasets themselves are produced by deterministic template-substitution scripts
(Python 3, no model dependencies); no paraphrase text is generated by a language model at
runtime. Random sampling steps (e.g. selecting one of twelve discourse-setting frames in SVA /
Country-Capital) use random.Random(42), so the released datasets are fully reproducible.
Why a template-based release rather than runtime neural paraphrasing? Three reasons:
1. Exact preservation of the corruption pattern. Mechanistic-interpretability evaluation
requires that pclean and pcorrupted differ only at the entity position(s) of the original task,
with the same flipped values as the original. A neural paraphraser used at runtime cannot
guarantee this byte-level invariant; even strong models substitute pronouns, drop modifiers,
or reorder constituents in ways that violate the corruption identity. Authoring templates
once and substituting slot fillers deterministically lets us guarantee the invariant exactly.
2. Hard-constraint verifiability. We require every paraphrase pair to satisfy a fixed set of
hard invariants (last-token preservation, entity-count preservation, byte-identical prefix and
suffix between pclean and pcorrupted, no answer-leaking vocabulary in the template frame).
These invariants are statically and runtime-verifiable for fixed templates, and infeasible to
enforce on free-form neural paraphraser outputs.
3. Forbidden-vocabulary enforcement. Several tasks require that no answer-leaking word
appear in the template frame: profession words for PP, country/nationality words for PC and
CC, gendered pronouns for GB and GP, colour and object words outside the original scene
for CO. Static forbidden-list checks are straightforward for fixed templates and difficult for
free-form neural-paraphraser outputs.
Every generated paraphrase pair (pclean, pcorrupted) is verified against the hard invariants in Table 4;
generation halts with an assertion error if any invariant fails.
H3 is enforced via byte-level partition around the entity slot, so each paraphrase decomposes as
prefix + slot_filler + suffix and the prefix and suffix bytes are required to match exactly
between pclean and pcorrupted. This is stricter than mere lexical identity; it eliminates any prefix/suffix
drift that could contaminate the clean-vs-corrupted logit difference.

IOI.
15 paraphrases per row, each ending with the literal token to. Within each of the seven base
templates, the operations applied are:
• Subordinate-clause fronting — “While A and B were ..., S handed a Y to”
• It-cleft on the event clause — “It was at the X that S gave a Y to”
• Participial / possessive NP — “Following A and B’s trip to the X, ...”
• Sentence splitting — “A and B visited the X. S then handed a Y to”
• Connective and verb variation — Then →Afterwards / Later / Next; gave →handed /
passed / offered / presented
• Light reversal — location fronting (“At the X, A and B ...”)
GB.
5 paraphrases per row, each preserving the original complementiser (that or because) at the
final position:
• Adverbial fronting — “Earlier that day, the {occupation} {verb} {comp}”
• Evaluative adverb — “Apparently, the {occupation} {verb} {comp}”
• It-cleft on the subject — “It was the {occupation} who {verb} {comp}”
• Parenthetical insertion — “The {occupation}, by all accounts, {verb} {comp}”
• Post-nominal modifier — “The {occupation} at the time {verb} {comp}”
Gendered tokens (he, she, man, woman, etc.) are forbidden in the template frame.
GP.
5 paraphrases per base template (18 base templates × 5 = 90 unique paraphrase templates),
authored by direct restructuring of the original sentence — no third-party narrators, journalists,
archives, or other external sources are introduced. Operations:
• Adverbial-clause synonym — “After the long meeting, ...” →“Following the long
meeting, ...”
• Subordinate-time recasting — “After the long meeting, ...” →“Once the long meeting
was over, ...”
• Prepositional-phrase recasting — “After the long meeting, . . . ” →“At the end of the long
meeting, ...”
• Sentence splitting — “After the long meeting, X said that” →“The long meeting was
finally over. X said that”
• Mid-position adverbial insertion — “X, after the long meeting, said that”
A subset of templates uses participial or conditional restructurings.

SVA/SVA-Binary.
5 paraphrases per row through discourse embedding. The original stimulus is

one setting and produce five syntactically distinct realisations of that setting:
• Declarative + that-complement — “The novel records that {stim}”

• What-cleft — “What the novel records is that {stim}”
• Adverbial fronting (no that) — “In the novel, {stim}”
• Biclausal conditional — “If you turn the next page of the novel, you will read that {stim}”
The original SVA contrast (head-noun number flip) is preserved exactly inside the embedded clause.
SVA-BLiMP.
5 surface-form perturbations per row, applied within the embedded relative clause
and on peripheral modifiers:
• Relative-pronoun substitution — “students who loved” →“students that loved”
• Participial recasting — “students who loved” →“students having loved”
• Reduced-relative recasting — “students who loved X” →“students fond of X”
• Mid-position adverbial insertion — “These students who loved X” →“These students, in
their youth, who loved X”
• Determiner / quantifier alternation — “These students” →“All of these students”
Pronouns and other number-marked elements outside the original head NP are forbidden in the

5 paraphrases per row, all retaining the literal sentence-final substring “the year YY”:
• Declarative active SVO — “The {noun} ran from the year YYZZ until the year YY”
• Passive PP — “The {noun} was conducted from the year YYZZ to the year YY”
• Fronted temporal adverbial — “Beginning in the year YYZZ, the {noun} continued until
the year YY”
• Nominal inversion — “The duration of the {noun} spanned from the year YYZZ to the
year YY”
• It-cleft — “It was the {noun} that ran from the year YYZZ to the year YY”
Template frames contain no digits, so no spurious 4-digit year or stray 2-digit YY value can leak into
the prompt.

5 paraphrases per row using shopping-domain verbs and frames, ending with the literal

• Passive PP — “That {noun} is priced from $ XXZZ to $ XX”
• Fronted temporal adverbial — “Starting at $ XXZZ, the price of that {noun} can reach $
XX”
• Nominal inversion — “The cost of that {noun} spans from $ XXZZ to $ XX”
• It-cleft — “It is that {noun} that costs anywhere from $ XXZZ to $ XX”
As in GT, the template frame contains no digits.

F.4
Evaluation Metrics
We evaluate circuit recovery across paraphrases using two complementary signal-magnitude metrics
together with the three standard circuit-quality metrics from the literature.
F.4.1
Logit difference
For a paraphrase pair (pclean, pcorrupted) with target tokens tclean and tcorrupted, the logit difference at the
prediction position is
LD(pclean) = logitpclean[tclean] −logitpclean[tcorrupted],
LD(pcorrupted) = logitpcorrupted[tclean] −logitpcorrupted[tcorrupted].
A correctly functioning circuit produces a positive LD(pclean) and a negative LD(pcorrupted). The
clean-vs-corrupted spread,
∆LD = LD(pclean) −LD(pcorrupted),
is the canonical signal-magnitude statistic used in IOI-style circuit analysis [44]. For tasks whose
target spans multiple tokens (e.g. multi-token country names in CC or PC), we use the first target
token throughout, consistent with the original task releases.
F.4.2
Probability difference
For tasks where unnormalised logits can be misleading (e.g. when adjacent- vocabulary tokens
absorb probability mass disproportionately, or when prompts have very different total log-probability
mass), we additionally report the probability difference at the prediction position. Let p(·) =
softmax(logit(·)). Then
PD(pclean) = ppclean[tclean] −ppclean[tcorrupted],
PD(pcorrupted) = ppcorrupted[tclean] −ppcorrupted[tcorrupted],
with the spread
∆PD = PD(pclean) −PD(pcorrupted).
Probability difference is bounded in [−1, 1] and is more directly comparable across prompts of
different total log-probability mass than unnormalised logit difference.
For the greater-than tasks (GT-Year, GT-Price), and SVA tasks (SVA, SVA-BLiMP) where the target
is a set of admissible 2-digit completions rather than a single token, we use the set-aggregated
probability-mass form following Hanna et al. [15]:
PDGT(p) =

summed over all 2-digit-year (or 2-digit-suffix) tokens y admissible at the prediction position.

G.1
SCA Evaluation on GPT-2 Small with More Tasks
Figure 5 reports recovery scores rA(K) for SCA and the six baselines on the remaining six tasks:
Person–Country, SVA, SVA-Binary, Gendered Pronoun, Greater-Than-Price, and Person–Profession.
SCA matches the EAP family on Person–Country, SVA, and SVA-Binary. On Person–Country
(Figure 5a), SCA descends jointly with the EAP variants and reaches near-zero recovery within
K ∈[10, 20]. On SVA and SVA-Binary (Figures 5b, 2f), all causally grounded attribution methods—
SCA, the three EAP variants, and Magnitude—plateau at rA(K) ≈0.25–0.35, while Direction sits
at or above Random throughout. The shared floor across methods that disagree on ranking criterion
indicates a property of the task and the attention-head-only evaluation budget rather than an attribution
failure: a non-trivial fraction of the clean–floor logit gap on these subject–verb agreement tasks is not
30


recovered by patching attention heads alone, consistent with prior evidence that MLP sublayers carry
substantial agreement computation [10]. Within this ceiling, SCA reaches the floor at the same K as
the EAP-IG variants.
A modest gap appears on Gendered Pronoun, Greater-Than-Price, and Person–Profession. On
these three tasks (Figures 5d, 5e, 5f), SCA reaches the floor but with a small K-offset relative to
EAP-IG and EAP-IG-KL: SCA passes through rA ≈0.2 at K ≈20–40, while the EAP-IG variants
pass the same value at K ≈5–15. The gap is most visible on Gendered Pronoun, where SCA exhibits
a brief plateau around K ∈[10, 40] before resuming descent. We do not read this as a refutation of
the method—all three curves still fall well below the Random band and reach near-zero by K ≈60,
and SCA achieves this without requiring counterfactual prompt pairs—but it does mark an honest
boundary: edge-level activation attribution with integrated gradients enjoys an advantage on tasks
where the relevant computation is concentrated in a small number of specific edges, whereas SCA’s
subspace estimator distributes sensitivity across cross-instance geometry and pays a small cost in
ranking sharpness on such tasks. We return to this trade-off in Appendix A.
The Magnitude/Direction ablation pattern is robust across all twelve tasks. On every panel of
Figure 5, Magnitude and Direction underperform both SCA and the EAP family, with Direction at or
above the Random band on five of the six panels. Combined with the main text, this gives twelve out
of twelve tasks on which the first-moment reductions of the same per-paraphrase gradient input fail
to recover EAP-comparable rankings, while block-wise SVD on that same input does—supporting
the claim that cross-instance subspace geometry, not gradient magnitude or direction, is the operative
signal in SCA.
Two findings worth emphasizing. The cross-task evidence supports two claims that the family-level
similarity matrix alone could not establish.
Pronoun resolution has no dedicated family-level circuit. The Gendered Coreference cluster would
suggest a coreference family with its own machinery. However, across any of our multi-classifier
configurations, the top-10 importance units for the three pronoun tasks contain no member of the
putative family. Instead, the units that drive these tasks are drawn from SVA-specialized heads,
GT-specialized heads, CC-readers, and Universal infrastructure—suggesting that pronoun resolution
in GPT-2 Small is compositional rather than dedicated, assembled from binding, retrieval, and routing
machinery built for other purposes.
The SVA-specialized circuit causally supports pronoun tasks. Direct evidence for the compositional
account comes from the SVA specialized 4-head set: in addition to lifting its three target tasks
(z ∈[4.4, 8.9]), it produces a substantially larger lift on GP (z = +60.4) and GB (z = +25.1).
Ablating the SVA-binding mechanism damages pronoun tasks more than it damages SVA itself. We
interpret this as evidence that the SVA circuit is repurposed for pronoun–antecedent binding, with
the same heads being read out under different downstream projections—a concrete instance of the
sign-agnostic, projection-dependent nature of gradient-based importance discussed in Section 3. This
pattern—a single mechanical primitive recruited by multiple syntactic-semantic tasks—would be
invisible to per-task analyses and is a direct consequence of the cross-task framing.

G.2.1
Gradient Analysis
Before running block discovery and SVD, we validate two upstream assumptions of SCA on the IOI
testbed: (i) that paraphrase-conditioned gradients carry a recoverable instance-level signal above the
noise floor, and (ii) that sign-consistency (SC) filtering yields a well-separated semantic dimension
subset.
Noise-to-signal ratio (NSR).
We compute the NM × NM cosine similarity matrix Cij =
⟨˜gi, ˜gj⟩/(∥˜gi∥∥˜gj∥) over N=100 IOI instances and M=5 paraphrases each, where ˜g denotes the
per-(instance, paraphrase) parameter gradient flattened across all attention and MLP weights. As
shown in Figure 6a, IOI yields NSR = 0.567. Within-instance blocks (along the diagonal) are visibly

(Eq. 4), where the effective rank ρk and the quality of the recovered semantic subspace UBk both

subspace overlap analysis in Section 4.5 where sample-size limitations would otherwise compound

spectral analysis; settings M ≥8 trade retrieval quality for a sample budget that the block-wise SVD
cannot meaningfully exploit (since rank(GBk) ≤N bounds the usable spectral dimension regardless
of M). M=5 thus sits at the Pareto frontier of retrieval accuracy and gradient sample budget.

Computational Resources.
We report the hardware, per-run wall-clock time, and the asymptotic complexity of each stage of the
pipeline so that the resource footprint can be estimated for any choice of model, scope, or dataset
size. Throughout, adopted from main text, let N denote the number of instances, M the number of
paraphrases per instance, D the number of parameters in the analysed scope (e.g. all attention output
projections, or attention plus MLP), K the number of discovered parameter blocks, dk the size of
block k (with P
k dk = D), du the size of a single attention or MLP unit, and ρB ≤N the effective
rank of block B.
• Hardware. A single workstation node with six NVIDIA RTX A6000 GPUs (48 GB VRAM
each), two AMD EPYC 7543 CPUs (64 physical cores in total), and 503 GiB of system
memory. Each run uses a single GPU; the remaining GPUs are used for embarrassingly
parallel sweeps over tasks.
40


• Device split. Only the per-instance forward and backward passes used to extract gradients
run on the GPU; all downstream linear algebra (gradient accumulation, Gram construction,
block discovery, and SVD) runs on the host CPU. This split is dictated by memory rather
than compute: the averaged gradient buffer alone reaches tens of gigabytes, exceeding single-
GPU memory; and for the small instance counts considered here (N ≤100), the Gram
and SVD stages are bandwidth-bound, so host execution incurs no meaningful slowdown
relative to a GPU implementation.
• Headline configurations and wall-clock time. We report two settings, both with N=100,
M=5, sequence length 256, and scope = attention output projections plus MLP weights:
– GPT-2 Small (D ≈8.4 × 107). End-to-end run: 1.5–3 minutes; peak GPU memory
1–2 GB; peak resident host memory ∼50 GB, plus ∼80 GB of memory-mapped scratch
on tmpfs.
– Pythia-160M (D ≈1.3 × 108). End-to-end run: 2.5–5 minutes; peak GPU memory
2–3 GB; peak resident host memory ∼75 GB, plus ∼130 GB of memory-mapped
scratch on tmpfs.
• Gradient collection dominates wall-clock time. Cost is O(NM · Tfb) forward–backward
passes, where Tfb depends on model size and sequence length (∼30–50 ms per pass for
GPT-2 Small at sequence length 256 in bf16 on an A6000). Persistent CPU memory is
dominated by three buffers: a per-instance averaged gradient buffer (4ND bytes, fp32);
a per-instance sign-coherence buffer (ND bytes, int8); and the full normalized gradient
matrix (2NMD bytes, fp16, transparently backed by a memory-mapped file on tmpfs
when it exceeds 4 GB). The dense Gram matrix over paraphrases adds 4(NM)2 bytes. For
the headline configuration (D ≈8.4 × 107), these account for ∼34 GB, ∼8 GB, ∼84 GB
(memory-mapped), and ∼1 MB respectively, all comfortably within the host’s 503 GiB of
RAM.
