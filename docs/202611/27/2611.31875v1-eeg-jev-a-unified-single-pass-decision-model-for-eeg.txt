Abstract.  EEG analysis spans choosing alternatives, judging statements, and rating 
ordered attributes, requiring calibratable probabilities with explicit meaning. We present 
EEG-Jev, a unified single-pass decision model for EEG. Given an EEG window, a 
question and an answer specification, one forward pass returns a typed readout: 
CHOICE gives a candidate distribution, NOUL a proposition probability, and SCORE an 
ordered-level distribution and expectation. One checkpoint is trained jointly and 
evaluated once on held-out splits of 35 public sources. Core raw outputs reach 54.08% 
balanced accuracy on Stieger2021 motor imagery, 70.45% on Sleep-EDF-SC sleep 
staging, 72.11% per window at threshold 0.5 on CHB-MIT seizure detection with 0.825 
AUROC, and 1.700 MAE on 0–10 ds005292 pain ratings. Prior correction and 
temperature scaling lower negative log-likelihood from 0.766 to 0.606 on Sleep-EDF-SC 
and 0.166 to 0.019 on CHB-MIT, while direct readout cuts batch-1 latency from 122.43 
to 63.11 ms (1.94×) against a matched-backbone generative comparator. Interactive 
demonstration and aggregate results: https://neuroimglab.github.io/EEG-Jev/.

1 Introduction
EEG analysis serves many kinds of decisions. Some choose among alternatives, such 
as the sleep stage of an epoch or the movement a participant imagines. Some judge 
whether a statement holds, such as whether a window contains a seizure. Others rate 
an ordered attribute, such as the pain a participant reports. These three forms recur 
across clinical monitoring, brain–computer interfaces and cognitive research. In each 
case the user needs more than a label: a probability whose meaning is stated, that can 
be used as it is, and that can be calibrated.
Today these decisions are mostly served one task at a time. Pretrained EEG 
encoders such as LaBraM, CBraMod and REVE provide representations that transfer 
across datasets1–3, but each downstream task typically still receives its own head and its 
own training run, and what an output means is fixed by the dataset rather than stated. 
EEG–language models such as NeuroLM and UniMind connect an EEG encoder to a 
language model so that one model covers many tasks, and they answer by generating 
text4,5. Generation is flexible, but the answer has to be parsed from the text and every 
answer token costs a further decoding step. A probability can be recovered by scoring 
the tokens of each candidate, but such scores depend on surface form and answer 
priors6,7 and belong to a token sequence rather than to a stated event.
A common form for the decision itself addresses these limits. If every task is stated as 
a question in natural language together with an explicit specification of the admissible 
answers, one shared model can express tasks that differ in form. The specification also 
fixes what each output probability means, so that outputs can be scored and calibrated 
in the same way across tasks. Jev, introduced as a System One model, defines such a 
form: it answers typed questions about an input and returns structured answers with 
probabilities instead of generated text8,9.


4
EEG-Jev builds a unified decision model for EEG on this form. A task is an EEG 
window, a question and an answer specification, and a typed readout returns the result 
directly: a distribution over the candidates (CHOICE), the probability that a proposition 
holds (NOUL), or a distribution over ordered levels with its expectation (SCORE). A frozen 
REVE-L encoder and a trainable connector feed the EEG to Qwen3.5-2B adapted with 
LoRA1,10–12. One set of weights is trained on all three types, and one forward pass 
answers a question without generating text.
The task definition is general, and our validation covers part of it: motor imagery (MI), 
sleep staging, seizure detection and pain rating, drawn from 35 public sources. One 
checkpoint is evaluated once on held-out test data for task performance and for the 
quality of its probabilities before and after simple post-processing, and its inference 
latency is measured on development windows against an autoregressive comparator 
built on the same backbone. Our contributions are:
1. A typed decision form for EEG in one model. Following the public Jev interface, 
EEG-Jev states choosing, judging and rating as one input form (EEG window, 
question, answer specification) with three typed readouts. One set of weights is 
trained on all three types and answers a question in one forward pass, with no text 
to generate or parse. In this study each application uses one readout type.
2. Probabilities that can be scored and corrected. Unlike EEG–language models 
that generate text, every output is the probability of a stated event, so proper 
scoring rules apply directly. A prior correction for the class-balanced training draws 
and one temperature per application, both fixed before the test evaluation, lower 
the negative log-likelihood on the sleep and seizure core sources without changing 
the model; decision thresholds then have to be set for the intended use.
3. A single test evaluation across 35 sources, with latency. One checkpoint, used 
without checkpoint selection, is scored once on held-out data from 35 public 


5
sources in four applications and compared with per-source baselines on the same 
encoder. Across the 35 sources, point estimates exceed the frozen-feature 
baseline on 26 sources and the fine-tuned baseline on 19; on the four core 
sources, the shared model matches the fine-tuned baseline on sleep staging and 
both baselines on pain rating, while trailing on four-class motor imagery and 
seizure AUROC. On a four-source development timing panel, direct readout 
answers a single request about 1.94 times as fast as an autoregressive comparator 
on the same backbone (4–6% faster at batch 32).
2 Related work
EEG encoders and EEG–language models.  Pretrained EEG encoders include BIOT, 
LaBraM, EEGPT, CBraMod and REVE1–3,13,14. REVE encodes each signal patch 
together with the position of its electrode and its time, so one encoder accepts different 
electrode layouts and window lengths. We use its publicly released large checkpoint, 
REVE-L10, frozen, for this property and for its public weights, not as the strongest 
encoder for every task: in NeuralBench-EEG the REVE entry, the base model fine-
tuned end to end, is the best listed model on the core motor-imagery task, fourth on 
sleep staging and twelfth on seizure detection15,16. Among EEG–language models, 
NeuroLM and UniMind are instruction-tuned on several datasets and produce the 
answer as generated text4,5; the UniMind authors note that the outputs carry no 
probability scores. Other systems generate explanations or clinical notes17,18 or align 
EEG representations with label-text embeddings or prototypes19–21. The Choice readout 
of EEG-Jev is close in form to these alignment methods, since it matches a projected 
state against text-embedding keys of the candidates. EEG-Jev adds proposition 
probabilities and rating distributions under the same task definition, trains one set of 
weights for the three types and evaluates all outputs as probabilities.


6
Typed decisions and probability quality.  The three answer types and their output 
contracts follow the public interface of Jev8,9. The architecture and training procedure of 
Jev have not been published, so the model, the readouts and the training described 
here are our own; EEG-Jev is an independent research implementation and is not 
affiliated with TypeSafe. TypeSafe states that Jev is trained with a method it calls 
reinforcement learning for calibrated decisions (RLCD)8,9, for which an independent 
open implementation has been proposed22; EEG-Jev uses supervised objectives only. 
Because candidate scores of language models depend on surface form and answer 
priors6,7, we evaluate with proper scoring rules23–25 and apply two standard corrections 
outside the model, prior-shift correction26 (prior correction below) and temperature 
scaling27.

3.3 Shared training and typed supervision
Question sampling and candidate reordering.  Each update uses 32 questions, and 
each question pairs one training window with one phrasing and the answer specification 
(Figure 2). Every source has a question family with five training phrasings, and one of 
them is drawn with equal probability for each question. For CHOICE, the candidates are 
permuted for each question and the target index is remapped to the new position of the 
annotated candidate. Target positions are balanced within each source, subject and 
class, so a position carries no information about the answer, and each key moves with 
the text of its candidate. NOUL and SCORE have nothing to reorder.

Typed supervision.  A question is supervised only by the objective of its own type. 
CHOICE uses the cross-entropy at the position of the annotated candidate, and NOUL the 
binary cross-entropy of p( yes). SCORE compares the level distribution with a soft target 
r centred on the reported rating and adds 0.2 CRPS / (vJ −v0), where CRPS is the 
continuous ranked probability score. Up to update 3,600 the target r splits its mass 
between the two levels that bracket the rating (cross-entropy); afterwards it is a 
discretized Gaussian with a standard deviation of one level ( KL(r  ||  p)). The 32 per-
question losses are summed and divided by 32, so every question has the same weight 
whatever its type and number of candidates, and one AdamW step on this mean 
updates all trainable parameters.


11
Four stages.  One run of 13,400 updates (seed 8) has four stages (Appendix B). 
Warm-up (updates 1 to 600) trains only the connector, the markers and the readouts, 
with LoRA frozen, so that the EEG embeddings and the readouts first adapt to the 
unchanged language model. Mixed training (601 to 3,600) adds the LoRA adapters and 
draws the four applications in fixed shares. Hard-task strengthening (3,601 to 11,000) 
follows a sampling plan that was regenerated once, at update 3,600, after development 
panels had shown motor imagery still at chance level. The new plan sets the number of 
questions per source from the amount of its training data, which raises the share of 
motor imagery from 0.30 to 0.46 of the draws; it gives more draws to the sleep sources 
and stages on which the update-3,600 checkpoint was weak on a fixed development 
subset, and directs part of the seizure draws to training windows that this checkpoint 
scored poorly. Development data influenced only these sampling statistics; no 
development window entered a gradient. The final stage (11,001 to 13,400) lowers the 
peak learning rate tenfold and returns to shares close to those of the first two stages. 
The run was planned with 8,000 updates and was extended to 13,400 when the plan 
was regenerated. Training ended at this fixed budget: no stopping criterion was applied, 
the training loss was still decreasing slowly in the final stage, and the last checkpoint is 
used without checkpoint selection.

4 Experimental setup
The experiments ask three questions: whether one shared model reaches useful task 
performance across applications, whether its probabilities have the stated meaning and 
improve with simple post-processing, and what direct readout saves at inference time.
4.1 Data and evaluation scope
We train and evaluate on 35 public sources in four applications (Table 1; per source 
in Appendix A). Motor imagery (17 sources) is posed as CHOICE among two to four cued 
conditions, including rest in some sources, and sleep staging (7 sources) as CHOICE 
among five stages for a 30-s epoch. Each epoch is staged on its own: the model does 
not see the neighbouring epochs, which manual scoring rules and sequence-based 
automatic stagers use. Seizure detection (2 sources) is posed as NOUL with the 
proposition “An annotated seizure occurs at some time within this window.” for a 5-s 
window. Pain rating (9 sources) is posed as SCORE on the 11 levels of a 0–10 scale of 


13
self-reported pain after a laser stimulus. The task is to predict this single-trial rating for 
subjects held out from training in that source; it is not an assessment of clinical pain.
Twenty-one sources follow the locked NeuralBench protocols with their windows, 
labels and partitions15,29: all motor-imagery sources, three sleep sources and CHB-MIT. 
The other 14, four sleep sources, Siena and the nine pain sources, use their own 
windows, labels and subject-level partitions. All sources share the signal recipe that 
NeuralBench uses for REVE (band-pass 0.5–99.5 Hz, 200 Hz, standardization per 
channel, clipping at ±15). As in the NeuralBench pipeline, the zero-phase band-pass 
filter and the per-channel standardization are computed over the whole recording, so 
the results describe offline record-level preprocessing, not a model that sees only the 
current window. Every source has a training, a development (validation) and a test 
partition. Partitions are subject-disjoint except in five motor-imagery sources whose 
protocols split sessions or trials of the same subjects.

4.2 Comparators
B1 and B2 are per-source baselines on the same REVE-L encoder, trained by us and 
scored on the same test windows as EEG-Jev. B1 is a readout on frozen features: a 
small MLP on each REVE-L token, mean pooling and a linear head (0.38 million 
trainable parameters). B2 fine-tunes the last four of the 22 encoder blocks together with 
the same head (71.2 million trainable parameters). Each baseline is trained and 
selected separately for every source with seeds 7 and 8, and we report the mean of the 
two seeds. NeuralBench best is, for each of the three NeuralBench core tasks, the best 
mean test result among the entries of the public NeuralBench-EEG results15,16. These 
are externally reported results of models trained or fine-tuned end to end for each task. 
Table 2 names the model behind each value and marks in bold the best of the three 
models of this study only.
4.3 Metrics
The main text shows one metric per application, the NeuralBench metric where a task 
exists: balanced accuracy (BA) for motor imagery, sleep staging and seizure detection. 
Pain rating has no NeuralBench task, and we report the mean absolute error (MAE) of ŷ 
in rating units. Seizure BA is computed per window from the decision p( yes)≥0.5 on the 
raw output at the natural prevalence. The protocol named the area under the ROC 


15
curve (AUROC) as the primary seizure metric. After the evaluation, with the AUROC 
results known, we made BA at 0.5 the displayed metric so that all three NeuralBench 
applications use the NeuralBench metric; the AUROC is reported alongside. All other 
computed metrics are in the released result files (Appendix E).
Task results use the raw outputs. Probability quality is measured by the negative log-
likelihood (NLL) and the expected calibration error (ECE, ten equal-mass bins) for 
CHOICE and NOUL, and for SCORE by the CRPS divided by the scale range and by the 
coverage of the central 80% interval. Intervals are 95% intervals of paired differences 
from 2,000 bootstrap resamples of the test subjects (patients for seizure) of a source. 
They describe the sampling of the test population only; variation between training seeds 
is a separate matter, which one EEG-Jev run and two baseline seeds cannot quantify. 
An interval that includes zero does not establish a difference between the models; no 
equivalence margin was set.
4.4 Efficiency experiment
To measure what direct readout saves (Figure 3), we compare EEG-Jev with a 
generative model on the same backbone that answers the same questions with short 
text. This comparator is initialized from the EEG-Jev checkpoint, and its LoRA adapters 
are then trained for 50 updates of 16 questions to produce the answer tokens followed 
by the end-of-sequence token, while REVE-L, the connector and the EEG markers stay 
unchanged. Its input row contains the same EEG embeddings, question and answer 
specification; the system prompt is replaced by an instruction to give one short answer, 
a sentence stating the answer format is appended to the question, and the readout 
marker is omitted. It is thus a matched-backbone autoregressive (AR) comparator 
adapted to short answers. It does not share the weights of EEG-Jev, and its task quality 
differs.


16
Both paths are timed from the preprocessed EEG window and its electrode positions 
in host memory, through the transfer to the GPU, the REVE-L encoding, the connector 
and the language model. This preprocessing needs the full recording (Section 4.1) and 
is not included in the timing. The EEG-Jev path ends when the typed probabilities and 
the decision are on the CPU. The AR path decodes greedily with cached states until the 
model emits the end-of-sequence token (at most 32 tokens) and ends when the 
complete text has been parsed into a valid answer on the CPU. The panel has 32 
development windows from each of four sources, one per application, chosen to 
balance classes and subjects: Lee2019 (motor imagery; not the core source), Sleep-
EDF-SC, CHB-MIT and ds005292. The two paths are timed alternately on the same 
windows on one GPU with 32-bit arithmetic; hardware, repetitions, synchronization and 
the rule for valid answers are given in Appendix D.
The request latency is the time of one request at batch 1; we report its mean over all 
requests, weighting the four sources equally. The amortized latency per window at 
batch 4 is the total time of a batch divided by 4, averaged in the same way; it is not the 
response time of a single request.

5.2 Probability quality and post-processing
Table 3 compares the raw outputs of EEG-Jev with the frozen post-processing of 
Section 3.4. Figure 4d shows the NLL at each stage. Post-processing reduces 
probabilistic prediction error and calibration error on sleep staging and seizure 
detection. On Sleep-EDF-SC, NLL decreases from 0.766 to 0.606 and ECE from 0.088 
to 0.044. On CHB-MIT, NLL decreases from 0.166 to 0.019 and ECE from 0.118 to 
0.001. These results show that the typed outputs can be recalibrated with standard 


19
tools. Most of the gain comes from undoing the class-balanced training draws, a 
correction that applies to any classifier trained on resampled classes. For reference, the 
raw outputs of B1 and B2 (means of two seeds) have an NLL of 0.778 and 0.794 on 
Sleep-EDF-SC and of 0.015 and 0.014 on CHB-MIT, where a constant prediction at the 
test prevalence gives 0.025. On CHB-MIT the post-processed EEG-Jev output therefore 
improves on the constant reference but remains above both baselines, in line with its 
lower AUROC. On Stieger2021, the raw ECE of EEG-Jev (0.028) is lower than that of 
B1 (0.133) and B2 (0.183), while raw NLL is 1.093 against 1.078 and 1.130.
The stepwise results attribute most of the NLL improvement to prior correction. 
Seizure windows constitute half of the CHB-MIT training draws and 0.38% of its test 
windows. Correcting the sampling prior using training statistics brings NLL to 0.614 on 
Sleep-EDF-SC and 0.021 on CHB-MIT. Temperature scaling further improves 
probability quality; on Sleep-EDF-SC, ECE decreases from 0.057 after prior correction 
to 0.044. On Stieger2021, NLL decreases from 1.093 to 1.082. On ds005292, range-
normalized CRPS decreases from 0.121 to 0.120 and MAE from 1.700 to 1.687.
Decision rules should account for the calibrated probability scale and the evaluation 
objective. On Sleep-EDF-SC, accuracy increases from 69.42% to 75.57%, while class-
balanced accuracy decreases from 70.45% to 66.79%, reflecting the trade-off between 
frequency-weighted and class-balanced evaluation. On CHB-MIT, post-processing 
preserves window rankings, with AUROC at 0.825. At a threshold of 0.5, positive 
predictions decrease from 6,580 to 68 of 121,650 windows, sensitivity decreases from 
49.5% to 13.8%, specificity reaches 99.997%, and BA decreases from 72.11% to 
56.88%. Binary decisions based on calibrated probabilities therefore require a threshold 
chosen for a target sensitivity or false-positive cost on development data. On ds005292, 
the temperature moves the coverage of the central 80% interval further from its nominal 
value, from 82.7% to 85.6%. Probability scores, point predictions and interval coverage 
together characterize the post-processed outputs.

5.3 Inference efficiency
Figure 3 illustrates how direct typed readout produces a decision after one forward 
pass, while the generative path performs prefill followed by incremental decoding. With 
the same backbone architecture and optimized execution, EEG-Jev has a mean request 
latency of 63.11 ms at batch 1, compared with 122.43 ms for the adapted AR 
comparator, a latency ratio of 1.94. EEG-Jev is faster on all four timing sources. At 
batch 4, its amortized processing time is 28.68 ms per window, compared with 44.01 ms 
for AR, a ratio of 1.53. Figure 4e shows all batch sizes. In absolute terms, direct readout 
saves 59.3 ms per request at batch 1. These measurements show a latency benefit 
over cached autoregressive decoding for single requests and small batches, even when 
the generative answers average only 2.0–3.0 tokens. The comparison does not include 
a single-pass readout of answer-token logits or the per-source heads B1 and B2, which 
use no language model.

6 Discussion
What a unified decision model provides.  EEG-Jev brings selection, binary judgment 
and ordered rating into one shared model. Questions and answer specifications identify 
the requested decision, and typed readouts return probabilities with explicit meanings. 
The 35-source evaluation shows that this common interface can support four EEG 
applications with one set of weights. In point estimates the model exceeds the frozen-
feature baseline on 26 sources and the fine-tuned baseline on 19, and it remains below 


22
both on the core motor-imagery source and on seizure AUROC. Calibration and direct 
inference extend its value beyond point predictions to probability-based decision 
systems.
Improving performance across tasks.  The heterogeneous source sizes, class 
frequencies and subject distributions make training-budget allocation an important 
design choice. Sharing capacity across 35 sources may also introduce unequal learning 
progress and task interference. These are plausible contributors to the observed 
differences and warrant controlled experiments. We plan to study source-aware 
sampling, adaptive exposure based on training and validation behavior, and 
architectural changes that improve feature alignment and cross-subject generalization. 
The present results motivate these directions, while causal attribution requires matched 
ablations.
Calibratable probability outputs.  Explicit probability semantics allow training-
sampling priors to be corrected and temperature scaling to be applied consistently. The 
reductions in sleep and seizure NLL demonstrate this practical benefit. Calibration and 
decision thresholds should be assessed jointly for the intended use, since prior 
correction can improve probability quality while changing balanced accuracy and 
sensitivity at a fixed threshold.
Efficiency and longer-form generation. 
 The matched-backbone comparison 
demonstrates an implementation-level latency advantage for direct typed readout at 
batch sizes 1 and 4. The comparator already uses short answers averaging two to three 
tokens. Generative systems that produce longer explanations or explicit reasoning 
chains require additional sequential decoding steps, which creates an opportunity for 
greater savings when the requested output is a typed decision. Larger backbones may 
add further computation. Quantifying these effects calls for comparisons with task-


23
trained generative EEG models and reasoning-oriented systems under matched 
hardware, output requirements and task-quality evaluation.
Scope of the evidence.  The results come from one training run with one seed, and the 
intervals describe subject sampling only. No ablation separates the contributions of the 
language model, of the question text or of joint training. B1 reaches 61.95% on 
Stieger2021 from the same frozen features with 0.38 million trainable parameters, so 
the present results do not show that the language model improves decoding; what it 
provides here is one interface for three answer types. Each application uses a single 
answer type, so answer type and application are confounded. Test questions use a 
phrasing and a candidate order that also occurred in training, so robustness to new 
wording and transfer to new questions are untested. All windows were preprocessed 
with statistics of their whole recording (Section 4.1); whether performance holds when 
filtering and standardization use the current window alone, as in online use on a new 
subject, is untested. Five motor-imagery sources share subjects between training and 
test by protocol, and the nine pain sources come from one research group and share 
some participants. The seizure results rest on five and four test patients and are pooled 
window-level metrics on 5-s windows: event-level sensitivity, false alarms per 24 hours 
and detection delay were not evaluated. With five patients the bootstrap intervals are 
coarse and should be read as descriptive. Sleep staging uses one epoch at a time. 
Development data shaped the sampling plan from update 3,600 on, when the training 
budget was also extended, and the displayed seizure metric was chosen after the 
evaluation (Section 4.3). At least seven of our sources, none of them a NeuralBench 
core source, are listed by NeuralBench among the pretraining data of REVE29; whether 
REVE-L saw them was not checked, and any benefit would reach all three models alike.

Future directions.  The first direction is scale: more datasets and applications, with a 
better architecture and allocation of training across sources. The second is more flexible 
language-conditioned decisions, including questions, candidate sets and scales that 
were not seen in training. The third is probability quality at training time, in particular 
reinforcement learning for calibrated decisions, the training method that TypeSafe 
names for Jev8,22. The fourth is deployment: distilling the typed decisions into small 
models that run on the device.
7 Conclusion
EEG-Jev unifies EEG selection, binary judgment and ordered rating in one shared 
decision model. Its typed readouts produce probabilities with explicit meanings in a 
single forward pass and support standard post-hoc calibration. Across 35 sources, it 
exceeds B1 on 26 and B2 on 19 in point estimates under the displayed application 
metrics; among the 26 sources with paired intervals, the interval excludes zero in its 
favour on 6 and against it on 2 versus B1, and on 2 and 6 versus B2. The clearest 
remaining gaps are on cross-subject motor imagery and seizure ranking. Sleep and 
seizure probabilities benefit from prior correction and temperature scaling. On the four-
source timing panel, direct readout achieves a mean single-request latency of 63.11 ms 
and a batch-4 amortized processing time of 28.68 ms per window, with latency ratios of 


26
1.94 and 1.53 relative to the matched-backbone generative comparator. Together, 
these findings provide a practical basis for efficient, calibratable EEG decisions and 
motivate further development of training allocation, generalization and model 
architecture.

B Training and configuration
Model.  The released REVE-L10 has 22 blocks of width 1216 and cuts each channel into 
patches of 200 samples with a stride of 180, which gives 3, 4, 5 and 33 patches for 
windows of 3, 4, 5 and 30 s. Qwen3.5-2B has 24 layers in six groups of three Gated 
DeltaNet layers and one attention layer. LoRA (rank 16, α =32) is applied to all 186 
linear maps of these layers. The trainable parameters are 6,690,817 in the connector, 
6,144 in the three markers, 16,819,200 in LoRA and 4,218,892 in the readouts 


33
(4,194,304 of them in the CHOICE projection W), 27,735,053 in total; an inherited linear 
layer of 22,539 parameters that is never called is not counted.
Schedule.  Table A2 gives the four stages. Training ended at the fixed budget of the 
regenerated plan, without a stopping criterion; the training loss was still decreasing 
slowly in the final stage. The optimizer is AdamW (β =(0.9,0.999), ϵ =10
−8, weight decay 
0.01) with gradient clipping at norm 1.0 and 32-bit arithmetic. Each update averages the 
losses of 32 questions, 428,800 training questions in total. The run took 10.4 hours on 
one NVIDIA RTX PRO 6000 Blackwell GPU.

Sampling.  Within a stage, a deterministic scheduler serves the source that is furthest 
below its share. In the first two stages the motor-imagery and sleep sources are 
weighted by the square root of their number of training subjects, classes are drawn 
equally, seizure draws are balanced between positive and negative windows, and pain 
draws cycle through all rated events. The plan regenerated at update 3,600 sets the 
question count of each source for the whole run from the amount of its training data (for 


34
Lee2019 and Cho2017, from their exposure in an earlier run) and subtracts what was 
already drawn. For sleep, a fixed development subset of 16,717 windows, scored with 
the update-3,600 checkpoint, sets source multipliers between 0.81 and 1.19 from the 
BA of each source and class shares between 0.12 and 0.35 from the per-class F1, 
highest for stage N1. For seizure, 30% of the positive draws come from the fifth of 
positive training windows with the lowest p( yes) under that checkpoint and 50% of the 
negative draws from the tenth of scored negative training windows with the highest. The 
ninth pain source, ds005473, enters at update 3,601, where the SCORE target also 
changes (Section 3.3). Per-source question counts will be released with the codebase.
Baselines.  B1 applies an MLP (1216→256→256) to each REVE-L token, followed by 
mean pooling, layer normalization and a linear head. B2 runs REVE-L on the 
preprocessed window and fine-tunes its last four blocks with the same head. For each 
source a fifth of the training subjects, at least two, is held out for model selection, and 
CHOICE losses are weighted by inverse class frequency. The baselines are references: 
their learning rate was selected from two values, and nothing else was tuned. They are 
not fully uniform. Seven B1 sources (Lee2019, Cho2017 and five pain sources) reuse 
readouts trained earlier with the same architecture, the seed-7 B2 runs come from three 
code paths with the same split, loss and selection rule, and ten seed-8 B2 runs ended at 
the limit of ten epochs.
C Question examples
Each source belongs to one of seven question families, and each family has five 
training phrasings. Evaluation uses the first of them:
• Sleep staging (CHOICE): “Which sleep stage is assigned to this 30-second EEG 
epoch under the dataset annotation protocol?”


35
• Motor imagery (CHOICE): “Which hand movement did the participant imagine during 
this cued motor-imagery trial?”, with candidates such as “Candidate 1: Left-hand 
movement. Candidate 2: Right-hand movement.”
• Seizure detection (NOUL): “Does any annotated seizure interval overlap this 5-
second EEG window with positive duration?”, with “Proposition: An annotated 
seizure occurs at some time within this window.”
• Pain rating (SCORE): “What pain intensity did the participant report for this laser-
stimulation trial on the 0-to-10 rating scale?”, with one line per level, “Level k: 
Reported pain intensity: k out of 10.”
The AR comparator of the efficiency experiment receives the same question and 
answer specification. Its system prompt is replaced by “Answer the question about the 
EEG with one short answer only. Do not explain.”, and a sentence stating the answer 
format is appended to the question, for example “Answer only yes or no.” All phrasings 
will be released with the codebase.

Timing procedure.  Both paths run on one NVIDIA RTX PRO 6000 Blackwell GPU with 
PyTorch 2.8.0, 32-bit floating-point weights and arithmetic, and one CPU thread; the 
optimized configuration adds fused kernels for the Gated DeltaNet layers of the 
language model, set to IEEE arithmetic. The two paths are timed alternately on the 
same windows after a warm-up call, at batch sizes from 1 to 32 with batches formed 
within a source, and the GPU is synchronized before the start and at the end of every 


37
timed call. Every window is timed three times at batch sizes up to 8 and thirteen times at 
16 and 32. An AR answer is valid only if the complete text is a listed candidate identifier 
or name, “yes” or “no”, or a number from 0 to 10.
Inputs and answers.  The windows have 62, 2, 24 and 63 channels (Lee2019, Sleep-
EDF-SC, CHB-MIT, ds005292). The input row of EEG-Jev has 345, 196, 213 and 464 
positions and the prefill of the AR comparator 333, 184, 197 and 454; the AR row is 
shorter mainly because its instruction is shorter than the system prompt of EEG-Jev. 
The AR answers have a mean length of 3.00, 2.72, 2.00 and 2.03 tokens including the 
end-of-sequence token. In a batch, rows that have finished are carried along until the 
last row ends, so the longest answer determines the time of the batch.
Adaptation of the comparator.  Without adaptation the EEG-Jev checkpoint does not 
produce usable text: on a diagnostic panel of 32 development windows, disjoint from the 
timing panel, only 2 answers were valid and 24 reached the 32-token limit. After the 50 
LoRA updates (800 training questions, 200 per application; AdamW, learning rate 
2×10
−5) all 32 were valid and ended with the end-of-sequence token. The number of 
updates was chosen on this small panel.
