## 摘要
脑电图（EEG）解码是通往用于通信、康复、认知评估和神经监测的脑机接口的核心途径。近期脑电图基础模型大幅推进了可复用信号表示，但其下游应用通常仍需要任务特定的解码器、基于梯度的适配以及验证驱动的模型选择。我们研究了一种基于上下文学习的互补基础模型范式：带标签的EEG记录将解码任务定义为上下文，新记录在无需更新模型参数的情况下被预测。我们首先将原始EEG特征与预训练的通用上下文预测器配对。这种直接形式提供了一个有前景的起点，但其性能仍然有限且不稳定，并且无法在各类EEG范式中可靠泛化。我们发现，通过提高有效信噪比并揭示时间和空间结构，适当的上下文构建可以解决这些局限。基于这一见解，我们提出了一个通用框架，该框架将EEG特定的上下文构建与冻结的上下文预测器以及基于度量的上下文适配机制相结合，在不依赖验证数据的情况下为每个下游任务匹配合适的上下文表示。在涵盖七种EEG解码范式的十个数据集上，我们的方法在十一个专用且经过微调的EEG基线中取得了最高的平均平衡准确率（BAcc），且无需任务特定的参数更新或基于验证的模型选择。该框架为实现免调优的EEG基础模型提供了一条实用路径，其中适配通过上下文而非参数更新来表达。

## Abstract
Electroencephalography (EEG) decoding is a central route toward brain-computer interfaces for communication, rehabilitation, cognitive assessment, and neurological monitoring. Recent EEG foundation models have substantially advanced reusable signal representations, but their downstream use still typically requires a task-specific decoder, gradient-based adaptation, and validation-driven model selection. We investigate a complementary foundation-model paradigm based on in-context learning: labeled EEG recordings define the decoding task as context, and new recordings are predicted without updating model parameters. We first pair raw EEG features with a pretrained general-purpose in-context predictor. This direct formulation provides a promising starting point, but its performance remains limited and unstable and does not generalize reliably across EEG paradigms. We find that suitable context construction can address these limitations by improving the effective signal-to-noise ratio and exposing temporal and spatial structure. Building on this insight, we introduce a general framework that combines EEG-specific context construction with a frozen in-context predictor and a metric-based context adaptation mechanism, which matches each downstream task to an appropriate context representation without relying on validation data. Across ten datasets spanning seven EEG decoding paradigms, our method achieves the highest mean BAcc among eleven specialized and fine-tuned EEG baselines, without task-specific parameter updates or validation-based model selection. This framework provides a practical path toward tuning-free EEG foundation models in which adaptation is expressed through context rather than parameter updates.

## 2. 方法论

### 2.1 问题形式化

- 预处理后的 EEG 数据集记为 $D=\{(e_i,y_i)\}_{i=1}^N$，其中 $e_i\in\mathbb{R}^{C\times T}$ 为多通道时间序列，$y_i\in[K]$ 为目标标签。
- 对每个下游任务，划分支持集 $D_{\text{support}}=\{(e_i,y_i)\}_{i=1}^{N_s}$ 和查询集 $D_{\text{query}}=\{e_q\}_{q=1}^{N_q}$。查询标签仅用于最终评估。
- 目标是学习支持集条件预测器 $\hat y_q = F(e_q\mid D_{\text{support}})$，且在目标数据集上不更新任何模型参数，也不使用验证性能或查询信息进行选择。

### 2.2 上下文构造算子

上下文表示为 $\tau=\tau_{\text{infer}}\circ\tau_{\text{feat}}\circ\tau_{\text{info}}$，按“信息暴露 → 特征转换 → 推理时构建”顺序执行。

- **特征类型算子** $\tau_{\text{feat}}$：
  - **原始波形** $\tau_{\text{RAW}}$：直接向量化，$\tau_{\text{RAW}}(e)=\mathrm{vec}(e)\in\mathbb{R}^{CT}$。
  - **逐试次归一化波形** $\tau_{\text{NORM}}$：对每个试次所有通道-时间坐标做 LayerNorm，抑制试次间偏移和尺度变化。
  - **频谱** $\tau_{\text{SPEC}}$：将时间轴分为 $S$ 个无重叠窗口，对每个窗口计算幅度 rFFT，并拼接所有窗口系数，显式暴露节律成分。
  - **协方差/黎曼** $\tau_{\text{RIEM}}$：对每个试次估计 OAS 收缩协方差，并在支持集拟合的黎曼参考点处映射到切空间，暴露跨通道二阶几何结构。

- **时间/空间信息算子** $\tau_{\text{info}}$：
  - **区域池化** $\tau_{\text{REG}}$：对已审计的解剖通道组施加固定池化统计（均值、最小、最大、标准差、方差、RMS），生成伪通道，再送入黎曼特征算子，暴露粗粒度区域组织。
  - **局部时间视图** $\tau_{\text{MV}}$：将试次分割为 $S$ 个时间窗口，每个窗口作为一个上下文实例；支持标签被广播，查询概率在多视图上取平均。

- **推理时策略** $\tau_{\text{infer}}$：
  - **反平衡支持集** $\tau_{\text{CB}}$：对每个类等量欠采样，保证类别均衡，并统一按“完整试次”和“有效行数预算”执行。
  - **一对多预测** $\tau_{\text{OVR}}$：对 $K$ 类任务构造 $K$ 个二分类上下文，分别预测正类概率后归一化为多分类分布，简化原生标签空间但增加 $K$ 次前向。

### 2.3 基于度量的支持集上下文选择

- 仅使用标注支持集，不评估候选上下文性能，也不使用验证集或查询信息。
- 计算四组低维描述符：**频带**（$\delta,\theta,\alpha,\beta,\gamma$ 相对功率）、**空间**（平均绝对非对角通道相关、归一化相关有效秩）、**时间**（滞后一自相关、归一化线长、非平稳性）、**幅值**（RMS、峰度、峰值因子）。
- 对每组描述符 $g$，计算类间离散度 $B_g$ 和类内离散度 $W_g$，并构造分离统计量：
  $$r_g=\frac{B_g/n}{\max\{W_g/(n-K),\,10^{-8}\}},\qquad s_g=\log\bigl(1+\min\{r_g,10^{6}\}\bigr)$$
  其中 $n$ 为诊断子集试次数，$K$ 为类别数。$s_g$ 越大表示该描述符组在支持集上类分离越强。
- 选择 $g^\star=\arg\max_g s_g$，然后按确定性规则映射到算子组合：
  - 频带主导且时间得分小于等于幅值得分 → $\tau_{\text{NORM}}$；频带主导且时间得分大于幅值得分 → $\tau_{\text{SPEC}}$；空间或幅值主导 → $\tau_{\text{RIEM}}$；时间主导 → $\tau_{\text{RAW}}$。
  - 幅值主导加入 $\tau_{\text{REG}}$，时间主导加入 $\tau_{\text{MV}}$。
  - 多分类且非频带主导
