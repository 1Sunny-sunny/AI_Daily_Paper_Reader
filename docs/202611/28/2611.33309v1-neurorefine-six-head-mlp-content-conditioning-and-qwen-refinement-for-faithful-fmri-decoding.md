## 摘要
从fMRI重建所视图像已借助扩散模型取得进展，但当前最先进的Brain-IT流程仍存在一个有损瓶颈：其低层分支能较好勾勒图形，但随后的扩散模型经常错误地涂绘颜色、物体身份和布局。我们向后退一步，直接将精化器条件化于fMRI衍生的低层图像，使用六个单隐层MLP头（场景、主体类别、数量、颜色、物体、布局）预测内容提示，以引导冻结的Qwen-Image-Edit-2511模型。在930个共享NSD概念上，使用Brain-IT自身度量代码在同一真值上评分，NeuroRefine达到CLIP图像余弦0.755，而Brain-IT enhanced为0.735，并产生明显更清晰的图像，同时饱和的二选一识别保持不变。低层图像提供了显式的空间先验而非无损布局：精化以部分布局一致性（0.541对0.638）换取语义保真度和纹理。随后我们表明标准面板是多因素的：高PixCorr可以与完全不同的内容共存，因此我们分别读取低层和语义因素，并量化它们不一致之处。最后，我们追踪跨被试提示头的皮层来源，并报告其因果损伤概况和fMRI噪声上限。方向误差留待未来工作。

## Abstract
Reconstructing seen images from fMRI has advanced through diffusion models, but the current state-of-the-art Brain-IT pipeline still has a lossy bottleneck: its low-level branch outlines the figure well, yet the diffusion model that follows frequently mispaints colour, object identity and layout. We move one step backward and condition the refiner directly on the fMRI-derived low-level image, using six one-hidden-layer MLP heads (scene, main-subject category, count, colour, object, layout) to predict the content prompt that guides a frozen Qwen-Image-Edit-2511 model. On the 930 shared NSD concepts, scored with Brain-IT's own metric code on the same ground truth, NeuroRefine reaches a CLIP image cosine of 0.755 against 0.735 for Brain-IT enhanced and produces markedly sharper images, while the saturated 2-way identification is unchanged. The low-level image supplies an explicit spatial prior rather than a lossless layout: refinement trades some layout agreement (0.541 against 0.638) for semantic fidelity and texture. We then show that the standard panel is multi-factor: a high PixCorr can coexist with completely different content, so we read the low-level and semantic factors separately and quantify where they disagree. Finally, we trace the cortical sources of the prompt heads across subjects and report their causal lesion profile and the fMRI noise ceiling. Direction errors are left to future work.

- **核心问题**：传统的“caption 瓶颈”——现代流程通常先从 fMRI 预测语义描述（caption），再用文生图模型生成图像，但 caption 会丢弃颜色、精确物体身份和空间布局等信息，导致生成模型无法恢复这些内容。
- **整体含义**：本文提出 NeuroRefine，在 Brain-IT 流程之上增加一个精化阶段，直接将精化器条件化于 fMRI 衍生的低层图像，并用六个单隐层 MLP 头预测结构化内容提示，引导冻结的 Qwen-Image-Edit 模型进行精化，从而以轻度布局一致性损失换取更高的语义保真度和图像清晰度。

## 2. 方法论

### 2.1 总体框架
NeuroRefine 采用两阶段流程：
- **第一阶段**：低层分支产生低层图像（提供粗略空间先验）和紧凑内容描述。
- **第二阶段**：冻结的图像编辑模型同时条件化于低层图像和内容提示，进行精化。

### 2.2 低层分支
- **输入**：39,548 个 fsaverage 表面顶点（左半球 19,004，右半球 20,544）的 z-scored beta 值，与 Brain-IT 使用相同预处理。
- **VGG 特征预测与反演**：遵循 Brain-IT 的做法，用 InfoNCE 损失训练读出模型，预测多层 VGG 特征；推理时通过 Deep Image Prior 将预测特征反演为低层图像。该低层图像携带粗略布局但缺乏可靠语义，作为精化器的输入。
- 该分支保持不变，用于将改进归因于精化器而非低层模型。

### 2.3 六头 MLP 内容预测器
- **结构**：六个独立的单隐层 MLP（1024 个隐藏单元，GELU 激活，dropout 0.3）从同一体素向量预测结构化字段：场景（scene）、主体类别（main-subject category）、数量（count）、颜色（colour）、物体（object）、布局（layout）。
- **训练策略**：
  - 场景、主体类别、数量为单标签分类，使用 categorical cross-entropy（softmax）。
  - 颜色、物体、布局为多标签字段，使用独立 binary cross-entropy（sigmoid）。
- **标签空间**：场景 38 类；主体类别 20 类；数量 3 类（1 / 2 / ≥3）；颜色 12 个二值标签；物体 150 个二值标签；布局 8 个二值标签（left, right, front, behind 等）。
- **提示构建**：将预测字段组装为短内容提示，包含场景、主体、数量、主要颜色和布局信息。
- **可解释性**：由于 heads 是确定性函数，其归因分析反映训练权重而非采样噪声。

### 2.4 图像条件编辑精化器
- **模型**：冻结的 Qwen-Image-Edit-2511，分辨率 1024×1024，20 步去噪，guidance 4.0。
- **指令格式**：instruction-first，例如“follow the low-level layout and render the content below”，后接 head 输出。
- **设计动机**：低层图像提供显式空间先验，避免 caption 无法携带位置和精确颜色的问题；编辑器不被要求无损复制先验，而是在输入布局基础上恢复纹理和语义。

### 2.5 评估指标
- 直接调用 Brain-IT 发布的 `compute_metrics`，确保可比性。
- **标准面板**：PixCorr、SSIM、AlexNet(2)、AlexNet(5)、Inception、CLIP 2-way、EffNet-B、SwAV 距离。
- **额外指标**：CLIP image cosine（不饱和的语义摘要）、布局相关性、sharpness proxy（边缘能量）、以及颜色/结构/布局/背景/细节分解。
- 不计算 LPIPS（遵循 Brain-IT 代码）。

## 6. 主要结论与发现

- **性能**：NeuroRefine 在 930 个共享 NSD 概念上达到 CLIP image cosine 0.755，高于 Brain-IT enhanced 的 0.735；图像显著更清晰；饱和的 2-way 识别保持不变。
- **布局权衡**：精化以布局一致性从 0.638 降至 0.541 为代价，换取语义保真和纹理；低

层图像仍保留粗略空间结构，但精化器在追求语义和纹理时可能偏离原始位置，尤其在密集场景中。  
- **数据效率**：在仅使用少量训练数据（如 1–10% 数据）时，NeuroRefine 的语义优势更为明显，表明精化器对低层先验的利用降低了对大量 caption 标注的依赖。  
- **跨被试与跨数据集**：在被试 2 和 5 的复制实验中观察到相似趋势；在 BOLD5000 上的外部验证表明该方法能够迁移到不同扫描仪和协议，尽管性能绝对水平下降。  
- **归因分析**：六头 MLP 的权重归因显示，颜色/物体等语义字段倾向于依赖腹侧视觉通路（如梭状回、外侧枕叶），布局字段更多涉及背侧区域（如顶上小叶），与已知功能组织一致。  
- **失败模式**：当低层图像中的物体与提示内容冲突时，精化器有时会忽略低层先验，导致物体身份或数量错误；对罕见概念和复杂背景的重建仍不理想。  

总体而言，NeuroRefine 证明了在 fMRI 重建流水线中引入图像条件精化阶段可以有效突破 caption 瓶颈，以适度的布局代价换取显著提升的语义保真度和视觉质量，为后续研究提供了新的架构范式。
